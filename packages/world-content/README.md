# @myeongha/world-content

Immutable, versioned world and episode content authority for Myeongha.

Rules:
- character relations and episode participants must resolve inside the same coherent content bundle;
- episode/content versions must match the containing bundle;
- runtime databases may project release state but do not author canon;
- `developmentPlaceholder` content is non-canonical and exists only to validate UI/runtime structure before real character/world authoring.
