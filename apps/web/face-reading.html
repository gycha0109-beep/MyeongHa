01 · 사진 준비

정면에서 얼굴이 잘 보이는 사진을 준비해주세요.

촬영하거나 앨범에서 사진을 선택하면 얼굴 구조 확인을 시작할 준비를 합니다.

  • ✓ 얼굴 전체가 프레임 안에 들어온 사진
  • ✓ 정면에 가깝고 흔들림이 적은 사진
  • ✓ 과도한 필터나 얼굴을 가리는 요소가 적은 사진
  • ✓ 밝기가 충분하고 얼굴 윤곽이 보이는 사진

HOW IT WORKS

관상은 이렇게 진행됩니다.

사진을 안전하게 준비하고, 얼굴 구조를 확인한 뒤 관상 풀이로 이어집니다.

01▣사진 안전 처리

사진을 분석 입력으로 정리하고 원본 저장 없이 다음 단계로 넘깁니다.

02◎얼굴 구조 확인

얼굴의 관측 가능한 영역과 구조를 중립적으로 확인합니다.

03▤관상 풀이

검증된 관상 기준과 연결된 결과를 하나의 풀이로 구성합니다.
