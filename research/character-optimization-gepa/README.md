# 명하 GEPA 오프라인 연구 실행 기반

> Watchtower-Track: character-runtime-lab · 2026-11-11
> **실제 GEPA 미설치 / OpenRouter 연결 안 함 / 네트워크 출구 전부 차단**

이 디렉터리는 v0.3 설계의 **예산 예약 핵심 및 차단 전용 출구**에 대한 초기 구현이다. 아직 GEPA 최적화 실행기가 아니며 학생·교사·심사·봉인 평가 모델을 호출하지 않는다.

- `budget_ledger.py` : 비공개 위치 SQLite WAL/원자적 예약/역할별 횟수·총비용 제한/재시작 후 미확인 과금 보류. 금액 단위는 정수 **USD 마이크로(1달러=1,000,000)**. **요청을 보내기 전** 다른 신뢰 가능한 호출 계층이 검증된 최악 청구액을 계산해야 한다.
- `egress_gateway.py` : 모든 원격 모델 호출을 실패 처리하는 차단 전용 출구. 실제 HTTP 클라이언트가 없다.
- `evaluation_bridge.py` : 원문 없이 평가 메타데이터만 Node 오프라인 검증기와 교환한다. 스크립트는 외부 네트워크를 사용하지 않는다.
- `tests/` : 합성 예산(실제 승인 아님)으로 병렬 경쟁·비정상 종료·중복 요청·미확인 과금·역할별 차단을 테스트한다.

```sh
python -m unittest discover -s research/character-optimization-gepa/tests -v
```

**실제 API를 허용하는 파일 또는 비밀키 입력 기능은 없다.** SQLite 장부를 구현했다는 사실만으로 Python/Node 전체 네트워크 우회 차단, 토큰 가격 검증, 교사 호출 추적, GEPA 라이브러리 연동, 봉인 파일 시스템 격리를 입증할 수 없다. 이 항목들은 후속 단계에 남아 있다.

검수 시점 로컬 환경: Python 3.13.5, GEPA 미설치. 설치 버전과 Python 의존성 잠금은 라이브러리 실증 시에 확정한다. 기존 프로젝트 npm 11.17.0 / Node >=24 설정은 변경하지 않는다.
