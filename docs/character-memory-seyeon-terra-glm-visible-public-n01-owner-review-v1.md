# 세연 공개 합성 첫 인사 — Terra / GLM 실제 대사 비교
Watchtower-Track: character-memory

이번 단발 실험은 동일한 공개 합성 입력 `N01: 안녕, 세연아!`에 대한 기존 Terra 5회 경로와 GLM 5.3 Flash 3회 경로의 **실제 최종 대사 원문**을 사용자에게 직접 보여주기 위한 것입니다.

기존 원본은 로그에 저장되지 않아 복원할 수 없습니다. 기존 실행의 Guard 판정·속도·비용·토큰 기록과 캐릭터 설계는 남아 있습니다.

대상: 고정 합성 N01 1건, relationship=null, retrievedMemories=[], PUBLIC만. Terra는 기존 runSeyeonCharacterTurnV2, GLM은 기존 runSeyeonCensusFirstThreeCallShadowV1의 정확한 서버 Guard를 사용합니다. 양쪽 모두 Guard에 승인되고 공개 레벨이며 개인 출처와 기억 참조가 없는 1~500자 한글 최종 대사일 때만 두 응답을 로그에 출력합니다. 중간 생성물, 실제 사용자의 대화/메모리, 인증키, 모델 내부 사고 내용, generation ID는 출력하지 않습니다. 출력 원문은 공개 합성 테스트 결과이므로 보호 대상 개인정보가 아닙니다.

요청 제한: Terra 최대 5회 × $0.08, GLM 최대 3회 × $0.02, 응답당 30초, 출력 최대 1536 토큰, 재시도·fallback 없음. OpenRouter 잔액·ZDR·JSON 구조화 경로는 유료 요청 전에 확인합니다. 호출 전 fsync 예약합니다. 기존 예약 2,441.385원, 추가 최대 1,150원, 전체 최대 **3,591.385원 / 승인 5,000원** (상한 환율 2,500원/USD). 요금 숫자는 공급자 실청구가 아닌 보수적 예약·추정값으로 구분합니다.

이 비교는 공개 합성 N01 1건에 대한 오너 비블라인드 정성 평가입니다. 기존 C08-S 8개 Gold 블라인드 인간 평가를 대체하지 않습니다. 사람의 인격 품질 승인, 실제 기억·관계 대화 검증, Production 승격은 별도 HOLD입니다.
