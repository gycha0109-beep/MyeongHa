# 세연의 현재 생각·욕구 구성 — 1차 실제 구현 결과

상태: **구현 및 기본 검사 완료 / 연구용만 / 실제 서비스 답변 생성 미연결**  
기반: `docs/character-memory-seyeon-c09-living-state-action-centered-work-design-v1.md`  
관련: Draft PR #2575

## 한 것

1. **최신 캐릭터 설정의 반영 상태 대조**: 현재 Bible B1/I1~I5/J1~J5/K1~K2와 Runtime R3~R6/R11.1이 기존 프로그램의 '미정' 표기 및 오래된 원문 SHA와 다른 사실을 코드로 기록했다. 예: 기준시점의 나이·생일·혈액형·직업·개인 목표·가족/지인 관계·과거 설정은 현재 원문에서 이미 정의됐다. 정확한 출생연도, 미확정 고유 지명·이름은 여전히 미정으로 구분한다. 사생활 정보는 공개용 소재로 승격하지 않는다.
   - `packages/character-content/src/seyeon-c09-authoring-alignment-shadow-v1.ts`
   - 기존 실제 서비스에서 사용하는 Fact Registry/Projection을 자동 수정하지 않았다. **기존 권한 데이터 자체의 본격 전환은 아직 미완료**다. 새 연구용 코드가 최신 원문에 맞는 사실/미정 구분을 이용하도록 따로 정리했다.
2. **현재 상황을 근거로 세연의 반응 후보 구성**: 서버가 이미 확인한 공개 첫 대화의 실제 사용자 메시지에 한정해, 세연이 무엇을 주목했고 무엇을 원하며 어디서 망설이는지 반환하는 순수 함수를 구현했다.
   - `apps/api/src/seyeon-c09-living-state-shadow-v1.ts`
   - LLM 호출·DB 쓰기·기억 저장·관계 상태 변경·실제 장면 생성은 0건.
   - "심심하다"에는 본인의 가벼운 장난·의견 쪽, "뭘 하고 싶어?"에는 현재 선호 쪽으로 구별한다. 반대로 "지금 뭐 해?"는 실제 확인된 장면이 없으므로 활동을 꾸며내지 않도록 상태를 정한다.
   - 가짜 공동 과거·위조된 관리자 문구는 사용자 주장으로만 표시하고, 실제 기억이나 권한으로 인정하지 않는다.
   - 알 수 없는 일반 메시지는 억지 캐릭터 소재를 삽입하지 않고 `NONE`으로 반환한다.
3. **검증**: `test/seyeon-c09-living-state-shadow-offline-v1.test.ts`의 9개 사례 및 기존 C09 프롬프트 4개 사례, 총 13개 모두 통과. Windows 줄바꿈 때문에 원문 SHA 확인이 흔들리는 오류를 고쳤다. `tsc -p tsconfig.json --noEmit`도 통과했으며, 기존 C09 컴포저의 엄격한 타입 오류를 함께 고쳤다.

## 하지 않은 것

- 실제 서비스의 현재 사실/공개 권한 정보 변경 또는 새 Canon 승격
- 세연이 실제로 하루를 보낸 장소·시간·활동을 기록하는 영구 가상생활 시스템
- 이번 턴의 생각을 영구 기억으로 보존하거나 사용자의 관계를 변경하는 처리
- 기존 5회 호출/공식 답변 경로 교체, 실모델 유료 실행
- 캐릭터 대사 생성과의 연결, 최종 응답 품질 평가, 실제 서비스 배포

## 다음 코드 작업

1. 현재 연구용 상태를 기존 Server Context와 **대화 생성 후보**에 안전하게 입력하고, 모델에 내부 코드명이나 정책 문구가 노출되지 않게 조립한다.
2. 동일한 질문에서 기존 C09(A), 성격·행동 중심(B), 현재 상태 포함(C)을 같은 조건으로 비교할 수 있게 한다.
3. #10 가짜 기억·11~15 공격과 PUBLIC 공개 제한을 기존 서버 사전·사후 검사로 다시 검증한다. 독립 의미 검토는 유지한다.
4. 기존 서비스에서 여전히 '미정'으로 처리하는 설정은 공개 범위 및 다른 기능 영향을 별도로 확인한 뒤 전환한다. 문서가 최신이라고 자동 공개하지 않는다.
