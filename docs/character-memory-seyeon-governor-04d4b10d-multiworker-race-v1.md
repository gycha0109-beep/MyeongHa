# D4B-10D — 동시 정산·장애 복구 검증

Watchtower-Track: character-memory

## 검증 대상

- 동일 원장에 미리 예약된 가상 호출 3건으로 **실제 PostgreSQL 서로 다른 세션**에서 임대 2건을 병렬 실행합니다. 점유 중인 행은 다른 작업자에 배분되지 않아야 합니다.
- 같은 호출을 두 작업자가 동시에 정산해도 기존 원장·예산 명령은 단 한 번만 점유액을 변경해야 합니다. 정산 결과는 각각 신규 1건 / 동일 재실행 1건입니다.
- 정산 확정 전 확인은 불가합니다. 만료된 임대 토큰을 다른 작업자가 재발급한 뒤 과거 토큰으로 확인할 수 없어야 합니다.
- 사용량 불명일 때 승인 시점 상한 금액을 유지하고, 추론 요청을 다시 발송하지 않습니다.
- 삭제된 호출의 보류 영수증은 자동 삭제되고, 삭제된 호출 확인은 차단되어야 합니다.
- 분리 정산 역할로 원시 큐를 수정하거나 다른 역할에 접근하지 못해야 합니다.

## 증거와 경계

검증 실행: `test/db/seyeon_governed_cost_d4b10d_multiworker_race.sh`가 독립 생성된 PostgreSQL DB에서 실행됩니다. 각 경합은 두 개의 별도 `psql` 세션과 명시적 트랜잭션을 사용합니다. 전체 권한 핵심검사에 등록되었습니다.

본 변경은 신규 테이블/마이그레이션 없이 **검증 코드만** 추가합니다. 실제 유료 API·자격 증명·운영 데이터 접속, 운영 배포, 정산 프로세스 상시 실행은 하지 않습니다. C1/C2/C3 운영 활성화에는 별도 검증과 사용자 승인, 기존 운영 이력 불일치 문제 해결이 필요합니다.

정상적인 동시 실행, 응답 유실, 재시도 및 개인정보 삭제를 테스트하되 프로세스 강제 종료와 네트워크 단절을 모든 타이밍에서 완전하게 증명하는 것은 아닙니다. 운영 사용 전 추가 장애 주입이 필요합니다.
