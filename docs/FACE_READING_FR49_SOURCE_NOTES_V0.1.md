# FR-49 source review notes

This note separates what was directly checked from what is only bibliographic metadata.

## NLC 麻衣相法 witness

Pinned upstream witness: `witness.mayi_xiangfa.nlc_1925_v1`.

Direct scan review confirms the transmitted text used by FR-33 on the relevant page includes:

`眉至準頭為中停。準至地閣為下停。`

The second clause is preserved exactly as printed in this witness. It is not silently normalized to `準頭至地閣`.

## Traditional lexical evidence

`欽定古今圖書集成 / 博物彙編 / 藝術典 / 第636卷` preserves the face-reading statement `頦為地閣` in the transmitted material.

This supports only a traditional chin-region association.

## Historical anatomical terminology

`御纂醫宗金鑒 / 正骨心法要旨 / 地閣骨` records `又名頦，俗名下巴骨`.

This is used only as independent historical anatomical terminology. Bony `地閣骨` is not equated with the traditional soft-tissue anchor or modern Me′.

## Modern soft-tissue landmark definitions

The following publication records explicitly define soft-tissue Menton from the chin soft-tissue contour:

- PMID `24559507`: `Three-dimensional evaluation of the relationship between jaw divergence and facial soft tissue dimensions`.
- DOI `10.3390/app14125307`: `Validity and Reliability of New Three-Dimensional Reference Systems for Soft Tissue Analysis Using Non-Ionizing Three-Dimensional Imaging`.

FR-49 uses these only for the conceptual relation `chin soft-tissue contour -> inferior midline/midpoint -> soft-tissue Menton`.

No source in this slice is treated as evidence for a MediaPipe index, FACE_OVAL equivalence, traditional 地閣 = Me′ equality, or a production threshold.
