# D4B-10C3 — 영속 영수증과 분리 정산 작업자 연결

Watchtower-Track: character-memory

## 구현 범위
- 이미 저장된 비용 영수증을 PostgreSQL `cmd_claim_seyeon_provider_receipt_v1()`에서 한 건씩 임대합니다. 원장 전체 조회나 새 모델 호출 권한을 부여하지 않습니다.
- DB의 예약 시점 가격, 호출·주체·턴·시도·단계 및 영수증 JSON을 교차 검증합니다. 임의 비용·가격 변경·불필요한 메시지 또는 비밀 정보가 있으면 정산을 거부합니다.
- 기존 `createSeyeonDetachedSettlementWorkerFromDriverV1`와 연결하면 전용 작업자만 동일 영수증을 정산하고 **정산 COMMIT 이후에만** DB 확인 호출을 수행합니다.
- DB에는 만료되는 임대 토큰과 선착순 잠금이 존재하며, 실행 프로세스는 한 건의 미확인 영수증만 보유합니다. COMMIT 응답 유실 시 성공으로 처리하지 않습니다. 종료·실패 후에도 재추론 없이 임대 만료 뒤 재시도할 수 있습니다.
- 테스트는 모의 PostgreSQL 단위 테스트를 포함합니다. 데이터베이스 레벨의 임대·권한·개인정보 삭제·중복 정산 검증은 D4B-10C1 격리 PostgreSQL 테스트에서 수행합니다.
