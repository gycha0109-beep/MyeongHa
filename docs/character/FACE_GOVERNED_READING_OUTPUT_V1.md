# 관상 승인 해석 결과 → 캐릭터 읽기 계획·최종 출력 v1

## 목적

이 단계는 제품 사용 승인을 받은 관상 해석 결과를 실제 캐릭터 관상 읽기 계획과 최종 출력 경계에 연결한다.

사진에서 전통 관상 조건을 판정하는 책임은 여전히 관찰 엔진과 관상 연결 트랙에 있다. 명하는 상위 엔진이 승인한 결과를 다시 해석하지 않는다.

## 실행 흐름

```text
현재 Face 런타임
+
제품 승인 관상 해석 결과
+
실제 캐릭터 관상 프로필
        ↓
같은 사진 분석 결과인지 결속
        ↓
캐릭터 최대 노출 개수 적용
        ↓
상위 엔진 순서 그대로 선택
        ↓
승인 보호 의미 본문 주입
        ↓
저작된 질문 전략으로 후속 질문
        ↓
캐릭터 출력 검증
        ↓
신뢰 언어 정책 재검사
        ↓
최종 출력
```

## 같은 사진 결과 결속

승인 해석 결과의 `sourceResultHash`는 현재 Face 런타임의 `groundingRef.sourceResultHash`와 정확히 같아야 한다.

따라서 같은 주제의 다른 사진 분석 결과를 현재 대화에 끼워 넣을 수 없다.

또한 `topicKey`도 현재 Face 런타임과 정확히 일치해야 한다.

## 세연의 현재 선택 권한

현재 세연 설정에는 재물·관계·직업 등 관상 의미 주제 사이의 선호 순위가 저작되어 있지 않다.

따라서 이번 버전은 세연에게 임의의 관상 주제 선호를 만들지 않는다.

선택 규칙:

1. 상위 관상 엔진의 승인 결과 순서를 그대로 유지한다.
2. 기존 세연 관상 프로필의 `maxUnits`만 적용한다.
3. 실제 존재하는 승인 결과만 선택한다.
4. 선택되지 않은 결과는 삭제하지 않고 생략 상태로 남긴다.

현재 세연은 기존 프로필 기준 최대 3개를 노출한다.

향후 캐릭터별 관상 의미 선호가 정식 저작되면 별도 버전에서 순서 정책을 확장한다.

## 보호 의미 본문

관상 해석 본문은 상위 엔진의 `protectedMeaningText`를 그대로 사용한다.

다음 변경은 허용하지 않는다.

- 재물 → 현실 감각처럼 주제 변경
- 긍정 → 혼합 또는 주의로 방향 변경
- 조건 삭제
- 충돌 상태를 한쪽 결론으로 정리
- 근거에 없는 관상 의미 추가

이번 버전은 AI 자유 재서술을 사용하지 않는다.

## 후속 질문

후속 질문은 실제 선택된 해석이 하나 이상 있을 때만 생성한다.

질문 전략은 세연의 실제 저작 소스에 있는 `questioning.preferredStrategies`에서 가져오고, 기존 관상 전달 프로필에 등록된 안전 문구가 있을 때만 사용한다.

현재 세연의 첫 유효 조합은:

- 질문 전략: `activate_next_step`
- 안전 문구: `어느 항목을 더 볼까요?`

후속 질문은 선택된 실제 해석 식별자와 주제 키를 함께 보존한다. 따라서 존재하지 않는 대인관계나 재물 항목을 새 선택지로 만들 수 없다.

## 최종 출력 경계

최종 출력에서는 기존 캐릭터 출력 검증을 그대로 재사용한다.

검증 대상:

- 허용된 감정
- 허용된 애니메이션
- 허용된 제안 동작

관상 최종 출력에서 다음 부작용은 허용하지 않는다.

- 메모리 제안
- 관계 상태 변경 제안
- 사주 보호 본문 혼입
- 사주 계산 불확실성 혼입
- 검증 뒤 자유 문장 앞뒤 삽입

보호 관상 본문과 후속 질문은 사용자 공개 직전에 신뢰 언어 정책을 다시 검사한다.

## 실제 세연 통합 시험

시험은 실제 세연 런타임 권한과 실제 세연 관상 프로필을 사용한다.

다만 관상 의미 내용은 아직 상위 관상 엔진의 실제 제품 승인 결과가 없으므로 **제품 승인 계약 형식을 만족하는 합성 고정 자료**를 사용한다.

시험이 증명하는 것:

- 세연 실프로필의 최대 3개 제한 적용
- 상위 승인 순서 보존
- 충돌 상태 보존
- 보호 의미 본문 정확 보존
- 실제 저작 질문 전략 사용
- 메모리/관계 부작용 없음
- 다른 사진 결과 혼입 거부
- 신뢰 훼손 문구 최종 차단

시험이 증명하지 않는 것:

- 합성 자료의 관상 내용 자체가 실제 제품 승인을 받았다는 것
- 사진 → 전통 조건 판정 정확도
- AI 세연의 자유로운 말투 품질

## 다음 단계

이 단계 뒤에는 최종 출력 결과를 기존 관상 읽기 결과물 저장 → 원자적 저장 → 통제 공개 흐름에 연결할 수 있다.

실제 상위 관상 엔진이 제품 승인 결과를 발행하기 전까지는 합성 승인 자료를 운영 데이터로 사용하지 않는다.
