## 3. Explicitly unresolved authority

This source snapshot does not establish:

```text
canonical characterId
immutable displayName
final gender canon
origin
apparent age band
final deity hierarchy / deityId / deity doctrine binding
versioned immutable visual profile
Character-to-Character canonical relation graph
Production roster-level differentiation PASS
```

Detailed per-Character values such as exact oath, Human Theory, Agency Theory, Truth Theory, desire, fear, flaw, contradiction, hidden motivation, Persona fields, Behavior rules, SajuProfile fields, and RelationshipBehavior rules require explicit source support before being represented as approved canon.

A draft/proposal may explore those values, but proposal text must remain structurally and semantically distinguishable from source-approved immutable Character content.
