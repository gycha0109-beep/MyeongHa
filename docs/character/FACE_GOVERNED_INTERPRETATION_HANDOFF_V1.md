# 관상 승인 해석 결과 → 캐릭터 브릿지 수신 계약 v1

## 목적

이 문서는 관상 엔진이 **제품에서 사용자에게 보여도 된다고 승인한 해석 결과**만 명하 캐릭터 계층으로 넘기기 위한 첫 수신 계약을 정의한다.

현재 관상 캐릭터 브릿지는 중립 관측값을 안전하게 전달하는 경로를 이미 갖고 있다. 이번 단계는 그 경로를 대체하지 않는다. 관상 연구와 사진 판정이 끝난 뒤 생성되는 승인 해석 결과를 별도 보호 구간으로 받는 통로를 추가한다.

## 책임 경계

전체 흐름은 다음처럼 분리한다.

```text
사진
→ 관찰 엔진: 중립 측정
→ 관상 연결 트랙: 측정값을 승인된 전통 조건으로 연결
→ 관상 해석 엔진: 전통 근거 조회와 제품 사용 승인
→ 명하 관상 브릿지: 승인 결과 수용·선택·전달
→ 캐릭터 출력
```

명하 관상 브릿지는 다음을 하지 않는다.

- 수치에서 전통 관상 조건을 새로 판정
- 임계값 생성
- 전통 명명형 자동 분류
- 연구 자료를 제품 권한으로 승격
- 새로운 재물·관계·직업·성정 의미 생성
- 상반된 근거를 임의로 하나의 결론으로 합침

## 수신 조건

수신 객체는 다음을 모두 만족해야 한다.

1. 제품 사용 승인 상태가 명시되어야 한다.
2. 사용자 공개용 관상 해석 범위로 승인되어야 한다.
3. 서버가 알고 있는 상위 출처 버전·권한 식별자·결과 해시·주제와 정확히 일치해야 한다.
4. 각 해석 단위는 사진 관측 근거, 관상 연결 근거, 전통 해석 근거, 원문 출처를 모두 보존해야 한다.
5. 같은 주제는 상위 관상 엔진에서 이미 하나의 단위로 정리되어야 한다.
6. 충돌 상태는 충돌 그대로 전달해야 한다.
7. 필수 금지 확장을 제거할 수 없다.
8. 전체 수신 내용의 해시가 일치해야 한다.

따라서 현재 연구 계층의 자료처럼 `제품 해석 허용 = false`인 결과를 그대로 명하에 넣는 방식은 지원하지 않는다.

## 필수 금지 확장

각 해석 단위에는 다음 금지가 유지되어야 한다.

- 새 관상 의미 추가 금지
- 주제 변경 금지
- 긍정/주의/혼합/충돌 방향 변경 금지
- 조건 삭제 금지
- 상위 권한 없이 충돌을 임의 해소하는 행위 금지

## 캐릭터 선택

캐릭터는 승인된 해석 중 어떤 것을 먼저 보여줄지 선택할 수 있다.

허용:

- 실제 존재하는 주제 중 선택
- 보여줄 개수 제한
- 순서 변경
- 캐릭터 반응 추가
- 실제 존재하는 주제를 대상으로 후속 질문 제안

금지:

- 없는 주제 선택지를 새로 생성
- 재물 근거를 현실 감각 등 다른 의미로 바꿈
- 충돌을 긍정 또는 부정 하나로 정리
- 조건부 의미에서 조건을 제거
- 근거에 없는 관상 주장을 추가

v1 선택기는 캐릭터가 제공한 주제 우선순위와 상위 결과의 원래 순서만 사용하며 의미를 계산하지 않는다.

## 보호 의미 본문

v1에서는 관상 엔진이 승인한 `protectedMeaningText`를 보호 의미 본문으로 취급한다.

캐릭터 자유 재서술은 아직 허용하지 않는다.

```text
승인된 보호 의미 본문
+ 캐릭터 반응
+ 캐릭터 후속 질문
```

구조를 기본선으로 한다.

향후 자유 재서술을 열려면 별도 의미 보존 검증과 평가 통과가 필요하다.

## 현재 상태

완료:

- 승인 해석 결과 수신 계약
- 신뢰된 상위 출처와의 정확한 결속
- 연구 전용 결과 직접 유입 차단
- 주제·방향·조건·충돌·출처 보존
- 결정적 선택
- 보호 의미 본문 생성

아직 하지 않음:

- 실제 Saju 저장소 관상 엔진의 제품 승인 결과 연결
- 사진 관측값 → 전통 조건 판정
- 세연 관상 의미 주제별 우선순위 저작
- 세연 자유 재서술
- 실제 AI 제공자 연결

실제 상위 관상 엔진이 제품 승인 결과 계약을 발행하면 이 수신 경계에 연결한다.
