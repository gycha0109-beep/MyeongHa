# Admin Console A0–A7 구현 로드맵 — 기존 범위 정합성 정리 (2026-11-14)

> 이 문서는 이미 존재하는 관리자 A0–A7 구현 범위의 **현황·종료 경계**를 정리한 것입니다. 신규 단계, 신규 기능, 운영 실행 승인 또는 기존 보류 해제를 만들지 않습니다.
> 기능 범위는 [관리자 README](../apps/admin/README.md)의 기존 A0–A7, 승인 정책은 [Admin 운영 정책](operations/ADMIN_OPERATING_POLICY_20261027_V1.md), 실제 수용 기록은 [읽기 전용 작업 로그](operations/ADMIN_READONLY_ACTIVATION_WORKLOG_20261105.md)와 [A4 최신 증거](operations/ADMIN_A4_OPERATIONAL_READINESS_EVIDENCE_20261112.md)를 우선합니다. 과거 문서의 당시 상태는 이후 날짜의 실증·사용자 결정으로 갱신합니다.

## 트랙의 소유 범위

- **관리자 소유:** Owner 전용 화면, 권한·감사, 사용자/결제/Reading 조회, AI 비용·예산의 출처 구분과 표시, 분석 조회·관리자 제어, 허용된 명령 UI와 감사, 공지·배너 관리 및 관리자 쪽 실행 계약.
- **원천 트랙 소유:** Saju 해석 권한·실제 공급사 호출과 Source 기록, Commerce 환불/크레딧 도메인 명령, 분석 원천 이벤트·동의·삭제, 서비스 배포·네트워크·TLS·DB/Secret 운영. 관리자는 필요한 계약과 확인 상태만 추적하며 원천 트랙의 작업을 대신 수행하지 않습니다.
- **운영 환경 선호(2026-11-14 사용자 지시):** 기존 Supabase를 유지합니다. Saju 실행의 Supabase Edge Functions 적합성은 운영 트랙에서 검토하고, 집 PC Docker는 개발·검증용으로 둡니다. Edge Functions 배포나 호환성 검증이 끝났다는 의미는 아닙니다.

## 이미 확인된 수용과 사용자 결정 — 재작업 금지

1. [관리자 읽기 전용 배포](https://github.com/gycha0109-beep/MyeongHa/actions/runs/42375880365)와 [회원 중심 화면 PR #3100](https://github.com/gycha0109-beep/MyeongHa/pull/3100)은 완료 기록이 있습니다.
2. 2026-11-08 Owner 브라우저에서 **회원 목록·상세, Reading, 검증 결제** 화면이 관측됐고 같은 종류의 `allowed` 감사 이벤트가 운영 DB에서 확인됐습니다. 단, 클라이언트 요청 ID와 감사 ID의 직접 문자열 대조까지 완료했다고 주장하지 않습니다. 근거: [읽기 전용 작업 로그](operations/ADMIN_READONLY_ACTIVATION_WORKLOG_20261105.md), [PR #3150](https://github.com/gycha0109-beep/MyeongHa/pull/3150).
3. 2026-11-08 Owner가 **비Owner 앱 수준 거부 로그인 재현의 추가 수행을 생략**하도록 결정했습니다. 이를 통과로 둔갑시키거나 다시 필수 승인 질문으로 올리지 않습니다. 단일 Owner Access 정책과 서버 측 권한 검사는 유지합니다.
4. 기존 승인 정책: AI 월 예산 **100,000원**, **80%·100% 경고**, 자동 중단 없음; 관리자 감사 **365일**; 분석 **180일**. [운영 정책](operations/ADMIN_OPERATING_POLICY_20261027_V1.md).
5. A4 **명하 사전 승인 증명**은 최대 **30일**, 회원 삭제 연계 폐기로 승인됐고 29일 선제 정리 작업의 실행 성공이 관측됐습니다. [보존 결정](operations/ADMIN_A4_PREPARED_PROOF_RETENTION_DECISION_20261113.md), [실측](operations/ADMIN_A4_OPERATIONAL_READINESS_EVIDENCE_20261112.md). **Saju Source 의도·영수증·Claim 기록의 보존 정책은 별개**이며 이 승인으로 대체하지 않습니다.
6. [A4 마지막 연결 코드 Saju PR #2792](https://github.com/gycha0109-beep/Saju/pull/2792)와 [명하 A4 실측 기록 PR #3301](https://github.com/gycha0109-beep/MyeongHa/pull/3301)은 병합됐습니다. 집 PC의 Docker Source 로컬 검증을 실제 운영 공급사 호출이나 실비 청구 대조로 확대하지 않습니다.

## 종료선과 재개 조건

- **관리자 자체 구현 완료:** 해당 단계의 기존 화면·API·DB/RPC·권한/감사 계약과 필요한 자체 검증이 실제로 끝났을 때만 표시합니다. 과거 성공한 배포·테스트를 무조건 재실행하지 않습니다.
- **외부 원천 대기:** A4 실제 공급사 비용/환율/청구, A5 실제 이벤트 원천, A6 도메인 실행, A7 게시 런타임 등은 소유 트랙의 검증 결과가 전달될 때 관리자 연결·표시를 수용합니다. 이를 이유로 관리자 트랙에서 Saju Docker·호스팅·TLS·DB를 구축하지 않습니다.
- **보류 유지:** A4 비용 수집 OFF, `completeCostCoverage=false`, `invoiceReconciled=false`; A5 수집 OFF, A6 고객 변경 OFF, A7 게시 OFF. 운영 설치·실제 호출·배포를 문서 수정으로 승인하거나 실행하지 않습니다.
- **추가 구현 중단 기준:** 현재 승인된 관리자 자체 작업이 끝나고 남은 조건이 외부 증거/기존 보류뿐이면, 합성 테스트나 새로운 후보 기능을 만들어 채우지 않고 해당 조건과 재개 신호를 남깁니다.
- **전체 종료:** A0–A7의 원래 필수 기능·실제 수용 조건이 모두 충족된 경우에만 `ROADMAP_COMPLETE`. 현재는 **미충족**입니다. 부분 구현 완료는 전체 운영 수용과 구분합니다.

## 이번 정리의 범위

기존 로드맵의 상태 분류와 문서 연결만 복원합니다. 고객 DB·실서비스·비밀키·결제/크레딧·Saju 실행·실제 AI 비용·운영 플래그를 변경하지 않습니다.
