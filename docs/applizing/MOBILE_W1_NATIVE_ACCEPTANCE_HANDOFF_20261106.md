진행 전 실제 테스트 대상 main 커밋 SHA, 개발용 실행 방법/앱 버전, 장치 모델·OS·언어·테마를 기록한다. Native 실행은 `apps/mobile/README.md`의 기존 `npm run start -w @myeongha/mobile` 및 `npm run android -w @myeongha/mobile` 등을 사용한다. **W2의 main 전용 physical-smoke APK 생성 워크플로는 W1 수락 전에 실행하지 않는다.** 기기가 없거나 실행 환경이 준비되지 않으면 결과는 '미실행'이다.

- [ ] 홈: 게스트/회원별 프로필·명식·최근 기록·로딩/오류/새로고침이 사실대로 표시되는지 확인. 계정 전환 중 이전 사용자 데이터 노출 없음
- [ ] 대화 목록: 공개 캐릭터 정확히 6명. 도윤·미라·서린은 공개 선택/준비 중 목록에서 미표시. 회원 대화 열기와 게스트 안내, 네트워크 오류 및 재시도
- [ ] 대화 상세: 소유자별 기존 메시지, 추가 페이지 오류/재시도, 미전송 문장 유지, 세연 회원 전송만 가능. 권한 보류 시 이전 기록 숨김. 계정 전환 후 이전 대화/초안·전송 결과 노출 없음
- [ ] 사주: Birth 정보(날짜/시간/성별/출생지 미제공/계산 기준), 원국·오행·계산 미확정, 11개 주제 및 보고서 예시 확인. 승인되지 않은 풀이·구매 버튼·권한 진입 없음
- [ ] 출생 입력: 양력/음력·윤달·시간 모름·12시간 입력 및 오류 안내. 같은 계정 새로고침에 초안 유지, 다른 계정 전환에는 이전 초안 제거. 원본 역법/서버 권한 수정 없음
