# FE041A — Fail-Closed Operationalization Candidate

Watchtower-Track: face-reading

FE041A installs the first OperationalizationDefinition boundary without claiming that any real traditional term has been quantitatively operationalized.

The architecture order remains:

`SourceWork → SourceWitness → SourcePassage → MethodologyStatement → OperationalizationDefinition → RuleDefinition → Claim`

## What FE041A records

A research candidate can bind an existing FE039 source-supported criterion candidate to one or more metric references from an actually issued FE040 canonical registry admission.

The output records:

- criterion candidate reference;
- source authority reference and bundle digest;
- methodology statement references;
- the already-recorded traditional term;
- canonical metric registry reference;
- canonical input metric references;
- `reviewStatus = research`.

This is a research mapping record, not a traditional classification decision.

## What remains deliberately null

Every FE041A candidate has:

- `classificationBands = null`;
- `numericThresholds = null`;
- `calibrationRef = null`;
- `ruleRef = null`;
- `productionCriterionAdmitted = false`.

The contract cannot accept those fields on input. Extra authority-shaped fields fail exact-shape admission.

## Canonical metric ownership

Input metric refs must exist in the actually issued FE040 registry admission. A structurally cloned/forged registry object is rejected by the existing FE040 issued-admission brand.

No canonical metric identity is copied into the FE041A contract.

## Semantic boundary

FE041A issues no:

- operationalization authority;
- traditional binding authority;
- threshold or comparison-band authority;
- calibration authority;
- classification;
- RuleDefinition;
- criterion authority;
- structured claim;
- score or ranking;
- narrative authority;
- LLM semantic authority;
- production interpretation authority.

Tests use only synthetic source and traditional-term fixtures. No real physiognomic term is operationalized by this phase.

The FE038 interpretation shell remains locked.

A later research/review phase must supply evidence for an actual OperationalizationDefinition and, separately, any calibration authority required for numeric classification bands before a production rule can exist.
