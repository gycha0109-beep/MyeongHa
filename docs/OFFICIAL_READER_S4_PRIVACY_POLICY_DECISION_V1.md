# 공식 Reader 유료 해설 개인정보 처리 정책 — 제품 책임자 승인 정본 v1

**Decision ID:** `P0-PR-02`  
**승인일:** 2026-10-19 (KST)  
**상태:** **제품 책임자 승인(DECIDED) / 법무·개인정보 기술 인수 대기 / 유료 공개·저장·운영 적용 금지**

이 파일은 명하의 **장기 정책 정본**입니다. 승인사항을 PR 대화나 AI 채팅 기록에서 복원할 필요 없이 이 파일과 [P0 결정 원장](P0_DECISION_REGISTER.md)에서 확인합니다. 나중에 변경하려면 새 승인 버전을 기록하고 이전 승인 범위를 보존합니다.

## 1. 승인 근거와 정확한 범위

- 제품 책임자 직접 지시(2026-10-19): **“외부 업체는 일단 없다. 나머지는 승인”**.
- 대상: 공식 Reading × Reader × 검증된 독립 구매권으로 생성한 **새 유료 사주 해설 원문·청크·후속 유료 답변**.
- 승인 범위: 개인정보·법률 검토안의 **D1·D2·D3·D5·D6 제품 정책**과 내부 목표 **본 DB 원문 파기 24시간 이내**, **원문 없는 일반 운영 로그 보존 상한 90일**.
- 외부 업체(D4): **새 유료 원문 처리 외부 업체를 현재 도입하지 않음**. 외부로 원문을 전송하거나 개인정보 처리위탁·국외 이전을 승인한 것이 아님.
- **본 승인은 법률 전문가의 적법성 승인, 새로운 DB 개인정보 그래프/RLS 승인, 운영 적용·유료 본문 저장·실결제·공개 승인이 아님.**

## 3. 외부 업체 — 결정 문장의 오용 금지

사용자의 “외부 업체는 일단 없다”는 **새 유료 해설 원문에 추가 외부 처리를 허용하지 않겠다**는 뜻으로 기록합니다. 기존 코드·사업 운영에는 PortOne V2 결제, Supabase, 배포/호스팅 등 외부 인프라가 존재할 수 있습니다. 따라서 **현행 위탁·국외 이전이 법적으로 존재하지 않는다**는 판단을 승인한 것이 아닙니다.

새 원문이 실제로 도달할 수 있는 인프라·수탁자·국가/리전·로그/백업·학습/재사용 조건을 Legal/Privacy가 검토하기 전 **원문 외부 전송 금지**. 앞으로 업체를 도입할 때는 업체/항목/목적/기간/국가/계약/법적 근거를 별도 승인합니다.

## 4. 변경하지 않는 기존 정본

1. [P0-PR-01 회원 삭제·보존 정책](operations/ACCOUNT_DELETION_FINALIZATION_POLICY_V1.json)의 **기존 테이블 개인정보 삭제/익명화, Commerce P5Y, P30D 백업**은 그대로 둡니다. 기존 정책의 그래프 지문·운영 실행 승인 플래그를 새 원문 저장 승인처럼 덮어쓰지 않습니다.
2. [RR-03 Saju Assistant 출처 이력 승인](https://github.com/gycha0109-beep/MyeongHa/issues/1884#issuecomment-6103479019)은 **그 별도 provenance 이력 테이블을 탈퇴 시 DELETE**한다는 결정입니다. 새 해설 **본문 전문·청크**까지 승인한 것은 아닙니다.
3. [단일 채팅·T1/T2 유료 Reader 제품 결정](MOBILE_READER_PRODUCT_OWNER_DECISION_20261012_V1.md)을 유지합니다. 기존 단일 채팅방과 신규 유료 원문 저장소의 **권한·삭제 경계는 구분**합니다.

## 5. 별도로 해결해야 하는 법률·기술 인수

- **LEGAL-002/Privacy:** 법적 처리 근거(민감정보·아동 포함), 현행 수탁자/국외 이전 사실, 개인정보 처리방침·AI 고지, 개인정보 권리행사 경로, 법정 소비자 환불/분쟁 요건 검증.
- **DB/Chat/Security:** 새 보호 저장소 구조, 정확한 FK/Subject 삭제 그래프 버전, 탈퇴 populated-row DELETE, RLS FORCE/ACL, 원문 안전 로그, 일반 Chat·Memory·Outbox 역유입 0, 24시간 삭제 대상 선정 및 재시도·오류 처리 검증.
- **복원/DR:** 기존 P30D 백업의 과거 원문이 복원되어도 tombstone/최신 권한·삭제 원장을 서비스 시작 **전** 대조·재적용하고 재노출 0을 실제 격리 DB에서 입증.
- **Saju·S5·출시:** Saju [#2410](https://github.com/gycha0109-beep/Saju/issues/2410) Production 공식 Source attestation, Reader S2 잠금·S5 동일 거래 T2 Commit, S7 법무·상품/결제, S8 통합 승인.
- **구현 금지:** 이 문서만으로 새 운영 DB migration, 유료 원문 영속 저장·모델 전송·실제 환불/결제·공개·PR #2301 병합을 허용하지 않습니다.
