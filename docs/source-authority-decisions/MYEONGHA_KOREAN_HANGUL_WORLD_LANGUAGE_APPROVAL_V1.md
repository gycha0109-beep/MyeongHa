## 1. Product Owner의 승인 결정

명하의 독립 언어·문자라는 기존 구상 대신, **현대 명하의 공용어는 한국어, 공식 표준 문자는 한글**로 확정한다.

현대 명하인과 현실의 한국어 화자는 별도 번역 장치 없이 자연스럽게 상호 이해할 수 있다. 명하 특유의 방언·제도 용어·고유 어휘는 인정하되, 그것을 현대 한국어와 별개의 필수 '명하어'로 설정하지 않는다.

이 결정은 **공용어·공식 문자의 월드 레벨 Canon**이며, 각 Character 개인의 모어·외국어 능력·직업·가족 관계를 일괄 확정하지는 않는다.

## 2. 채택된 역사적 최소 설명

1. 초기 정착 집단에서 **한반도의 옛 언어·문화 계통**이 핵심적인 영향력을 가졌다. 수천 년 전부터 현대 대한민국 국적이나 현대 한국어·현대 한글이 존재했다고 소급하지 않는다.
2. 이후 명하는 여러 세대에 걸쳐 언어적 특색을 가진 독립 문명으로 발전했다. 초기 정착민 전원이 동일 출신이었다는 설정은 아니다.
3. **한글은 현세에서 역사적으로 등장한 이후**, 제한적 왕래와 문서·교육 등의 교류를 통해 명하에 유입·보급되었다.
4. 현실과의 후대 교류, 특히 근현대의 인쇄물·매체·교육·문화 접촉이 명하의 현대 한국어 사용과 상호 이해 가능성을 뒷받침한다. 이는 전근대에 대규모 상품·기술 무역이 있었다는 주장이 아니다.
5. 명하의 독립된 제도·역사·정체성은 그대로 유지된다. 공용어·문자가 같아도 한국의 도시·학교·국가 체계를 그대로 복제하지 않는다.

## 3. 명시적인 대체 및 영향 범위

- 오래된 기획·초안·캐릭터 대사 설계 중 **현대 명하 주민에게 한국어와 별개의 독립된 필수 언어 또는 한글과 별개의 공식 표준 문자가 있다는 가정**은 이 World Root 결정보다 후순위다.
- 명하에서 독자적으로 만들어진 사회적 표현, 속어, 고유 명칭, 옛 문헌의 다른 기록 형태가 존재할 가능성 자체는 폐기하지 않는다.
- 현실의 다른 언어가 자동 번역되거나 모든 국가의 사용자와 아무 제약 없이 대화할 수 있다는 설정을 승인하지 않는다.
- 백헌과 현세인 배우자, 딸의 **일상적인 한국어 의사소통이 가능하다는 월드 전제**는 제공한다. 그러나 혼인·사별 방식, 딸의 실제 언어 습관, 성장지·학력 등 세부 Biography는 별도 Character Bible의 결정이다.
- Saju/Face/Reading 근거, 메모리 공개 범위, 통행 권한, Product Release, Runtime 언어 변환 구현은 이 결정으로 변경되거나 자동 승인되지 않는다.

## 4. OPEN — 이번 결정으로 채우지 않는 역사

- 최초 정착민의 수·시대·집단별 구성비
- 명하 지역 한국어의 역사적 형태와 방언 분포
- 한글 최초 전래·보급의 연도, 매개 집단, 이전 문자·표기 전통
- 현대 명하의 상세 언어 교육과 외국어 통역 정책
- 각 Character가 실제로 사용하는 말투·언어 능력과 문서 양식

이 항목들은 필요할 때 후속 World/Character Authority 아래에서 결정한다. 현 단계에서는 공용어·표준 문자·기본 상호 이해 가능성만으로 제품과 서사를 진행할 수 있다.

## 5. 변경·검증 범위

- 변경: World Root의 정착 역사·언어 정책·교류 근거, Physical Life의 학습·거주 맥락.
- 유지: 동일 역사시간, 한국과 첫 Canary 시장 관계, 명하 독립 문명, 경계 Access와 통행 절차, 기존 Character 승인 설정.
- 코드 변경 없음; `main` 병합 후 새 World Canon이 향후 Character Bible과 신규 World authoring의 기준이 된다.
