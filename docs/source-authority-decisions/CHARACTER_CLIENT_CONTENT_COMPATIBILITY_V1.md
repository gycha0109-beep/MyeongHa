# 캐릭터 콘텐츠 호환성 판정 권한 v1

> 상태: **MVP 판정 계약 확정 / 실제 운영 자산 승인 및 운영 게시 미승인**  
> 결정일: 2026-10-06  
> 범위: 현재 운영 웹 클라이언트와 원격 캐릭터 콘텐츠 묶음 사이의 호환성 판정  
> 비범위: 실제 자산 값 승인, 자산 출처/라이선스 승인, 운영 DB 게시, 공개 채팅 활성화, 대체 콘텐츠 선택

## 1. 결정 목적

기존 SRC-15는 클라이언트 기능 식별자, 자산 목록 식별자, 연출 규격의 비교 규칙이 없어 원격 캐릭터 콘텐츠의 활성화 여부를 권한 있게 판정할 수 없었다.

이번 결정은 MVP에서 필요한 최소 호환성 계약만 확정한다.

## 2. 지원 클라이언트 범위

MVP 호환성 판정 대상은 기존 제품 결정과 동일하게 **현재 운영 웹 클라이언트**로 한정한다.

모바일이나 미래 버전 웹의 호환성 계약을 이번 결정으로 추론하지 않는다.

## 3. 식별자 의미

다음 값은 모두 순서가 없는 불투명 식별자로 취급한다.

- 최소 클라이언트 기능 식별자
- 자산 목록 해시
- 연출 규격 버전

따라서 다음은 금지한다.

- 숫자 접미사 크기 비교
- 문자열 사전식 크기 비교
- 시맨틱 버전 강제 해석
- 접두사/접미사 추론
- 암묵적 상위 호환 간주

## 4. 판정 소유권

최종 호환성 판정기는 서버 소유다.

클라이언트가 임의로 `호환 가능=true`를 보내는 값은 권한이 아니다.

판정기는 다음 두 입력만 사용한다.

1. 게시된 불변 콘텐츠 묶음의 호환성 메타데이터
2. 서버가 신뢰하는 현재 웹 클라이언트 호환성 프로필

호환성 프로필의 구체 자산 값은 별도 자산 승인 단계가 닫히기 전에는 운영 권한으로 만들지 않는다.

## 5. 비교 규칙

각 항목은 **정확 일치 집합 포함 여부**로만 판정한다.

- 콘텐츠 묶음의 최소 클라이언트 기능 식별자가 클라이언트 프로필의 지원 기능 식별자 목록에 정확히 존재해야 한다.
- 콘텐츠 묶음의 자산 목록 해시가 클라이언트 프로필의 지원 자산 목록 해시 목록에 정확히 존재해야 한다.
- 콘텐츠 묶음의 연출 규격 버전이 클라이언트 프로필의 지원 연출 규격 목록에 정확히 존재해야 한다.

세 조건이 모두 참일 때만 원격 콘텐츠를 활성화할 수 있다.

## 6. 실패 처리 우선순위

MVP에서는 대체 콘텐츠 자동 선택 권한을 만들지 않는다.

판정 우선순위는 다음과 같다.

1. 판정 입력 자체가 잘못됨 → 콘텐츠 숨김
2. 자산 목록 불일치 → 콘텐츠 숨김
3. 클라이언트 기능 또는 연출 규격 불일치 → 업데이트 필요
4. 모두 일치 → 활성화 가능

자산 목록 불일치에서 업데이트 필요를 강제하지 않는 이유는, 불일치가 클라이언트 노후가 아니라 게시 자산/출처 문제일 수도 있기 때문이다.

## 7. 결과 형태

판정 결과는 최소 다음을 포함한다.

- 판정기 버전
- 호환 여부
- 처리 방식: 활성화 / 숨김 / 업데이트 필요
- 실패 사유 목록
- 각 세부 검사 결과

이 결과 자체가 관계 상태, 기억, 캐릭터 정사 또는 사용자 사실을 변경하지 않는다.

## 8. 기록 정책

별도 호환성 판정 DB 기록을 새로 만들지 않는다.

성공적으로 새 대화방을 생성하는 경우 기존 제품 권한대로 선택된 릴리스와 콘텐츠 묶음 고정값이 지속 증거가 된다.

운영 진단에서는 판정기 버전과 클라이언트 프로필 키를 로그로 남길 수 있지만, 이것을 새로운 제품 상태 권한으로 사용하지 않는다.

## 9. 운영 활성화 경계

이 결정으로 SRC-15의 **비교 알고리즘과 판정 소유권**은 해결된다.

그러나 다음이 끝나기 전에는 실제 운영 캐릭터 콘텐츠를 활성화하지 않는다.

- 실제 운영 자산 값과 출처 승인
- 실제 자산 목록 해시 승인
- 실제 연출 식별자/규격 승인
- 운영 게시 권한 및 검증
- 공개 채팅 연결 단계의 별도 검증

따라서 이번 결정은 실제 운영 자산 승인이나 공개 채팅 활성화 권한이 아니다.
