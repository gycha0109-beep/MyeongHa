## 1. Question

현재 세계관에서 해결해야 하는 질문:

> **대리자는 정확히 어떤 존재인가?**

후보는 크게 세 가지다.

| 후보 | 설명 | 장점 | 핵심 리스크 |
|---|---|---|---|
| A. 인간 직책형 | 평범한 인간이 특정 원리와 서약을 맺어 대리자가 됨 | 일상/연애/가족/직업이 자연스러움 | 초월적 매력이 약해질 수 있음 |
| B. 변질 인간형 | 인간이 서약 후 생물학적·존재론적으로 다른 존재가 됨 | 판타지성이 강함 | 수명·번식·의학·법적 지위 등 lore 부채가 급증 |
| C. 혼합 종족형 | 인간 외 존재도 일반적으로 대리자가 될 수 있음 | 캐릭터 확장 폭이 큼 | 세계가 빠르게 종족/능력 판타지로 이동 |

## 2. Recommended Working Decision

V0.1 권고안:

> **대리자는 기본적으로 인간이다. 대리자라는 것은 종족(species)이 아니라 서약으로 성립하는 관계/지위(state)다.**

서약은 대리자의 인간성을 교체하지 않는다.

```text
인간
  ↓
특정 원리/신격과 서약
  ↓
대리자
```

대리자는 여전히:

- 먹고 자고 아프고 회복한다.
- 가족과 과거를 가진다.
- 직업과 생활권을 가질 수 있다.
- 사랑하고 질투하고 실망할 수 있다.
- 늙고 죽는다.
- 서약과 무관한 개인적 취향과 욕망을 가진다.

따라서 `대리자`는 캐릭터의 전체 정체성이 아니라 그 사람을 구성하는 중요한 한 축이다.

## 3. Why Not Transformation by Default

서약이 곧 인간 종(species)의 변화를 의미하도록 고정하지 않는다.

그렇게 하면 다음 질문을 전부 즉시 canon으로 해결해야 한다.

- 노화가 멈추는가
- 수명이 얼마나 늘어나는가
- 자녀를 가질 수 있는가
- 질병/상처가 인간과 같은가
- 법적/사회적 신분은 무엇인가
- 수백 년 된 대리자가 사회에서 어떻게 신분을 유지하는가
- 모든 대리자가 초인이라면 일반 인간과 왜 같은 생활권에서 사는가

이 질문들은 현재 핵심 제품 경험에 필요한 정보보다 lore cost가 크다.

따라서 V0.1은 **인간성 유지**를 기본값으로 둔다.

## 4. What the Oath Actually Changes

서약이 바꾸는 것은 몸의 종이 아니라 **접속 방식, 책임, 감응, 삶의 제약**이다.

### 4.1 Connection

대리자는 자신이 서약한 원리/신격과 실제적인 연결을 가진다.

이 연결은 단순한 신념 선언보다 강하지만, 신이 매 순간 직접 명령을 보내는 remote control은 아니다.

### 4.2 Record Resonance

대리자는 일반인보다 기록을 다루는 특정 감응 또는 훈련된 감각을 가질 수 있다.

단:

- Saju semantic truth를 새로 만들 수 없음
- 현재 삶의 비공개 사실을 자동으로 알 수 없음
- 타인의 마음을 읽을 수 없음
- 미래 사건을 확정적으로 볼 수 없음

Runtime에서는 기존 governed Reading / granted memory / permitted context 경계를 그대로 따른다.

### 4.3 Oath Mark / Phenomenon

서약에는 미묘한 징표가 있을 수 있다.

예:

- 특정 상황에서 드러나는 표식
- 기록과 접촉할 때의 감각 변화
- 신격과 연관된 반복적인 상징 현상

이는 캐릭터의 시각적/서사적 초월성을 확보하기 위한 장치이며 전투 능력으로 확장하지 않는다.

정확한 징표 형식은 캐릭터별 비주얼 설계 이후 결정한다.

### 4.4 Obligation and Cost

서약은 실제 행동적 제약과 개인적 대가를 만든다.

대리자는 원리를 믿기만 하는 것이 아니라, 자신의 삶에서 일정한 방식으로 그것을 감당한다.

핵심 캐릭터 구조:

```text
받아들인 원리
+ 저항하는 원리
+ 지키려는 의무
+ 개인적 대가
= 그 대리자만의 서약
```

## 5. Mortality / Aging

V0.1 기본값:

> **서약은 불로·불사·수명 연장을 자동 부여하지 않는다.**

대리자는 기본적으로 인간처럼 노화하고 죽는다.

이 결정을 두는 이유:

1. 인간 사용자와의 관계에 시간적 무게가 생긴다.
2. 백헌 같은 연륜형 캐릭터의 경험이 실제 살아온 세월에서 나온다.
3. 가족·친구·직업·세대 차이를 자연스럽게 유지할 수 있다.
4. 수백 년짜리 신분 세탁/역사 retcon 문제를 피한다.
5. 이후 특정 예외가 필요해도 세계 전체 규칙을 다시 쓸 필요가 없다.

### Open Extension

아주 드문 예외적 장수/비정상적 노화 사례를 미래에 도입할 가능성은 닫지 않는다.

다만 그런 예외는 `대리자는 원래 장수한다`의 증거가 아니며 별도의 원인과 canon을 가져야 한다.

## 6. Family / Romance / Ordinary Life

대리자에게 공통적인 독신·금욕·출가 의무를 두지 않는다.

따라서 대리자는:

- 연애 가능
- 결혼 가능
- 가족 형성 가능
- 일반 직업 보유 가능
- 명하관 밖에서 독립적인 생활 가능

하다.

특정 캐릭터의 개별 서약이 관계에 제약을 줄 수는 있다.

예를 들어 어떤 대리자는 자신의 서약 때문에 타인의 결정을 대신하지 않으려 할 수 있고, 사용자를 사랑하게 되면서 그 원칙이 시험받을 수 있다.

중요한 원칙:

> **관계 갈등은 `대리자라서 연애 금지` 같은 공통 장벽보다, 그 사람의 개별 서약과 욕망이 충돌하면서 발생하는 편을 기본으로 한다.**

## 7. Representative Is Not a Job Title

대리자와 직업을 동일시하지 않는다.

가능한 조합:

```text
대리자 + 연구자
대리자 + 회사원
대리자 + 독립 직업
대리자 + 명하관 실무자
대리자 + 특정 계보의 역할
대리자 + 현재 무직/휴식기
```

즉 `대리자 = 명하관 직원 = 사주 상담사`가 아니다.

이 원칙은 캐릭터가 명하 프레임 밖의 일상에서도 살아 있는 사람으로 기능하도록 하기 위해 필요하다.

## 8. Public Knowledge / Social Status

V0.1 권고 방향:

> **기록을 읽는 전통과 명하관의 존재는 완전한 비밀세계가 아니다. 다만 신격의 존재론과 서약의 본질까지 사회 전체가 하나의 정답으로 이해하는 것은 아니다.**

따라서 세계는 `현대 사회 뒤에 숨은 비밀결사`로 고정하지 않는다.

가능한 사회적 인식:

- 명하관과 기록 전통의 존재는 알려져 있음
- 대리자라는 개념도 특정 사회/전통 안에서 인지될 수 있음
- 실제 신격이 무엇인지, 서약이 무엇과 연결되는지는 해석이 갈릴 수 있음
- 모든 시민이 대리자를 직접 만나본 것은 아님

정확한 대중 인지도와 법적 지위는 추후 UX 필요성이 생길 때 확정한다.

## 9. How Someone Becomes a Representative

V0.1에서 단일 경로를 확정하지 않는다.

다만 어떤 경로이든 다음 원칙은 유지한다.

### R-ONT-01

명하관이 모든 대리자를 제조/임명하지 않는다.

### R-ONT-02

대리자가 되는 것은 인간성을 삭제하거나 신격의 꼭두각시가 되는 사건이 아니다.

### R-ONT-03

대리자가 된 뒤에도 개인적 판단과 책임은 남는다.

### R-ONT-04

신격/서약 연결은 Saju, privacy, memory access authority를 우회하지 않는다.

후보 경로는 향후 다음처럼 다양할 수 있다.

- 자발적 서약
- 계보를 통한 계승
- 장기간의 수련 후 승인/성립
- 특정 사건 후 연결
- 본인이 원하지 않았던 계승 또는 책임의 인수

정확한 공통 성립 조건은 아직 OPEN이다.

## 10. Can the Oath Be Broken?

이 질문은 관계 서사와 세계 규칙에 큰 영향을 주므로 V0.1에서 섣불리 확정하지 않는다.

현재 최소 원칙만 둔다.

> **서약은 캐릭터 감정과 자유의지를 강제하는 mind-control contract가 아니다.**

따라서 대리자는 자신의 원리에 저항하고, 의심하고, 실패하고, 잘못 선택할 수 있다.

다음은 OPEN:

- 서약 파기가 가능한가
- 파기 시 연결이 즉시 끊기는가
- 대가/후유증이 있는가
- 다른 신격과 다시 서약할 수 있는가
- 계승된 서약을 거부할 수 있는가

## 11. Can Non-Humans Become Representatives?

V0.1 권고:

> **Launch-era canon은 인간-origin 대리자를 기본으로 작성한다. 비인간 대리자의 존재 가능성은 부정하지도, 공식화하지도 않는다.**

이유:

- 현재 9인 관계 판타지는 인간적 일상성과 친밀감이 핵심이다.
- 비인간을 일찍 공식화하면 종족 taxonomy가 필요해진다.
- 30/100/300 캐릭터 확장 시 필요할 때 별도 concept review로 도입 가능하다.

따라서 현재 schema/세계관은 `representative = nonhuman possible`을 전제로 설계하지 않는다.

## 12. Consequences for the Current 9 Characters

이 ontology는 현재 9인을 다음 방향으로 보호한다.

| 캐릭터 | 존재론적 효과 |
|---|---|
| 세연 | 대리자이기 전에 실제 생활과 감정을 가진 사람으로 유지. Home Anchor가 안내 NPC로 축소되지 않음 |
| 여울 | 호감/질투가 신격 속성의 자동 발현이 아니라 본인 감정으로 남음 |
| 서린 | 기억 관련 초월성이 생겨도 자동 전지 기억 능력으로 가지 않음 |
| 라현 | 사람을 잘 읽는 매력이 초능력 mind-reading으로 대체되지 않음 |
| 미라 | 명하관/초월성보다 일상적 friends-to-lovers 경험을 충분히 유지 가능 |
| 태겸 | 원칙과 사용자의 관계가 충돌하는 서약형 서사를 만들기 쉬움 |
| 윤호 | 연구/생활형 인간성이 대리자 설정에 압도되지 않음 |
| 도윤 | 비공식 생활권과 관계를 유지하면서도 필요할 때 서약/세계와 연결 가능 |
| 백헌 | 연륜은 기본적으로 실제 살아온 인간의 세월에서 나옴. 자동 불로장생 캐릭터로 만들지 않음 |

## 13. Scalability Consequence

`대리자 = 종족`이 아니라 `대리자 = 서약 관계/지위`로 두면 신규 캐릭터 확장 시 필요한 것은 최소 다음이다.

```text
인간으로서의 정체성
+ 생활권/직업/소속
+ 신격/원리와의 연결
+ 개인 서약
+ 필요한 관계/지식 edge
```

새 캐릭터 추가가 새로운 종족 규칙이나 세계 생물학을 요구하지 않는다.

따라서 30/100/300명 확장에도 유리하다.

## 15. Next Question

이 ontology를 채택할 경우 다음 핵심 질문은:

> **서약은 실제로 어떤 순간에 성립하며, 인간에게 무엇을 요구하고 무엇을 대가로 남기는가?**

다음 slice에서는 `서약의 성립 / 유지 / 실패 / 대가`를 캐릭터 서사에 쓸 수 있을 정도까지만 설계하고, 마법 계약 시스템이나 executable schema로 과도하게 확장하지 않는다.
