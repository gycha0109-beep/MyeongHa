## 0. 왜 별도 기록하는가

Duolingo is unusually useful because one public company combines:

```text
large free core
+ subscription conversion
+ higher AI subscription tier
+ advertising
+ IAP
+ separate one-time high-value product
+ public MAU / payer / revenue / gross-margin data
```

This makes it a stronger structural benchmark than a private app with only sticker prices.

---

# 1. Public 2025 business-model disclosure

Duolingo's 2025 10-K says it operates a freemium model where most learning content remains available without a paywall.

Revenue sources include:

```text
Super Duolingo subscription
Duolingo Max subscription
advertising to free users
in-app purchases such as Streak Freezes / Timer Boosts
Duolingo English Test one-time fee
```

Duolingo describes free users as economically useful because they:

- generate word-of-mouth;
- create large-scale usage/data for experimentation and product improvement;
- can convert months or even years after first use.

Source:
- SEC 2025 10-K: https://www.sec.gov/Archives/edgar/data/1562088/000162828026025737/duolingodecember312025an.htm

# 4. AI features also compress margin

Duolingo's 2025 disclosures say gross margin decreased partly because subscription gross margin declined from increased AI costs in features such as Video Call.

Reuters previously reported Duolingo expected AI feature costs to pressure gross margin as Max adoption expanded.

Sources:
- SEC FY25 10-K
- Reuters, 2025-02-27, Duolingo annual outlook / AI feature adoption

### MyeongHa implication

This reinforces a recurring conclusion from Kindroid:

```text
premium AI feature
!= automatically high-margin feature
```

Therefore MyeongHa must track:

```text
incremental revenue from premium experience
-
incremental compute cost
```

rather than celebrating premium-tier attach alone.

# 5. Free users can be rational even when payer share is minority

Duolingo publicly argues that free users contribute through:

- word-of-mouth acquisition;
- engagement/reengagement;
- experimentation data;
- long-tail future subscription conversion;
- advertising revenue.

This matters for MyeongHa because Pass 1/2 repeatedly worried:

> `What if free relationship users never pay?`

Duolingo shows that a minority-payer model can be structurally rational **when free users create measurable non-payment value**.

But MyeongHa cannot assume the same benefits.

Required proof:

```text
free relationship user
→ referral / organic acquisition value?
→ higher future conversion?
→ useful repeat engagement?
→ lower CAC?
→ ad/subsidy value if ads exist?
```

If none exist, free inference cost is simply subsidy.

---

# 6. Free experience must remain compelling

Duolingo's 2026 investor strategy explicitly says it is developing monetization while ensuring the free product remains compelling for the broadest possible audience.

Source:
- https://investors.duolingo.com/company-strategy-overview-0

This supports MyeongHa's existing principle:

> Do not deliberately make free Saju semantically wrong or free characters emotionally worse to force conversion.

Conversion should come from:

- depth;
- capacity;
- convenience;
- structured artifacts;
- richer experience;

not artificial corruption of the core product.

---

# 7. One product can support multiple monetization mechanisms without becoming incoherent

Duolingo combines:

```text
subscription
+ premium AI tier
+ ads
+ IAP consumables
+ one-time test product
```

This is a mature example supporting H-R18 `Layered Value Monetization`.

The mechanisms map to distinct user jobs rather than one currency controlling everything.

Possible MyeongHa analogy:

```text
relationship access
→ free/open layer

membership
→ recurring service bundle

premium compute
→ higher-cost experience

analysis rights
→ bounded inquiry unit

structured report
→ one-time artifact

ads
→ optional free-tier subsidy only if later validated
```

---

# 8. Important difference: Duolingo free usage is not equivalent to LLM chat

Do not copy Duolingo's freemium generosity directly.

MyeongHa ordinary conversation has marginal inference cost that can scale with engagement.

Therefore MyeongHa needs a stricter condition:

```text
free user lifetime value
= future payment
+ referral/acquisition value
+ optional ad/subsidy value
- inference/infra/support cost
```

Free relationship is rational only when this total is acceptable.

---

# 9. What Duolingo adds to Pass 3

Before this anchor case, H-R18 was mostly supported by cross-company pattern matching.

Duolingo provides one coherent public-company example where:

```text
free core
+ paid convenience
+ premium AI
+ consumables
+ ads
+ one-time high-value product
```

coexist at scale.

Therefore H-R18 becomes more credible as an **architecture pattern**.

It still does not tell MyeongHa which layers will convert.

---

# 10. Current takeaway

> **A free core can coexist with strong paid conversion, but only when the free layer creates measurable strategic value and expensive AI features are separately priced/controlled.**

For MyeongHa this means the core experiment remains:

```text
Does open relationship access create enough retention / referral / future conversion
relative to C_chat?
```

and separately:

```text
Can new grounded analysis / artifacts / premium experience monetize enough
relative to C_read / C_premium?
```

These two equations should not be blended.
