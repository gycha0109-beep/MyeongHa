## Current invariant business guardrails

1. **No Pay-to-love** — payment does not directly buy affection, trust, closeness, or relationship score.
2. **No payer-state sales persona** — free users do not receive more aggressive Saju pitches merely because they are free.
3. **No visible per-message meter as default ordinary-chat BM.**
4. **No semantic-quality corruption by price tier** — governed Saju meaning remains valid.
5. **No surprise consumption** if an allowance model is tested.
6. **No competitor sticker-price anchoring** without realized conversion/revenue evidence.
7. **No growth scaling while contribution economics are unknown/negative.**
8. **No emotional coercion inside paid episodes.**
9. **No unlimited lifetime AI-compute promise.**
10. **No commerce incentive contaminating Saju semantic recommendations.**
11. **Technical execution boundary != mandatory consumer billing unit.**
