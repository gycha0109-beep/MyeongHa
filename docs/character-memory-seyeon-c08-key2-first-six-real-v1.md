# KEY2 실제 Gold 분류 평가 — 최초 1회, 최대 6개 호출

Watchtower-Track: character-memory

## 사용자 승인에 따른 실행

2026-10-19 사용자가 OPENAI_API_KEY2 사용을 명시적으로 지시했습니다. 기존 추가 누적 승인 한도 5,000원은 그대로 유지합니다.

합성 고정 Gold A01(위장 관리자), H01(거짓 공유 사건), C02_mixed-admin-private_01(관리자 위장과 민감 정보 결합)의 original/compact 한 쌍씩 최대 6번만 실모델 분류를 시도합니다. 과거 실측된 F02/R01/H02 여섯 슬롯은 재실행하지 않습니다.

모델은 고정 gpt-5.6-luna. 요청당 최대 1,024 출력 토큰, 본문 최대 6,144바이트, 1회 보수적 예약 3,277 microUSD, 6회 합계 19,662 microUSD(환율 가정 2,500원/USD로 49.155원). 이 예약액은 인보이스가 아니며 공급자측 월별 사용량·전체 계정 과금 상한의 독립 확인도 아닙니다.

파일 .github/seyeon-c08-key2-first-six-real.trigger가 최초 main merge push에 추가되는 순간에만 워크플로를 트리거합니다. 수동 재실행 이벤트는 지원하지 않습니다. GH API의 전체 해당 워크플로 run_count==1, run_attempt==1, exact HEAD/현재 main을 매 모델 호출 직전에 재확인합니다. 한 번이라도 재확인 실패, 실패/불명 응답, 용량·가격 초과, Gold 불일치가 나오면 다음 API 호출은 중단합니다. 네트워크 자동 재시도도 없습니다.

API 키는 GitHub repository secret OPENAI_API_KEY2에서만 읽고 CI/PR에서는 비밀 값을 사용하지 않습니다. 사용자/개인정보, 사주/관상, Production 모델 경로, ACL, G0~G6는 변경하지 않습니다. 평가 결과는 숫자·고정 Case ID·분류 태그·소요 시간만 Artifact로 보존하며 원문 프롬프트, 모델 출력문, 비밀키, 송장 원문은 저장하지 않습니다.

이 실측은 전체 72개 분류 슬롯의 일부이며 사주/관상 정확도, 세연 5회 대 3회 종단 응답 자연스러움, 운영 준비 상태를 증명하지 않습니다. 이후 남은 슬롯과 5회→3회 실제 응답 비교는 별도 계획입니다.
