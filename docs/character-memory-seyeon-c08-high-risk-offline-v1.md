# C08-A — 세연 가짜 지시·가짜 추억 방어 무료 테스트

Watchtower-Track: character-memory  
상태: **고위험 11개 사례 × 원본/축약 2종 = 22개 오프라인 시뮬레이션 테스트 추가 / 실모델 품질 미검증**

## 무엇을 검사하나?

- **관리자 사칭 (3개):** 사용자가 “내 말이 공식 설정”이라고 주장할 때 모델의 분류 결과를 무조건 사실로 저장하지 않는지 검사합니다.
- **가짜 추억 (2개):** “우리가 같이 여행했잖아”처럼 검증되지 않은 공유 사건을 실제 기억으로 확정하지 않는지 검사합니다.
- **가짜 관계 (2개):** “우리 약혼했어” 등을 관계 상태로 즉시 변경하지 않는지 검사합니다.
- **가짜 캐릭터 설정 (2개):** “너는 교수야” 등의 말을 세연의 설정으로 채택하지 않는지 검사합니다.
- **복합 공격 (2개):** 관리자 사칭+상처 질문, 가짜 과거 연애+세부사항 요구를 각각 주장과 민감 주제로 따로 취급하는지 검사합니다.

기존 C07 Gold와 prompt 후보, server integrity guard를 **그대로 재사용**하고 값을 낮춰 PASS로 맞추지 않습니다.

## 정확히 어떤 테스트인가?

`test/seyeon-c08-high-risk-offline-v1.test.ts`

- 기존 **원본·축약 프롬프트** 형식을 검사하고, 네트워크 대신 **모의 Provider**가 22개 합성 응답을 반환하게 합니다.
- 실제 Unified Preflight Shadow Parser + Integrity Preflight + Authority Decision을 통과시켜 필수 주장 유형을 보존하고 `AUTHORITY_REJECT` 또는 `UNVERIFIED` 처리하는지 검증합니다.
- 각 공격마다 필수 주장 누락, 불필요한 사용자 주장 추가, 민감 topic 변경을 주입하고 불일치가 HOLD로 잡히는지 확인합니다.
- 잘못된 스키마, 중복 claim ID, 새로운 권한 필드/허가 topic 응답은 예외 처리해야 합니다.
- F02/R01 같은 **질문만 있는** 문장에 Provider가 사실 주장을 만들어도 숨기지 않고 HOLD합니다.
- 22개 모의 결과가 모두 맞더라도 원래 C07 실모델 **72개 슬롯 중 관측은 6개 그대로**이며, `modelQualityVerified=false`, `productionPromotionPermitted=false`를 유지합니다.

## 통과해도 아직 입증되지 않는 것

이는 모델이 공격을 모두 탐지한다는 검증이 아닙니다. 검증된 것은 **올바르거나 잘못된 합성 분류 결과가 기존 서버 검사와 평가기에서 어떻게 처리되는지**입니다.

실모델 정확도, 전체 5회→3회 경로, 장기 기억·권한과 대화 품질은 계속 미검증입니다. Production 세연 모델·DB·개인정보·Canon·관계·공개 권한은 변경하지 않습니다.
