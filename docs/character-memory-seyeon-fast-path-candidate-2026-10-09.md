# 세연 통합 사전 분류·일상 대화 Shadow 후보 (2026-10-09)

Watchtower-Track: character-memory

## 권한 경계
- PR에는 **실행 경로의 후보 모듈과 합성 테스트**만 추가한다. Production turn-send, 라우팅 ENV, DB, 관계·기억·Canon·Saju 권한은 변경하지 않는다.
- Unified 후보는 기존 Shadow의 합성 100건 분류 실험에서 출발하지만, 실제 장기 대화 및 공개 심도 허가를 검증한 것은 아니다.
- 후보 분류기를 한 턴 범위로 메모이제이션해 Integrity·Disclosure 분류 두 책임에서 **동일한 API 결과**를 재사용한다. 두 권한 판정은 기존 서버 resolver/gate를 **그대로 실행한다**.
- 통합 사전 분류의 분류 오류, 스키마 오류, 메시지 혼용은 실패를 삼키거나 결론을 보정하지 않고 실패 처리한다.

## 저위험 통합 대사 Shadow
- 첫 만남, null 관계·의미 오버레이, 공개 질문, 민감정보/주장/회상 근거가 없는 **매우 제한된 후보**만 평가한다.
- 하나의 모델 응답으로 interpretation + draft를 받아 먼저 **서버 해석 가드·행동 인과성 가드·Renderer Draft 입장 가드**를 적용한다.
- 그 뒤 기존 독립 의미 검증 모델을 호출하고 최종 Output Guard를 통과해야 후보 결과를 생성한다.
- 지원하지 않는 입력이나 구조/의미 검증 오류는 즉시 거부한다. 결과는 `SHADOW_ONLY_NOT_PRODUCTION`이며 사용자 응답으로 전송되지 않는다.

## 활성화 보류 기준
1. 기존 권한/Disclosure 결과의 동등성 검증을 더 늘려 민감 질문과 허위 공유 기억을 포함하는 최소 300건에서 탐지 누락 0건 검증.
2. 다중 턴 일반 대화에서 첫 인사/가벼운 상태 공유/대화 속도/의견/현시점 욕구 등 세연 특성 및 오류율 비교.
3. Shadow 의미 검증 모델에 대한 실제 호출 P50/P95, 비용, 거부율 추적 및 기존 경로 대비 비열등성 확인.
4. 캐릭터 품질 및 무결성 검증 전에는 Production 적용, 라우팅 기본값 변경, 새로운 자동 재시도 수행 금지.

## 비고
- 이번 후보 모듈은 외부 호출·DB 쓰기·스케줄러를 스스로 시작하지 않는다.
- 3회 구조는 **추가 검증이 필요한 설계 목표**이지 달성된 운영 성능이 아니다.
