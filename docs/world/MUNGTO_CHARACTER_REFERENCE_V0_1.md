> 상태: **PO APPROVED WORLD CULTURE / CHARACTER INTEREST REFERENCE / NOT PRODUCTION ASSET**
> 승인 근거: 사용자가 뭉토의 취미·세계관 설정을 승인하고, 2026-10-22에 양쪽 귀가 바닥에 끌리는 최종 디자인 시트를 제공하여 저장소 기록을 요청함.
> 적용 범위: 명하 대중문화에 존재하는 캐릭터 **뭉토**와 강태겸의 개인 취향. 실제 상표 등록·제품 출시·계약·생산 사실을 주장하지 않는다.

## 1. 명하 세계 안에서의 뭉토

- **뭉토**는 명하 세계에서 널리 알려지고 사랑받는 귀여운 **토끼 캐릭터**다. 강태겸을 위해서만 존재하는 캐릭터가 아니다.
- 팬 상품 중 프라모델·조립형 피규어 같은 제품군이 존재한다는 창작 설정을 채택한다. 실제 상품의 브랜드명·공급사·출시 연표·가격은 미정.
- 성격: 뭔가 하려고 일어났다가 무엇을 하려 했는지 까먹고, 잠시 멍하니 있다가 다시 주저앉는 느슨하고 하찮은 토끼.
- 격구나 명(命), 守의 의인화가 아니며, 태겸의 트라우마를 치유하기 위해 만들어진 상징도 아니다.

## 2. 외형 기준 — 2026-10-22 사용자 선택 디자인

- 전체적으로 크림색·연분홍·연갈색의 **단순한 2D 파스텔 일러스트**.
- **양쪽 귀가 같은 길이로 아주 길게 늘어져 바닥에 끌린다.** 귀 길이 비대칭 버전은 폐기한다.
- 둥글고 말랑한 몸통, 작은 팔다리, 양볼의 분홍빛 홍조.
- 동그란 점눈, **작게 벌린 ‘ㅇ’ 형태의 입**, 배 중앙의 **작은 갈색 배꼽 점**.
- 서 있는 정면/측면/후면, 엎드린 형태, 멍한 표정과 무언가 까먹는 짧은 행동이 기준 디자인 시트에 포함된다.
- 후속 이미지에서는 이 시각적 특징을 유지하되, 표현상 추가 장식이나 상품 변형은 별도 제안으로 다룬다.

## 3. 강태겸과의 관계

- 강태겸은 **뭉토 자체를 귀여워해서 좋아한다.** 자신만의 취미로 뭉토 굿즈를 수집하고 특히 **조립형 피규어/프라모델을 직접 조립**하는 것을 즐긴다.
- 숨겨야 할 약점이나 부끄러운 비밀로 취급하지 않는다. '의외네요'라는 반응에 **'귀엽잖아요. 안 귀여워요?'** 하고 담담히 대답할 수 있다.
- 이 취향을 격구 분석, 경기력, 守, 성취욕에 억지로 연결하지 않는다. 평범하게 귀여운 것을 좋아하는 사람의 취미다.
- 대중적으로 유명한 캐릭터이므로 그의 취미가 곧바로 엽기적이거나 희귀한 취미가 되는 것은 아니다.
