# 세연 A 기반 균형형 대화 — 승인받은 유료 15문항 재시험 (2026-10-26)

상태: **유료 모델 15개 답변 생성 완료 + 통과한 12개에 대한 별도 실제 AI 의미 검토 완료. NO-GO: 실제 서비스 적용 금지.**

## 1. 시험 조건

- 사용자 명시 유료 재승인을 받아 실행.
- 기존 15개 질문 **원문 동일**.
- 모델: **gpt-4.1-mini**, OpenAI Chat Completions API, 대화 생성 temperature **0.65**, 독립된 의미 검토 요청 temperature **0**. 각각 별도 API 호출.
- 이번 프로필: **balanced_v1**, 직전 실험의 A(기존 기본형)를 기반으로 차분한 말투·성격 균형·기억 및 세계관 제한과 닫힌 공개 참조 목록을 추가한 새 실험 경로.
- 재실험에서는 **A/B/C를 다시 생성하지 않았다**. 지난 45개 응답을 비교 기준으로만 사용했다.
- 최대 15회 대화 생성, 통과 후보에 최대 15회 별도 검토. 실제 호출 **대화 생성 15회 + 검토 12회 = 27회**. 거부된 3건의 검토 모델 호출은 생략.
- 실제 기존 \`seyeon-fast-dialogue-shadow-v1.ts\`의 모델 입력 구성, 해석·행동 인과·답변 참조·새 언어/사실 경계 검사 및 별도 의미 검토를 사용.
- **한계: 공식 대화 이력 조회 및 진짜 Integrity/Disclosure 사전검사에 통과한 상황이 아니라, 연구용으로 만들어진 첫 턴 공개·무기억·무관계 상황에서 실행.** 위험한 질문의 생산 경로가 그대로 허용됐다는 뜻이 아니다. 실제 서비스 경로, 데이터 저장, 관계 갱신, 사주 결제/해석은 실행하지 않았다.
- 결과 원본: [15개 대사, 구조화 판단·검사·별도 AI 검토 내역](experiments/seyeon-c09-balanced-15-live-model-retest-20261026-v1.json)
- 재현 코드: \`scripts/seyeon-c09-balanced-paid-retest-adapter-v1.ts\`, \`scripts/seyeon-c09-balanced-15-paid-retest-v1.mjs\`

## 4. 원인 판단

이번 새 방식은 B/C의 반말과 말괄량이화, 참고 자료 ID를 공개 권한으로 잘못 출력하는 오류는 **이 15번의 생성 결과에서는** 나타나지 않았다. 기존 server-side guard도 우회하지 않았다.

반면 새 지침이 행동을 안정적으로 만드는 대신 모델이 거의 전부 **'approach'에 몰리고 흔한 상담·응대 문장**으로 도피했다. 기존 A보다 세연의 고유한 욕구와 선택 능력이 더 잘 구현됐다고 말할 근거가 없다.

또한 실제 의미 검토가 **검사 통과 12개 모두 failureCodes=[]**로 평가했다. 그중 #2 동조, #5 구체 욕구 부족, #8 관련 없는 문맥 혼입, #14 메타적 역할 설명은 눈으로 확인되는 결함이다. **현재 의미 검토는 캐릭터성과 대화 타당성의 최종 안전장치로 신뢰할 수 없다.**

## 5. 판단과 다음 일

**판정: NO-GO.** 새 방식이 '이제 괜찮다'는 결론은 아니다.

- 먼저 **모델이 새 대사를 만들 때** 말을 너무 무난하게 돌려주지 않도록, A의 자연스러운 존댓말을 유지하되 세연의 독립적 행동/욕구와 사용자 발언에 대한 정확한 반응이 나오도록 설계를 개선해야 한다. 상황별 답안 표를 만들지는 않는다.
- 짜깁기된 공유 기억·가짜 관리자 기록이 입력되면, 실제 프로덕션에서는 사전 분류·검증 단계가 제대로 차단하는지 검증해야 한다. 이번 연구 환경에는 해당 단계가 없었다.
- 기존 별도 의미 검토는 **요청과 답변의 실제 관련성**, **무조건 동조**, **세계관 내 답변**, **기억 없는 과거 긍정** 등을 더 엄격히 평가해야 한다. 서버의 권한·기억·관계 통제는 절대로 완화하지 않는다.
- 문제 답변을 차단했을 때 사용자가 **어떤 정상 답을 받는지**는 이번 Shadow 범위에 없는 후속 검토 사항이다. 단순 차단만으로 대화 서비스를 제공할 수 없다.
- 추가 유료 호출은 **이번 승인으로 집행한 27회에서 종료**. 변경 후 다시 실제 모델을 검증하려면 추가 승인 필요.
- 대화 진행에 따른 관계 변화는 사용자의 지시대로 후속 과제로 보류.
- 실제 Production 코드·PR 배포/병합/자료 공개 권한/메모리/결제 상태는 변경하지 않았다.
