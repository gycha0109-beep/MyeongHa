# 공식 Reader 사주 근거 보존을 위한 비공개 출처 후보 v1

- 기준 문서: `OFFICIAL_READER_PAID_CHAT_INTEGRATION_ROADMAP_20261012_V1.md`, Reader RR-02/03/06/09, DB #1884.
- 상태: **서버 내부 출처 후보 구현·부정 시험 / 최종 사주 출처 저장 권한·유료 답변 공개 권한 아님**.
- 외부 API, 데이터베이스 권한, 기존 세연 일반 채팅 경로, 모델 공급자 및 결제 계약 변경 없음.

## 1. 입력 신뢰 경계

`prepareOfficialReaderSajuSourceCandidateV1`은 `CharacterStandardChatGroundingV2`의 서버 발행 실물 객체만 받는다. `assertServerPreparedStandardChatGroundingV2`가 실제 서버 내부 발행 집합에서 동일 객체를 확인하므로, JSON·브라우저·AI 모델이 복제한 `grounding_unit_*` 자료는 허용하지 않는다.

서버가 확인한 공식 사주 결과의 Reading ID, Reader, 회원·채팅방, Release/Bundle, 버전, 사주 원본 해시·근거 해시를 결속한다. 호출자가 고른 임의 텍스트는 출처가 아니며 초점은 실제 사주 Unit 식별자여야 한다.

## 2. 근거 범위의 완전성

기존 `closeCharacterStandardReaderSourceFocusV1`를 재사용한다. 초점 Unit을 기준으로 Saju 소유의 필수 동반 Unit 전체, 전역 주의·공시 설명, 계산 불확실성 근거를 폐포로 계산한다.

- 허용된 실제 근거 Unit 1~12개, 중복 불허, 초점 포함.
- 원본의 전역 disclosure/ambiguity는 일부 설명 단위와 직접 연결되지 않아도 모두 유지.
- 원본이 표시 의무를 가진 불확실성을 안전하게 일반화할 수 없다면 `protectedOnly` 기록 유지.
- 초점 불명확 또는 근거 수 제한 초과는 새 답변 후보를 발행하지 않고 `hold`한다.
- 결과 구조의 `sourceCandidateHash`는 *동일 후보의 변경 감지*용이다. 서명이나 DB가 독립 검증한 원본 출처 증명으로 해석하지 않는다.

## 3. 명시적 미완료 사항

- **의미 보존 검증과 출력 검증은 이 함수 안에서 하지 않는다.** 승인된 Reader 생성/검증기의 성공 결과와 실제 생성된 발화 해시를 이후 동일한 저장 시도에 결속해야 한다.
- 서버 메모리의 `WeakSet`은 같은 프로세스 내 객체 위조 차단 도구일 뿐, **데이터베이스에 저장할 수 있는 출처 발행자 증명은 아니다.** 해당 증명은 Saju·DB 소유 계약을 별도로 구현해야 한다.
- T2에서 현재 구매권, 환불, 공식 원본, 상품 규칙, Release/Bundle/Revision 및 해당 해설 요청의 생존 여부를 다시 확인해야 한다. 과거 서버 내 발행 객체만으로는 최종 권한을 인정하지 않는다.
- RR-03 저장 틀(#1960)과 RR-04 비공개 조회(#1974)는 실제 검증된 유료 본문과 아직 원자적으로 결합되지 않았다.
- 이 변경 요청은 **거짓·복제 입력 거절에 대한 단위 시험**까지만 포함한다. 실제 발행된 Grounding을 검증된 Semantic/Output 결과, DB Writer, 실제 구매권에 연결하는 양성 종단 간 시험은 별도 납품 조건이다.
- 운영 DB의 마이그레이션 충돌 1720 및 누락된 과거 이력 1400~1450을 본 변경으로 해결하지 않는다.

## 4. 완료 조건과 후속 작업

1. 코드 유형 검사 및 구조 위조 부정 시험 통과.
2. 실제 공식 Saju 발행 Grounding→선택 근거→의미 검증→출력 검증을 같은 호출자 신뢰 경계로 결합하고 서버의 출처 발행 증거를 추가.
3. DB Owner가 승인한 최신 권한 T2와 동일 거래로 출처·실제 발화·시도·메시지 저장.
4. 환불·삭제·복원·출처 변조·중복 생성 경합에서 신규 유료 본문 공개 0 검증.

이 네 단계 전에는 `source_candidate`라는 이름을 부여했더라도 **공식 답변 저장 성공 또는 공개 근거로 승격할 수 없다.**
