- [ ] **공식 사주 결과 연결:** [사주 엔진 #2410](https://github.com/gycha0109-beep/Saju/issues/2410)의 실제 운영용 출처 증명을 기존 사주 결과·근거·버전과 연결합니다. 시험용 서명이나 임의 생성 출처만으로는 유료 해설을 열지 않습니다.
- [ ] **개인정보 보호·복구 연결:** [개인정보 #2318](https://github.com/gycha0109-beep/MyeongHa/issues/2318)의 승인된 정책에 맞춰 암호화된 유료 해설 저장, 환불 후 재열람·AI 기억 차단, 탈퇴 삭제, 오래된 백업 복원 후 재노출 차단을 실제 삭제·복구 경로에 연결합니다.
- [ ] **해설 저장과 채팅 열람 연결:** 기존 단일 채팅방을 유지하고, 저장 직전에 구매권과 공식 출처를 다시 확인합니다. 모든 기록이 함께 저장된 뒤에만 원문을 공개하며, 후속 질문도 현재 권한으로 다시 확인합니다.
- [ ] **사용자 전달·환불 기록 연결:** 화면 제공과 사용자 수신 확인을 구분하고, 중복 전송·네트워크 장애·환불 뒤에도 필요한 비민감 기록만 남깁니다.
- [ ] **운영 DB 변경 준비·적용:** [운영 DB 복구 #1887](https://github.com/gycha0109-beep/MyeongHa/issues/1887)의 누락된 변경 이력 원인과 백업·복구 근거를 해결한 뒤 정해진 절차로 실제 변경을 적용합니다. 이력에 대한 근거 없는 임의 수정은 하지 않습니다.
- [ ] **최종 E2E 테스트:** 결제 → 권한 발급 → 공식 사주 기반 해설 → 저장·열람 → 새로고침·후속 질문 → 환불·차단까지 연결된 흐름을 시험합니다. 별도 구매권, 위조·중복 이벤트, 동시 처리, 다른 회원 접근, 삭제·백업 복원, 전달 장애도 포함합니다.

## 완료 및 삭제 기준

- **최종 판정:** 실제 연결 환경에서 위 E2E 시나리오가 통과하고, 공식 출처·개인정보 삭제/복구·운영 DB의 필수 근거가 갖춰진 상태. 코드 존재·부분 CI 통과만으로 완료 처리하지 않습니다.
- **사용자 사전 승인:** 이 작업 범위의 운영 적용·서비스 공개에 관한 제품 결정은 2026-10-23 사용자 요청에 따라 미리 승인된 것으로 기록합니다. 다만 필수 기술·법적 조건, 운영 접근권과 근거가 충족되기 전에는 실제 유료 결제와 사용자 공개를 하지 않습니다.
- **정리:** 완료 증거를 기존 PR·이슈 및 필요 시 기존 정식 문서에 남기고 **이 임시 로드맵 파일은 Git에서 삭제**합니다. 미완료 중에는 삭제하지 않습니다.
