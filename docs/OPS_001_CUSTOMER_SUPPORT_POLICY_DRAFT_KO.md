# OPS-001 명하 고객지원·민원 대응 운영안 v0.1

> 2026-10-13 / 내부 운영 초안 / 게시·상담 채널 및 응답 SLA 미승인
> 목적: 무료 베타와 추후 유료 사주 해설의 이용자 문의를 합법적이고 재현 가능하게 접수·처리한다.

## 1. 문의 유형과 최소 처리 정책

| 유형 | 접수 후 분류 | 원칙 | 실제 운영 준비 |
|---|---|---|---|
| 계정·로그인 | AUTH | 본인 권한 검증, 타인 계정정보 미노출 | 본인확인/복구 경로 검증 |
| 사주 결과 오류 | READING | 입력정보 오류/계산 장애/AI 표현 문제 분리 | 오류 재현에 필요한 최소 기록만 사용 |
| AI 캐릭터 신고 | CHARACTER | 유해 표현·개인정보 노출·사칭·악성 입력 신고 | 신고·차단·재발방지 경로 |
| 개인정보 | PRIVACY | 열람·정정·삭제·처리정지 등 법정 권리 행사 접수 | 개인정보 보호 담당자·절차·실행 게이트 |
| 결제·환불 | COMMERCE | 미제공/오결제/하자/단순 변심/부분 미제공 구별 | PG 계약 및 실제 구매 활성화 후만 적용 |
| 장애·접근불가 | INCIDENT | 오류 규모와 거래 영향 확인 | 공지·복구·사후 대응 |

## 2. 기본 접수·처리 순서
접수 → 사건 종류 분류 → 본인확인 필요성 판단 → 최소 증빙 확보 → 법률·제품 정책 확인 → 처리 및 결과 통지 → 법정 보존기간에 따른 보관/삭제.

- 모든 신고에 계정 비밀번호, 전체 주민등록번호, 결제 카드번호, API 비밀키, 전체 대화 이력을 요구하지 않는다.
- 로그·대화·생년월일은 문제 해결에 필요한 항목만 접근하고, 업무 목적 밖 사용을 금지한다.
- 문의 메일/헬프센터는 **실제로 운영·모니터링 가능한 채널만** 공개한다. 연락처 후보를 임의로 생성하지 않는다.
- 법정 환급·청약철회 처리 기한은 서비스 자체 '영업일 목표'가 아니라 관련 법률이 우선한다.
- 소비자에게 제공되지 않은 가분적 디지털 콘텐츠까지 일괄 환불 제한하지 않는다.
- 원인을 확인하지 않은 AI 답변 내용을 ‘계산 오류’로 단정하지 않는다.

## 3. 사전 구현·검증 체크
- [ ] 고객지원 대표 이메일/문의경로 실제 수신 테스트
- [ ] 개인정보 권리행사 경로 및 처리 담당자
- [ ] 캐릭터 신고 접수·이의 신청
- [ ] 가입·탈퇴·계정복구 안내
- [ ] 공지/장애 안내 동선
- [ ] 유료 오픈 후 주문·결제·해설 제공·환불 증빙 분리조회
- [ ] 보존기간·접근권한·개인정보 마스킹·감사로그
- [ ] 환불 신청·계정 삭제가 구매보다 부당하게 복잡해지지 않도록 UX 검증
- [ ] 연락처, 영업시간, 일반 응답 목표(권장), 긴급사고 연락체계 별도 확정

## 4. 승인 분리
- 무료 공개 준비에 필요한 기본 문의 및 개인정보 권리행사 경로는 무료 오픈 전 검증.
- 실결제 환불 채널은 상거래 개시 전 추가 준비.
- 현 문서는 공개 FAQ/이용약관/개인정보 처리방침 문구를 자동 승인하지 않는다.
