# 명하 최초 상용 출시 범위 및 로드맵 분류 정본 — 2026-11-13

> 상태: **제품 소유자 범위 결정 확정 / 실행·판매·운영 배포 미승인**.
> 용도: 기존 트랙 로드맵의 *최초 출시 필수 / 상품별 필수 / 출시 후 개선*을 판별하는 공통 기준. 각 트랙의 기존 구현 이력·증거·안전 보호를 삭제하거나 완료로 승격하지 않는다.
> 명시적인 이번 결정에 포함되지 않은 기능은 임의로 출시 필수로 추가하지 않는다. 기존 별도 제품 승인 결정과 충돌하면 그 결정과 차이를 확인한다.

**로드맵 실행·중복 검증·출시 후 검증의 현재 단일 분류표:** [2026-11-14 통합 게이트](LAUNCH_ROADMAP_CANONICAL_GATE_MATRIX_20261114.md). 이 문서는 **제품 범위 결정의 정본**이고, 통합 게이트는 실제 트랙별 완료 선후관계의 정본이다. 같은 작업의 상세 검증 요건을 이 문서에 반복 추가하지 않는다.

## 1. 제품 소유자의 확정된 최초 출시 기준

1. **사주:** 2026-11-06 승인 카탈로그에 포함된 14개 구매 상품 **모두** 최초 출시 목표. 상품 중 일부만 판매하는 부분 출시를 최종 성공으로 인정하지 않는다.
2. **플랫폼:** 웹 우선. 네이티브 모바일 앱 배포, 모바일 전용 OAuth/Push·앱스토어 결제는 최초 웹 출시의 선행조건이 아니다. 웹이 모바일 브라우저에서 정상 동작하는 기본 사용성은 웹 품질 검사 범위에서 판정한다.
3. **캐릭터:** 세연·라현·백헌·여울·윤호·태겸 **6명을 동시에 공개**. 서린·미라·도윤은 차후 확장 대상. 9명 전체 배포를 최초 출시의 별도 필수 조건으로 요구하지 않는다. 다른 세 캐릭터의 기존 승인 자료·역사는 보존한다.
4. **구매 후 Reader:** 공식 구매 풀이의 보호된 열람·재열람과 기본 첫 질문·후속 질문 제공. 실제 상품·캐릭터·정확한 Reader 권한 및 개인정보 보호를 유지한다. **2026-11-14 추가 승인:** 최초 공개하는 6명 모두가 정식 구매 풀이의 Reader로 함께 제공되어야 한다. 단, 상품별/Reader별 지원 가능한 풀이 범위와 독립 권한·정식 콘텐츠·모델/Guard·실제 발급 검증을 모두 통과해야 하며 미지원 조합은 명시적으로 차단한다. 6명 전원 공개는 권한 검증 우회나 자동 유료 자격 부여를 뜻하지 않는다.
5. **사주 연구:** 상품별 내부 채택 규칙·계산·한국어 해석·정식 서명 발급이 실제로 검증되면 해당 해석의 준비 판정 가능. 외부 전문가나 추가 학술 승인 자체는 출시 조건이 아니다.
6. **품질:** 기존 Saju 7단계의 **500명 품질 개선과 확대 검증은 반드시 최초 출시 전에 완료**한다. 임의로 출시 후 개선으로 이동하지 않는다.
7. **출시 방식:** 위 선택 범위의 필수 기능과 안전·운영·법적 조건이 모두 충족될 때 **웹에서 한 번에 공개**. Preview/격리 CI/부분 배포는 출시 완료가 아니다.

## 4. 상품별 필수 (상품·캐릭터 특화 게이트)

- **사주 원국 4개:** 각 판매 구성의 실제 해석 규칙/고객 문단, 500명 관련 품질 결과, Signed Official Reading/보관/Reader 권한·환불을 검증.
- **연·월운 2개 및 해당 묶음:** 서울 선택 기간·입춘/절입 전후·대운/세운·구간별 한국어 판단, 정확한 구매 기간에 묶인 서명·Reader 재열람. [Saju #2762](https://github.com/gycha0109-beep/Saju/pull/2762) / [명하 #3174](https://github.com/gycha0109-beep/MyeongHa/pull/3174).
- **관계 비교 3개:** 두 명식별 내부 해석 의미·고객 문단, 정확한 상대·구매·동의/철회·신원/서명·첫 상대/추가 상대/본인+첫 비교 발급·재열람. [Saju #2763](https://github.com/gycha0109-beep/Saju/pull/2763). 500명 **원국 8메뉴 검사에는 궁합이 포함되지 않으므로**, T10 고유 5단계와 실제 관계 입력 검사는 별도로 필수다.
- **묶음 5개:** 이미 승인된 포함 구성요소의 중복 발급 없는 결합, 정확한 가격·구매 권리·실패 회복·환불. 세부 상품의 완료가 묶음 전체 E2E를 대체하지 않음.
- **캐릭터 여섯:** 각각 승인된 Character Source/Content Release, 독립 채팅 실행·출력 보호·웹 실제 송수신. 특히 **윤호**는 기존 실행 선택에서 제외된 상태이므로 승인된 개별 배포/실행 경로 구현·검증이 추가 필수다.
- **Reader 자격:** 여섯 캐릭터의 채팅 공개와 각 캐릭터의 유료 Reader 자격은 구별한다. 첫 출시 6명 **모두**에 대해 정식 Reader 실행·권한·공식 풀이 불변성·기본 질문/후속 질문을 통과시킨다. 캐릭터별 미지원 상품/구성요소는 명시하고 다른 캐릭터의 권한을 추정하지 않는다.

## 5. 최초 출시 이후로 분리 (기존 프로젝트 목표 보존)

- 네이티브 Android/iOS 앱, 모바일 전용 로그인 딥링크·Push·앱스토어 결제 및 모바일 스토어 공개: 웹 최초 출시 후.
- 서린·미라·도윤의 추가 캐릭터 공개 및 **9명 전체가 필요한 집합 배포/일괄 차별화 검사**: 최초 6명 독립 배포가 안전하게 가능함을 검증한 경우 최초 출시 이후. 기존 9명 원본·승인 기록은 유지.
- 여울 등 캐릭터별 GEPA 최적화·전 캐릭터 블라인드 차별화 향상·선택적 장기 기억 자동 추론 및 확장형 개인화: 기본 6명 채팅 품질·안전 충족 후 개선. 단, 실제 출시에 사용하는 모델의 필수 응답 품질·예산·보안 검증은 연기 불가.
- Reader의 **기본 구매 풀이 열람 + 질문** 외 확장형 표현·다수 Reader 간 고급 비교/관점 차별화. 해당 확장 없이도 승인된 기본 기능이 안전하게 제공되는지 확인.
- 명시적으로 선택되지 않은 관상 기능: 이번 결정을 근거로 첫 출시 필수라고 **새로 단정하지 않는다**. 기존 관상 독립 로드맵도 취소·완료 처리하지 않는다. 다른 확정 제품 결정에서 최초 출시 필수로 정한 증거가 발견되면 충돌로 기록하여 제품 소유자 결정에 따름.

**주의:** 기술적 개인정보·암호화·회수·복구 및 실제 결제 안전성이 필요하다면, 그것을 '출시 후 개선'으로 재분류해서는 안 된다.

관련 이슈와 다른 트랙 로드맵에는 **기존 원인이 현재에도 남았는지** 확인한 후 수정/정정한다. 단순히 문서에 적혀 있다는 사실만으로 현재 구현 전체를 차단하거나, 문구 교체만으로 안전 게이트를 제거하지 않는다.

## 7. 진행·출시 판정 규칙

1. 개별 트랙의 `ROADMAP_COMPLETE`와 **전체 웹 최초 출시 가능**은 서로 다른 값. 각 트랙의 필수 작업을 삭제하거나 임의 추가하지 않는다.
2. 최초 출시 조건을 만족하려면 **14개 모두 + 6명 모두 + 웹 기본 Reader + 500명 확대 검증 + 운영/결제/개인정보/법적 조건**이 증거로 완료돼야 한다. 일부 완료를 전체 완료로 계산하지 않는다.
3. 모든 상품·캐릭터가 출시 준비를 마쳐도 운영 DB 변경, 상업 호스팅/PG 계약, 실제 고객 데이터 처리·모델 관련 필요한 외부 조건이 해결되지 않았다면 전체 판매 HOLD.
4. 이미 완료·병합·검증된 부분은 증거를 재사용한다. 기존 로드맵에 없는 기능을 '출시 품질' 명목으로 추가하지 않는다.
5. 문서 갱신은 정책 결정 기록이지 판매 플래그·실거래·Production 권한 변경 승인이나 실제 캐릭터 게시 허가가 아니다. 현재 안전 차단은 적용된 검증을 통과할 때까지 유지.
6. 진행 보고는 **한 것 / 남은 것 / 다음에 할 것 / 블로커 및 승인사항**의 짧은 한국어로 작성하고, 단계별 막대는 실제 증거로 상태를 표시한다. 확인되지 않은 완료율 금지.
