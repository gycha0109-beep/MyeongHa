# 여울 GEPA 500원 장부 — 파일럿 전체 청구 불명·우회 차단 v1

> 2026-11-12 · 캐릭터 최적화 연구 트랙 · **합성 비용 검증만** / 실모델 요청·충전 없음

## 확인한 결함

이전 원화 장부는 여러 실행을 합쳐 500원 한도를 계산했지만, **추가 예약 전 검사** 중 두 조건은 현재 실행 ID만 확인했다.

1. 다른 실행 ID에서 원화 장부를 거치지 않은 USD 전용 예약을 생성하면 현재 실행이 이를 발견하지 못한다.
2. 다른 실행에서 과금 불명(HOLD)이 발생해도 현재 실행은 새 요청을 예약할 수 있다.

이는 하나의 파일럿에 여러 실행·역할이 참여한다는 승인된 500원 상한 계약과 다르다.

## 실제 변경

- YeoulKrw500SyntheticLedger는 같은 연구용 SQLite 파일 안의 **전체 USD 예약 건수**와 고정된 파일럿 ID의 KRW 예약 건수를 한 거래 안에서 대조한다. 보호되지 않은 예약이 하나라도 있으면 새 KRW 예약을 거부한다.
- 각 실행의 청구 불명 검사는 그대로 두되, **파일럿 ID에 연결된 어느 실행에서든** 과금 불명이 하나 이상 발견되면 모든 후속 KRW 예약을 중지한다.
- 기존 예약은 삭제하거나 반납하지 않는다. 정상 정산된 다른 실행은 계속 사용할 수 있지만, 예산 상한을 벗어나는 호출은 여전히 거부된다.
- krw_status()는 파일럿 전체 보류 건수, 장부를 거치지 않은 USD 요청 존재 여부, 두 조건이 모두 충족됐는지만 별도로 반환한다. 이 값은 **결제 송신 허가 또는 실제 청구 검증이 아니다**.
- 가상 테스트: 다른 실행의 HOLD, 다른 실행의 USD 전용 우회, 보호 예약 이후 생긴 우회, 다른 실행의 정상 정산.

## 경계

- 이 장부 파일은 **여울 GEPA 파일럿 전용**이라고 전제한다. 다른 사업/실험과 원장을 혼합하면 예산 검증을 보수적으로 중단한다.
- 별도의 SQLite 파일을 만들거나 API 키·결제 수단을 갈라서 호출하는 행위, 실제 제공업체가 지연 청구하는 비용을 이 코드만으로 막을 수 없다.
- 요금·환율·수수료·선불 크레딧의 진위와 실행 권한은 연결되지 않았다. 사용자 결정 **총지출 500원**은 유지하지만 새 크레딧 구매/자동 충전 및 유료 송신은 계속 금지한다.
- 실제 여울 대화 288건, 사용자 검토 후보 30건, 비공개 홀드아웃, 운영 캐릭터 모델 및 Canon/기억/관계/사주를 변경하지 않는다.
