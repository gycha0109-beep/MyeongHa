## 구현된 기능

- Python 연구 모듈: research/character-optimization-gepa/krw500_synthetic_ledger.py
- 기존 GovernedBudgetLedger의 SQLite BEGIN IMMEDIATE 예약에서 **원화 한도 검증과 달러 예약 기록을 하나의 트랜잭션에 포함**하도록 연구 확장 지점을 추가한다.
- YeoulKrw500SyntheticLedger는 파일럿 ID를 고정하여 **같은 지속 DB 안의 복수 run_id** 간 누적 500원을 공유한다. 각 학생/반사/심사/최종평가 역할과 재시도를 독립 호출로 원 단위 올림 후 합산한다.
- 사용자 한도: KRW 500 고정. 환율은 1달러당 milli-KRW 단위의 **합성 상한 입력**, 기타 고정 수수료도 **합성 상한 입력**으로서, 정식 환율·수수료 검증이 아니다. 수수료 상한은 파일럿 전체에서 한 번 차감한다.
- 기존 달러 합계·호출 횟수·동시 요청·요청 중복·정책 해시·청구 불명 HOLD 조건도 유지한다. 원화 정책/환율/수수료를 실행 중 변경하면 DB 기록과 비교해 거절한다.
- 같은 DB에서 기존 달러 전용 경로로만 만든 요청이 발견되면 다음 원화 보호 예약을 중지한다. 그러나 **그런 달러 전용 경로 자체를 시스템 전체에서 차단하는 통합은 아직 수행하지 않았다.**
- 합성 테스트: 정확히 500원과 501원 경계, 모든 역할 공동 계산, 역할별 원 단위 올림, 재시작/복수 실행 누적, 병렬 과예약, 합성 요청 게이트 연결, 기존 달러 경로 우회 탐지, 청구 보류 차단.
- 테스트 파일: research/character-optimization-gepa/test_krw500_synthetic_ledger.py
- GEPA 고정 무네트워크 CI에 새로운 Python 테스트를 포함한다.
