## 2. 이번에 구현한 오프라인 사전 점검

- 함수: scripts/character-optimization/yeoul-pilot-readiness-v1.mjs
- screenPrivateYeoulOverlap(): **비공개 환경에서만** 주어지는 Y01~Y12 질문 가족 12개와 공개 신규 8가족의 정규화 문자열/2글자 묶음 유사도를 보수적으로 대조한다. 0.5 이상 또는 부분 일치는 **사람 확인이 필요한 의심 사례**로 표시한다.
- 중복이 0건이어도 **의미적 독립성을 증명하지 않으며**, 사용자/검토자의 의미 중복 검토, 원본 바이트 검증이 필요하다. 결과에는 기존 원문·내용 해시를 쓰지 않는다.
- quoteYeoulPilotEnvelope(): 학생·반사·심사·홀드아웃 4역할의 모델 ID, 하위 공급자, 시도 수(재시도 포함), 입력·출력·추론·캐시 읽기/쓰기의 요청별 최대 토큰 및 해당 역할의 잠정 요금표를 모두 받아 **상향 반올림한 마이크로달러 최악 비용**을 제시한다.
- makeYeoulPilotReadiness(): 검토·단가·승인 증거 부족과 기존 공개 평가의 한계를 모아 HOLD 보고서를 만든다. 어떤 입력이 주어져도 실제 API 전송, 유료 호출 승인, 캐릭터 운영 반영을 수행하지 않는다.
- Node 내장 테스트(node:test) 7개: 중복 의심, 위조된 승인, 역할 누락, 모델 불일치, 미지정 요금, 예산 부족, 가격 올림 계산을 검사한다. npm test와 GEPA 전용 CI의 기존 test 파일 탐색 경로에 포함된다.

## 4. 비용·호출 상한 사전 승인 계약

| 필드 | 요구 사항 |
|---|---|
| 모델 및 공급자 | 학생/반사/심사/홀드아웃별 정확한 모델 ID·하위 공급자 |
| 비용 | **각 공급자 실제 단가**: 입력/출력/추론/캐시 읽기/쓰기, 기타 가능한 최악 고정비 |
| 토큰 | 역할별 요청당 입력/출력/추론/캐시 최대치 |
| 횟수 | 역할별 총 요청 시도 횟수. **429·타임아웃 재시도까지 포함** |
| 총액 | 소유자가 명시적으로 정한 USD 총상한(마이크로달러 단위로 기록) |
| 정책 | 비용 자료 출처·조회 시각·가격 유효기간·정확한 모델/공급자 설정 해시 |
| 중단 | 예산·시도·토큰 상한 초과, 라우팅/모델 변경, 가격 실효·불명, 과금 불명, 품질/보안 필수 위반 시 HALT |

오프라인 계산기는 **입력받은 가격 주장의 산술만 확인**한다. 실제 단가의 진위·현재 유효성·사용자 지출 승인·네트워크 게이트웨이 권한은 확인하지 않는다. 따라서 그 계산 결과를 넘겨도 paidExecutionReady=false 및 externalCalls=0을 유지한다.

GEPA max_evals/max_token_cost는 학생/반사/심사/최종 시험을 모두 합친 실제 지출 상한이 아니다. 유료 전송 경로는 별도로 인증된 승인 원장, 원자적 예산 예약, 외부 송신 단일 게이트, 응답별 사용량/청구 대사가 실제 연결된 후에만 열 수 있다.

## 6. 비공개 원본 직접 점검 실행기

비공개 원본 `yeoul-evaluations-all-288-clean.json`을 실제 바이트로 접근할 수 있는 승인된 로컬 환경에서만 다음을 실행한다.

```sh
mkdir -m 700 /private/yeoul-gepa-report
node scripts/character-optimization/yeoul-private-source-intake-v1.mjs \
  --input /private/yeoul-evaluations-all-288-clean.json \
  --out /private/yeoul-gepa-report/legacy-overlap-audit.json
```

- `--input`은 288행 정제본이어야 하며, 12개 질문·288개 행의 모든 조합과 질문 텍스트 불변을 확인한다. 사용자가 붙인 품질 등급, 자유 의견, 자동 변별력 비움 상태를 수정하지 않는다.
- 출력 JSON은 원문 없는 기존 사용자 평가 건수와 신규 8가족의 문자열 유사도 의심 표식만 포함한다. 입력 원본의 바이트 해시는 비공개 로컬 보고서에만 기록한다. 이전에 신뢰된 원본 해시가 없으므로 이를 원본 진위 증명으로 오인하지 않는다.
- 보고서 폴더는 저장소 밖 **0700**, 출력 파일은 **0600**, 기존 파일 덮어쓰기 금지. GitHub Actions에서는 합성 288행만 테스트하며 실사용자 평가 자료는 등록하거나 게시하지 않는다.
- 문자 유사도 의심 0건과 완전한 288개 조합은 유용한 사전 검사일 뿐이며, 30개 사람 검토·의미상 독립성·새 봉인 홀드아웃·비용 승인·실제 송신 경계 중 하나라도 미완료이면 유료 실행은 계속 HOLD.
