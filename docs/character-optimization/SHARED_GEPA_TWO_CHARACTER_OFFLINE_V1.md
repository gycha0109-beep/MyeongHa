# 공통 표현 슬롯 — 두 캐릭터 실 GEPA 오프라인 실행 검증 v1

> 2026-11-12 · character-runtime-lab · **합성 자료만 / 외부 모델 요청 금지 / 운영 승인 아님**

## 확인할 필수 조건

GEPA 공통 최적화 계약은 복수 캐릭터를 명세할 수 있지만 기존 잠금 소스 실제 실행 검증은 단일 여울 캐릭터 중심이었다. 공통 표현 규칙이 어느 캐릭터의 품질을 떨어뜨리는지 평가하려면 최소 두 캐릭터 각각의 개발 자료와 최적화 검증 자료가 동일 실제 실행기에 들어가야 한다.

기존 `test_pinned_gepa_offline.py`에 별도 **실제 GEPA 공통 표현 슬롯 실행 시험**을 추가한다.

- 여울·세연 각각 개발 1가족, 최적화 검증 1가족의 **서로 다른 네 개 합성 자료**만 입력한다.
- 공통 표현 슬롯 `shared_expression` 한 곳만 GEPA가 변경한다. 캐릭터별 설정·권한·기억을 후보에 넣지 않는다.
- 두 캐릭터의 기초 점수와 개선 가상 점수를 다르게 구성해 평가기가 두 캐릭터를 실제 방문했는지 확인한다.
- 반사 전략은 완전한 로컬 가상 함수만 사용하고 네트워크 호출·원격 모델·자격증명·추가 프롬프트 입력을 차단한다.
- `test_set=None`을 유지하고 공개된 합성 데이터만 이용하며, 평가 횟수 상한 10회로 고정한다.

## 해석 범위

실제 잠금 GEPA의 다중 캐릭터 자료·공통 슬롯·개별 검증셋 처리에 대한 **통합 실행 증거**일 뿐이다. 인공 점수 상승은 한국어 자연스러움·캐릭터 개성 향상이나 사람 블라인드 검토 결과가 아니며, 공통 평균의 향상은 개별 캐릭터의 비열화 통과도 보장하지 않는다. 후보는 반드시 제안 단계에 머물고 GEPA 반환만으로 승격할 수 없다.

실제 사용자 288건, 미검토 규칙 6건·대사 24건, 캐릭터별 미확보 R16, 독립 비공개 최종평가, 모델·공급자·요금·500원 승인 경계는 여전히 미충족이다. **유료 모델 호출·충전·배포·기억·관계·Canon·사주·DB 수정 없음.**

검증: `python -m unittest -v test_pinned_gepa_offline` (고정 GEPA 소스 설치가 요구되는 무네트워크 CI에서 실제 실행).
