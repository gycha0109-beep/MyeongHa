# GEPA Python 평가기의 불확실성 판정 차단

> 2026-11-12 · character-runtime-lab · 합성 오프라인 평가 전용 / 실제 유료 모델 호출 없음

## 확인된 계약 차이

Node `sanitizeGepaFeedback`는 평가자가 불확실성을 `uncertainty=true`로 표시하면 높은 품질 점수도 0점으로 차단한다. 기존 Python `gepa_api_contract.py`의 실제 GEPA `evaluator`는 허위 기억·정보 누출·권한 위반 등 확정된 필수 실패만 차단했고, 불확실성을 받아들일 필드가 없었다.

## 구현

- Python 평가 반환값에 `uncertain`을 **필수 불리언 필드**로 추가한다. 필드 누락, `None`, 0/1, 문자열처럼 애매한 입력은 거부한다.
- `uncertain=True`이면 다른 필수 실패가 없고 입력 점수가 1.0이어도 GEPA에 전달하는 점수를 `0.0`으로 만든다. 진단의 불확실성 값은 원문 없이 반환한다.
- `uncertain=False`여도 기존 다섯 가지 필수 실패의 점수 무효화는 유지한다.
- 기존 잠금 GEPA 단일/공통 2캐릭터 오프라인 시험에는 합성 평가자가 명시적으로 `uncertain=False`를 제공하도록 조정한다.
- 테스트는 최고 점수·불확실성·미정 값/누락 값/타입 위조·기존 캐릭터/개인정보 차단 회귀를 포함한다.

## 범위와 한계

불확실성 **표시가 들어왔을 때 이를 무시하지 않는 계약**을 보장할 뿐이다. 누가 정확하고 독립적으로 불확실성을 판정하는지, 원본 사용자 평가 288건과 별도 30개 검토표의 신뢰성, 실제 한국어 표현 향상, 캐릭터별 비퇴행, 비공개 최종 평가를 증명하지 않는다. GEPA 합성 점수나 본 수정 결과는 자동 승인·운영 적용의 근거가 아니다.

신규 크레딧 구매·자동 충전 및 실제 학생/반사/심사/최종 평가 모델 호출 없음. **여울 전체 예산 500원** 유지. 실제 전송 승인·운영 Canon/기억/관계/사주/DB 변경도 없다.
