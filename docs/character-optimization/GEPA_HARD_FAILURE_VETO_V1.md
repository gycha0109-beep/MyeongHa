# GEPA Python 평가 점수의 필수 실패 우선 차단

> 2026-11-12 · character-runtime-lab · 연구·합성 평가 전용 · 유료 호출 0회

## 결함과 수정

기존 Node 평가 계약은 허위 기억·다른 캐릭터/사용자 정보 유출·Canon 및 권한 위반·근거 없는 관계 주장·공급자/비용 위반을 **점수가 높아도 0점**으로 처리한다. Python `gepa_api_contract.py`는 이 다섯 가지 필수 실패 코드를 검증한 뒤에도 원래 점수를 그대로 GEPA 엔진에 돌려주어, 실패가 있는 후보를 높은 평균 점수로 선정할 수 있었다.

이번 변경은 실제 GEPA에 전달하는 `evaluator`에서 필수 실패 중 하나라도 보고되면 최종 점수를 `0.0`으로 강제한다. 원래 실패 코드는 비공개 원문을 제외한 허용 코드로만 유지한다. 합성 평가의 설명용 `synthetic_verbosity`는 필수 위반으로 승격하지 않는다.

## 확인 범위

- 다섯 가지 필수 위반 각각에 최고 합성 점수 1.0을 넣어도 0.0을 반환하는지 확인한다.
- 설명용 합성 코드만 있으면 기존 점수를 유지하고, 설명용 코드와 필수 위반이 함께 있으면 0.0으로 차단한다.
- 평가기 등록 사례·캐릭터 일치·원문 비공개 제한은 이전 검증을 유지한다.
- 테스트: `python -m unittest -v test_gepa_api_contract test_pinned_gepa_offline`.

## 완료되지 않은 조건

이는 **거짓으로 높은 점수가 GEPA 선택에 반영되는 것을 막는 합성 평가 경계**다. 실제 모델 응답에서 어떤 실패가 존재하는지 감지하는 검증된 독립 심사 모델이나 사람 판단을 새로 만든 것은 아니다. 실제 한국어 품질·인격 유지 개선, 봉인 평가, 신뢰할 만한 승인·비용 청구, 배포/되돌리기 기능을 입증하지 않는다.

여울 전체 유료 파일럿 500원 한도를 유지하며, 유료 모델 요청·새 크레딧 구매·자동 충전·Canon/관계/기억/사주/DB/운영 변경은 수행하지 않는다.
