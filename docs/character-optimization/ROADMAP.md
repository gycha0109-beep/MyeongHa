## 이번 작업 단위

- 신규 공통 모듈 `scripts/character-optimization/`: 캐릭터·모델·설정 버전/권한 상태, 공통 실험 대상 명세, 수정 가능한 두 표현 슬롯을 검증한다.
- `scripts/character-optimization/validate-offline-manifest.mjs`: 비공개 입력에서 메타데이터만 집계하는 읽기 전용 CLI. 승인·네트워크·모델 호출·운영 변경 기능은 **없다**.
- 개발/검증 자료만 최적화 대상; 봉인/장기 평가 메타데이터가 CLI에 입력되면 실패한다. 물리적 파일/프로세스 분리는 C에서 별도로 구현한다.
- 공통 규칙 점수는 각 캐릭터의 후퇴를 독립적으로 검사하며, 전체 평균으로 상쇄하지 않는다.
- 후보 문구 검사는 휴리스틱 위험 신호만 감지할 뿐 인간 검토나 런타임 Output Guard를 대체하지 않는다.
