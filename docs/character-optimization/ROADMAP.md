## 고정 경계

- GEPA는 Canon/세계관/기억/관계/사주/콘텐츠 권한을 변경하지 않는다. 허용된 표현 슬롯 하나만 제안한다.
- 기존 12개 여울 질문과 288개 평가는 개발 근거이며 독립 품질 검증에 재사용하지 않는다.
- H01~H10은 평가군의 독립성에 공개 노출 이력이 있는 합성 자료다. 최적화기 파일 마운트·읽기 권한 차단은 별도 구현·검증 전까지 **미충족**이다.
- 사용자 승인 없는 외부 모델 호출은 0회로 유지한다. GEPA 가상 실행이나 자동 CI 성공은 품질 개선 또는 운영 승인 근거가 아니다.
- 필수 구현/검증/문서화가 완료되지 않았으므로 **ROADMAP_COMPLETE 미선언**.

## 현 호환성 문제

- 공개 `gepa==0.1.4` 릴리스는 구 API에 해당하며, 신규 `OptimizeAnythingConfig`가 포함된 공식 소스 커밋 `ce5b0d6e3d6af6c6dbec6de2c54536bbb961d309`을 대상으로 별도 **가상/무네트워크 실제 실행**을 검증한다.
- 새 GH Actions 검증은 해당 소스 SHA를 사용하며 실제 유료 모델을 사용하지 않는다. 공식 소스 고정 설치·합성 점수 0.2→0.8 개선·18개 Python 테스트 GREEN(https://github.com/gycha0109-beep/MyeongHa/actions/runs/42963466961). 이는 실제 대사 향상이나 전체 보안 격리의 증거가 아니다.
## 별도 오프라인 격리·모의 게이트 검증

- 가상 모델을 사용하는 비용 장부/공급자 불일치·중복 요청 차단은 `test_offline_egress_gate.py`에서 검증한다. 실제 요청을 보내는 gateway는 미구현이다.
- 컨테이너의 커널 네트워크 차단과 봉인 파일 마운트 분리는 기존 고정 GEPA 워크플로에서 실행한다. 이 단계의 봉인 파일은 **합성**이고, 실제 비공개 시험 데이터 격리는 아직 입증하지 않았다.

### 단일 요청 경로의 구현 수준
- 오프라인 모의 게이트에는 Node·Python 공통 유닉스 소켓과 단일 SQLite 예산 장부를 연결했다. 실제 OpenRouter 요청 전송 기능과 승인 검증, 요청별 최대 토큰/요금 계산, 하위 공급자 강제 제한은 아직 구현되지 않았다. 이 조건이 충족되기 전 외부 모델 호출은 계속 거부한다.

## 2026-11-11 — 모의 요청 정밀 통제 추가

- 호스트가 고정한 합성 정책으로 모델·공급자·설정/라우팅/가격표 해시, 가격표 유효기간, 입력·출력·추론 토큰 상한, 최악 비용(반올림 포함)을 검증한다.
- 기존 SQLite 장부를 공유해 요청별 재시도 번호·병렬 요청 상한을 한 트랜잭션에서 제한하고, 재시작·정책 변경·과금 불명 시 예약을 보존한다. Unix 소켓에 별도 통제 모의 요청 경로를 추가한다.
- 유료 승인 증명 저장소와 실제 가격표/모델 지원 범위 검증 및 OpenRouter 송신은 **미구현**이다. synthetic-fixture 가격은 테스트 전용이며 실제 요금으로 사용해서는 안 된다.

## 2026-11-11 — 캐릭터별 R16 평가 출처 연결

- Character Runtime Standard v1의 R16.1~R16.4 및 선택적 R16.5를 실제 캐릭터 Runtime 소스에서 읽어 해시·분류·출처만 등록하는 연구용 계약을 추가했다.
- 현재 R16 원문이 확인된 여울·세연·라현·백헌 4명만 연결한다. 나머지 5명의 R16 시나리오, 품질 평가 점수, 승인 기록은 임의로 생성하지 않는다.
- 소스 문구는 GEPA 전달용 평가 메타데이터에서 제외하고 DRAFT/사람 미승인 상태를 유지한다. 시나리오 가족의 의미적 중복 및 실제 품질 평가 완성은 별도 남은 작업이다.

## 2026-11-11 — 승인 출처 미연결 HOLD 및 신규 여울 질문군

- 승인 레코드의 실행 범위·예산·역할·모델·공급자·유효기간·출처 해시를 **비권한적 범위 검사**로 대조하는 모듈을 추가한다. 실제 신뢰 가능한 사용자 승인 원장/진위 검사 경로가 정해지지 않아, 모든 유료 송신 승인은 계속 **HOLD**다. 테스트용 승인 주장만으로 송신을 열지 않는다.
- 여울에 신규 합성 개발 4가족, 최적화 검증 4가족을 따로 구성했다. 질문 원문은 메타데이터 전송 계약에서 제외하고 다중 턴은 동일 가족에 유지한다.
- 기존 Y01~Y12 원문과 의미적 중복 독립 감사를 완료하지 않았으므로 신규 8가족은 **검토 대기 후보**, 공식 독립 검증셋이 아니다. 기존 공개 H01~H10을 봉인된 신규 홀드아웃으로 재분류하지 않는다.
- 실제 가격표·모델 세부 지원 파라미터 확인, 강제 네트워크 송신 게이트, 사용자 승인 증명, 비공개 연구 입력/독립 홀드아웃은 여전히 미완료다.

## 2026-11-11 — 청구 불명 전역 중단 보강

- 기존 모의 장부가 보류 상태를 단지 비용 합계로만 보존하던 결함을 보정했다. 동일 실행에 보류 건이 하나라도 있으면 별도 역할·별도 요청도 보내기 전 거부한다. 재시작 후에도 보류 건을 해제하지 않는다.

## 2026-11-11 — 모의 정책 입력 스냅샷 봉인

- 앞선 `@dataclass(frozen=True)`만으로 중첩 요금표·공급자 목록·호출 한도 변경이 가능한 문제를 해결했다. 정책 생성 시 원본 참조를 끊고 내부 데이터도 읽기 전용으로 봉인한다.
- 종전 정책 해시의 JSON 표현을 유지해 기존 장부 비교를 깨지 않도록 하며, 외부 입력 변조·내부 직접 변조·가격 계산·예산 예약의 회귀 테스트를 추가한다.
- 이 변경은 **합성 정책만** 다루며 실제 승인·요금표 신뢰·외부 요청 송신을 열지 않는다.


## 2026-11-11 — 여울 파일럿 평가 자료·모델·비용 사전 등록

- 기존 288건은 개발 근거, 여울 규칙 6건·대사 24건은 승인 0건의 검토 후보, 신규 개발 4/검증 4는 의미 중복 확인 전 후보로 둔다. 공개 H01~H10의 80상황·104턴 설계는 새로운 봉인 최종 평가로 인정하지 않는다.

- 상세 계약: docs/character-optimization/YEOUL_PILOT_READINESS_V1.md. 별도 여울 연구 PR #3187은 건드리지 않았다.

## 2026-11-12 — 캐릭터별 평가 가족·후보 검토 증거 게이트

- 기존 여울 288건, 사람 검토 30건, 신규 비공개 최종 홀드아웃, 실제 유료 비용·송신 게이트 미완료 상태는 유지한다. 상세: CANDIDATE_EVIDENCE_REVIEW_V1.md.
