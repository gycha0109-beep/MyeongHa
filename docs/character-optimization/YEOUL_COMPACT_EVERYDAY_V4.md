# 여울 GPT-6 Luna 일상 대화 10개 실측 — 예산 상한 내 압축형 연구 (2026-11-18)

## 목적과 변경

이전 v3 실제 출력에서 '허전해요'가 상투적 위로에 머무르고 '밥 먹었어요?'가 사용자를 '여울 씨'로 잘못 부른 결함을 확인했다. 최종 수정본은 예산 상한 때문에 실측하지 못했다. 이번 v4는 **예산 500원 전체 상한을 유지**하면서 10개 일상 발화에서 여울의 개성이 드러나는지 확인하는 **별도의 압축형 단회 연구 경로**다.

- `yeoul-compact-everyday-v4.mjs`: 원본 여울 Bible/Runtime SHA를 검사하고, 항상 같은 여울 성격을 전달한다. 별도의 '허전함 케어 모드'를 켜지 않는다.
- 장황한 부정 지침 대신 **여울 개인의 순간적 관심 → 행동 선택 → 짧은 대사**를 우선한다. 결과 대사 10개를 한 번의 JSON 배열로 받는다.
- `yeoul-compact-everyday-v4.test.mjs`: 원본 고정, 10개 질문, 예산 근거, 출력 결함 표식 확인. 오프라인 테스트 2/2 통과.
- `yeoul-compact-everyday-live-once-v4.mjs`: 실행 전 실제 OpenRouter 모델별 8개 엔드포인트 중 **가장 높은 가격**을 적용해 보수적 비용을 산출한다. 최초 호출 후 잠금 파일로 재실행을 막고, 응답 원문은 개인 PC 비공개 폴더에만 기록한다.

## 실제 실측

- 2026-11-18, `openai/gpt-6-luna` 실제 API 1회, **10개 응답** 반환.
- 모델 사용량 보고 비용 **USD 0.0002226**, 호출당 보수적 환율·가격 안전계수와 10원 추가비를 포함한 예산 추정 **17원**.
- 종전 보수적 예약·사용 계산 **481원** + 이번 17원 = **498원 / 500원**. 이 수치는 공급자 최종 청구액이 아니다. 과거 실패 CI 과금 여부도 미확인이다. 추가 호출 자동 실행 금지.
- JSON 내용 검사 통과(10건 모두 수신, 상투적 첫마디와 잘못된 '여울 씨' 호칭의 단순 표면 검사는 모두 0건). **캐릭터 품질 자체를 통과했다는 뜻이 아니다.**
- 중요한 '허전함'의 실제 결과: “허전하다는 말은 그냥 넘기기 어렵네요. 무슨 일 있었는지, 말해도 괜찮아요?” — 기존 '그랬군요'형보다는 관심 표현이 개별적이지만 **“말해도 괜찮아요?”에는 상담형 말투가 잔존**한다.
- '심심해요'에는 상대를 가볍게 받아치는 여울의 반응이 보이고, '그냥 인사하려고 왔어요'에도 상대를 붙잡는 성격 반응이 드러난다. 다만 일부 질문은 아직 무난하거나 사실 근거 없는 짐작을 포함할 수 있다.

## 해석 제한

- **실측은 질문 10개를 하나의 요청 안에 배치한 것**이다. 10회 개별 호출의 독립 검증이 아니며 서로의 질문이 출력에 간섭했을 가능성을 배제할 수 없다.
- V3 수정본의 직전 12KB 프롬프트를 동일한 모델에서 실측한 것은 아니다. 이번 변화는 v4의 압축형 지시문과 배치 구성에 의해 발생했을 가능성이 있으며 정확한 개선 원인을 분리해 증명하지 못한다.
- '허전함'은 요구한 여울의 자연스러움에 아직 미달. 사람의 블라인드 판정/반복 검증 및 운영 캐릭터 런타임 통합은 진행되지 않았다. GEPA winner·Canon·기억·관계 권한·운영 배포를 변경하지 않는다.
