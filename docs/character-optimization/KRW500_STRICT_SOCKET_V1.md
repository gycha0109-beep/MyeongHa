# 여울 GEPA 500원 공동 예산 — 전용 소켓 보호 경계 v1

> 연구용 합성 실험만 · 사용자 상한 KRW 500 · 실제 결제/모델 호출/승인 없음

## 구현 목적

기존 LocalSocketGateway에는 모의 USD 예약만 수행하는 구형 요청 형식과 정책·비용 검증을 수행하는 governed_dry_run 형식이 공존했다. 500원 원화 예산 장부를 만들더라도 같은 소켓에서 구형 요청을 받아주면 **그 요청은 원화 예약을 우회할 수 있다**. 이 트랙은 여울 500원 파일럿 전용 소켓에서 그 경로를 차단한다.

## 반영된 동작

- LocalSocketGateway(..., gate=None, governed_gate=..., krw500_only=True)로 전용 소켓을 열면 GovernedDryRunGate가 실제로 YeoulKrw500SyntheticLedger를 보유하는지 확인한다. 달러 전용/임의 게이트 객체는 소켓 시작 전에 거부한다.
- 기존 구형 요청, 알 수 없는 유형, approvalRef 또는 비공개 대화 필드를 담은 요청은 거부한다. 오직 kind=governed_dry_run의 기존 엄격한 합성 메타데이터 형식만 통과한다.
- 통과한 합성 요청은 기존 USD 예약, KRW 500원 공동 상한, 재시도·정책 해시·동시 호출·불명 청구 보류 검증을 **같은 SQLite 거래**에서 수행한다.
- yeoul_krw500_socket_daemon.py는 KRW 전용 소켓을 여는 **합성 예시 실행기**다. 공급자 ID fake-provider, 모델 synthetic/deepseek, 환율 1달러 1,400원 및 고정 수수료 498원은 모두 가상 숫자다. 이것으로 실제 요금을 추정하면 안 된다.
- 기존 소켓의 기본값은 예전 합성 테스트와 호환되도록 유지한다. 전용 소켓 보호가 다른 소켓/별도 API 키/다른 결제 프로그램까지 차단한다는 뜻은 아니다.

## 검증·안전 한계

- 테스트는 로컬 Unix 소켓을 통한 보호 요청 1회 성공, 재요청 한도 초과, 구형 경로 거부, 위조 승인/개인정보 차단, 잘못된 장부 구성 거부, 과금 불명 시 후속 요청 차단, 장부 재시작, 전용 예시 실행기 경계를 검사한다.
- .github/workflows/character-gepa-offline-pinned.yml의 고정 GEPA 합성 검사에 추가했다. 네트워크 금지 컨테이너와 실제 모델 호출 없는 기존 실행 경계는 그대로 유지한다.
- 실제 승인 원장/계정 잔액/현재 환율·단가/수수료/공급자 라우팅/실제 청구 영수증 검증은 아직 없다. 이 소켓은 유료 요청을 전송하는 인터페이스가 아니다.
- 모든 호출 결과는 external_calls=0, 실제 크레딧 신규 충전 금지, 실제 모델 호출 0회를 유지한다. 기초 평가 288건 및 미검토 규칙·대사 30건, 독립 최종평가도 이 단계에서 변경하지 않는다.

**완료 조건:** 이 합성 경계만으로는 유료 파일럿의 승인이나 ROADMAP_COMPLETE를 선언하지 않는다.
