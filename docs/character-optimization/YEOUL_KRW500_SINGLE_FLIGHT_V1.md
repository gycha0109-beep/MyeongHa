# 여울 500원 파일럿 전체 단일 요청 보호 v1

> 상태: **오프라인 합성 검증만 완료**. OpenRouter 실송신/승인/과금 대사 기능이 아닙니다.

## 목적과 기존 결함

기존 `YeoulKrw500SyntheticLedger`는 한 요청의 과금이 명시적으로 `held`가 되면 다른 실행까지 차단했지만, 예약 직후 프로세스가 종료되어 `reserved`로 남은 요청은 다른 `run_id`의 예약을 막지 못했습니다. 네트워크 요청의 송신 여부가 불명확한 상황에 신규 유료 호출이 누적될 수 있는 위험입니다.

## 구현

- `YeoulKrw500SingleFlightLedger`는 동일한 파일럿 SQLite 장부에서 한 번에 **정산 전 예약 하나만** 허용합니다. 기존 학생·반사·심사·최종평가 4역할과 모든 실행 ID가 이 검사를 공유합니다.
- 기존 `BEGIN IMMEDIATE` 거래 안에서 다른 예약의 `reserved` 상태를 확인합니다. 재시작 뒤에도 원장에 남은 예약은 자동 해제하지 않고, 추가 요청을 거부합니다.
- 해당 시도에 대해 기존 `settle`로 정산이 끝난 경우에만 다음 예약을 허용합니다. 송신 성공 여부나 청구액을 알 수 없다면 `hold`를 유지합니다.
- 원장의 `pilot_dispatch_scope`에 `strict-single-flight-v1`을 고정합니다. 병렬 합성 원장으로 설정을 바꿔 동일 파일을 재사용하면 시작이 거부됩니다. 안전하게 이전 파일을 자동 전환하거나 초기화하지 않습니다.
- 기존 병렬 합성 테스트의 호환 경로는 보존하되 **기본 모드 자체를 유료 게이트로 승격하지 않습니다**.
- 상태 출력에는 미정산 예약 개수와 단일 요청 보호 모드를 표시합니다. 비용·모델 원문 또는 자격증명은 기록하지 않습니다.

## 검증과 미충족

`python -m unittest -v test_krw500_synthetic_ledger`로 총 17건 통과. 새로운 5건은 다른 실행 차단, 재시작 보존, 모드 전환 차단, 기존 병렬 파일 업그레이드 거부, 동시 요청 하나만 예약을 검증합니다.

**여전히 미충족:** 신뢰 가능한 소유자 유료 승인 원장, 기존 OpenRouter 크레딧 확인, 공급자·역할별 확정 단가, 환율/수수료 상한의 진위, 비용 견적과 실제 POST 연결, 공급자 영수증 독립 확인, 동일 운영 네트워크의 다른 결제 경로 차단. 오프라인의 가상 정산은 실제 OpenRouter 청구 증명이 아닙니다.

이 단계에서 **실제 유료 API 호출 0회, 신규 충전 0원, 운영 캐릭터 변경 없음**을 유지합니다.
