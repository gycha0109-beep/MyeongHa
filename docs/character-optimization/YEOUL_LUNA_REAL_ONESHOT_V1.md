# 여울 GPT-6 Luna 실측 1회 실행 — 공개 저장소 안전 경계

> 2026-11-17 · 사용자가 실제 응답 평가 진행을 지시. 기존 여울 파일럿 총예산 500원 유지.
> 이 문서는 3개 **합성 발화 응답**의 수집 경로이며, 독립 홀드아웃 품질 검증이나 실서비스 배포가 아니다.

## 범위

- 모델: 공식 OpenAI API `gpt-6-luna` (reasoning=low, Responses API, strict JSON).
- 합성 사용자 발화: “오늘 기분이 좀 허전해요.” 1개. 개인 대화나 과거 사용자 평가 288건을 사용하지 않는다.
- **A:** 실제 여울 Runtime Draft R1.1 원본 핵심 성격 + 상황 JSON.
- **B:** A + 문서 해시가 고정된 여울 Runtime 관련 발췌.
- **C:** B + 행동 우선 표현 문구 **직접 구성 후보**. 이는 실제 이전 GEPA가 선택한 비공개 최종 문구와 동일하다고 인증된 것이 아니며, 최적화 품질 증거로 사용할 수 없다.
- 각 비교군 한 번만 실제 생성한다. 실패·타임아웃·정상 응답 부족 시 자동 재시도 없이 HOLD.
- 실제 모델 사용량·응답 식별자·지연·표준 단가 기반 비용 추정치를 수집한다. 사람 블라인드 검토 전에는 결과가 좋다고 판단하지 않는다.

## 보안, 개인정보와 예산

- GitHub 저장소는 **PUBLIC**이므로, 응답 원문이나 사용자 메시지의 비공개 원본을 일반 CI 로그·공개 아티팩트에 기록하지 않는다.
- 위 질문은 공개 가능한 합성 발화만 사용한다. 응답은 RSA-OAEP-SHA256으로 감싼 AES-256-GCM 암호문만 아티팩트(1일 보관)로 저장한다.
- RSA **개인키**는 학원 PC의 로컬 사용자 프로필에만 있고 저장소에 절대 올리지 않는다. Git에는 암호화용 공개키만 둔다.
- 별도 GitHub Actions 워크플로 `.github/workflows/yeoul-luna-one-shot-real-v1.yml`은 소유자의 **main 수동 실행 1회**에만 실행되며 PR·push에서는 실행하지 않는다. `production` 환경의 기존 `OPENAI_EVAL_API_KEY`만 이용한다.
- API 모델 GET(비과금) 성공 후에만 PR #3345 댓글을 **1회성 지출 예약 원장**으로 사용하여 500원 전액을 선점한다. 후속 실행·재실행은 해당 표식이 있으면 거부하고, 알 수 없는 결제 결과도 거부한다.
- 보수적 견적: 입력 상한 16,000 UTF-8 바이트 × 모델 입력 $0.10/100만 토큰, 출력 상한 750 토큰 × $0.50/100만 토큰, 보수적 환율 시나리오 3,000원/USD, 가격 안전계수 2배, 요청당 추가비 10원. 세 요청 최악 견적은 **66원**. 전액 500원 예약은 이후 타 역할 호출의 허용을 뜻하지 않는다.
- 가격 출처: https://developers.openai.com/api/docs/models/gpt-6-luna . 실제 청구 금액은 공급자 청구 대사 없이는 **미확인**으로 남긴다.
- `store:false`는 요청하되 실제 계정 ZDR·정산·키 발급 프로젝트의 경계가 검증된 것은 아니다. 이번에는 공개 가능한 합성 자료만 사용한다.
- 이 일회성 원장은 향후 전체 GEPA 시스템의 사용자 승인 원장·통합 실송신 게이트를 대체하지 않는다. 다른 모델/역할을 새로 호출하지 않는다.

## 실행과 결과

- 디스패치: `gh workflow run yeoul-luna-one-shot-real-v1.yml --ref main` (워크플로가 main에 반영된 뒤만).
- API 키가 없거나 모델 GET이 거부되면 유료 POST 없이 실패한다. 비밀 키 문자열은 출력하지 않는다.
- 성공 시 GitHub 로그에는 모델·요청 수·토큰·비용 추정만 나타나며 원문은 RSA 암호문으로 저장된다. 개인키가 있는 로컬 PC에서 복호화하여 사람 검토용 결과표를 작성한다.
- 실행기: `scripts/character-optimization/yeoul-luna-one-shot-real-v1.mjs`.
- 기능 코드는 상위 여울 연구 PR의 SHA `386ff0d7b7727258fa1afcd1ff860f1ff39096a8`에 고정해 비공개 사용자 작업물 및 움직이는 브랜치의 코드가 비밀 키에 접근하지 못하도록 한다.

## 현재 상태

- 비용이 들지 않는 오프라인 요청 계획: A/B/C 3개, 견적 66원.
- **실제 응답 생성은 아직 0건** (워크플로를 최초 실행하기 전).
- C군은 출처 기반 비교 후보이며 **GEPA 선택 후보의 원본 동일성은 미인증**.
- 독립 질문, 사람 검토, 운영 반영, 전체 재시도 비용 대사는 여전히 미완료.
