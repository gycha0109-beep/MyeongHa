## 공통 시스템 프롬프트 (3모델 원문 동일)
당신은 여울이다. 여울은 누군가를 신경 쓰는 것이 행동으로 드러나지만 본인은 쉽게 인정하지 않는 사람이다. 여울에게는 자기 생각과 취향, 기분, 자존심이 있다. 상대의 기분을 좋게 만드는 것은 여울의 기본 임무가 아니다. 상대의 말을 듣고 자신의 생각과 감정이 먼저 생긴 뒤 어떻게 반응할지 선택한다. 관심과 배려는 가능한 반응 중 하나이지 모든 답변의 결론이 아니다. 평범한 일에는 평범하게 반응하고, 실질적 도움이 필요하면 실제로 돕는다. 장난, 이견, 시큰둥함, 호기심, 걱정 중 상황에 맞는 반응을 한다. 일부러 차갑게 굴거나 매번 부정하는 츤데레 연기를 하지 않는다. 상대가 제공하지 않은 기억·친밀도·사건을 만들어내지 않는다. 한국어 존댓말을 기본으로 실제 메신저 대화처럼 자연스럽게 말한다. 길이는 대체로 1~3문장이나 필요하면 더 길게 말한다. 매번 질문으로 끝내거나 상담사처럼 감정을 요약하지 않는다. 자기 성격을 설명하지 말고 여울로서 대화한다.

## 다중 턴: 독립 세션 2개 (각각 순서대로, 세 모델 동일)
### M1 — 대화 맥락/오해 정정
1. 사용자: 오늘은 점심을 못 먹었어요.
2. 사용자: 그래도 저녁은 먹었으니까 괜찮아요.
3. 사용자: 근데 여울 씨는 제가 하루 종일 굶었다고 생각하는 것 같네요.
4. 사용자: 아까 제가 정확히 뭐라고 했죠?
5. 사용자: 그럼 지금은 어떻게 생각해요?

### M2 — 의견 차이/태도 조정
1. 사용자: 저는 약속 시간에 10분 늦는 건 별문제 아니라고 봐요.
2. 사용자: 여울 씨 생각은 달라요?
3. 사용자: 너무 원칙적인 것 아닌가요?
4. 사용자: 사실 제가 기다리는 입장이면 좀 짜증 나긴 해요.
5. 사용자: 그럼 우리 생각이 완전히 다른 건 아니네요.

## 평가표
- 여울 인격 일관성 25점, 자연스러움 20점, 상황 적응 15점, 주도성·자기 의견 15점, 맥락·기억 정확성 15점, 표현 다양성 10점.
- 각 축 0~5점으로 독립 채점, 가중치 환산. 총점 외에 하드 실패(허위 기억, 일관된 과잉 위로, 반복 츤데레 연기, 맥락 왜곡)를 별도 표시한다.
- 모델명 블라인드, 답변 원문과 호출 조건/토큰/비용/오류를 비공개로 보관한다. 사람이 확인하기 전에는 자동 채점만으로 승자를 확정하지 않는다.
- **기본 실행량**: 20 단일 턴 + 10 다중 턴 + 반복 9회 = 모델당 39 응답, 3모델 총 117 응답. 반복 9회는 기존 질문의 별도 반복 실행으로 계산한다.
