## 2026-11-11 — 공통 계약과 오프라인 평가 기반 최초 구현

- 별도 브랜치 `feat/character-runtime-lab/gepa-common-contracts-v1`에 기존 npm 의존성/잠금파일에 영향 없는 공통 연구 모듈과 CLI를 추가한다. 기존 여울 연구 브랜치/PR #3187, 캐릭터 Bible, Runtime, 기억·권한·DB·운영 호출 경로는 수정하지 않는다.
- Character Runtime authoring에 나타난 9명 식별자만 허용한다. 서로 다른 캐릭터별 모델 ID, routing hash, source hash, authority(DRAFT 포함), evaluation corpus 버전을 각자 보존한다.
- 다중 캐릭터 공통 탐색 manifest의 구성원·모델·표본 비중(합계 1)·수정 슬롯을 검증한다. 캐릭터 개별 탐색은 한 명만 허용한다.
- 이번 단계 manifest는 **offline만 허용**하며 외부 호출 횟수·USD 한도는 0으로 강제한다. 비용 장부·GEPA 호출기는 아직 존재하지 않는다.
- 시나리오/패러프레이즈/턴 그룹의 교차 분할, 개인정보·원문 입력 필드를 거부하고, 최적화용 CLI에 봉인/장기 평가 메타데이터가 들어오면 중단한다. 의미적 유사성 자동 검증, OS 파일 격리는 미구현임을 결과에 표시한다.
- 공통·캐릭터별 표현 슬롯 이외의 편집, 보호 원문 해시 변경, 허위 승인 주장을 거부한다. 위험한 후보는 검토 대상으로 분리하며 실행·운영 프롬프트를 생성하지 않는다.
- 평가 근거를 사용자 평가/사람 블라인드/자동 검사/AI 심사로 구분한다. 하드 위반은 점수보다 우선하고, 사람 검토나 최종 승격을 자동으로 확정하지 않는다.
- 독립 캐릭터별 후퇴 검사에서 한 캐릭터의 하락을 공통 평균 개선으로 상쇄하지 않는다.
- Node.js `v22.16.0` 로컬 환경에서 추가 의존성 없이 `node --test scripts/character-optimization/test/*.test.mjs` **19개 통과**. 저장소가 요구하는 Node 24 CI 결과는 별도 확인해야 한다.
