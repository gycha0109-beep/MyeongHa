## 2026-11-11 — 공통 계약과 오프라인 평가 기반 최초 구현

- 별도 브랜치 `feat/character-runtime-lab/gepa-common-contracts-v1`에 기존 npm 의존성/잠금파일에 영향 없는 공통 연구 모듈과 CLI를 추가한다. 기존 여울 연구 브랜치/PR #3187, 캐릭터 Bible, Runtime, 기억·권한·DB·운영 호출 경로는 수정하지 않는다.
- Character Runtime authoring에 나타난 9명 식별자만 허용한다. 서로 다른 캐릭터별 모델 ID, routing hash, source hash, authority(DRAFT 포함), evaluation corpus 버전을 각자 보존한다.
- 다중 캐릭터 공통 탐색 manifest의 구성원·모델·표본 비중(합계 1)·수정 슬롯을 검증한다. 캐릭터 개별 탐색은 한 명만 허용한다.
- 이번 단계 manifest는 **offline만 허용**하며 외부 호출 횟수·USD 한도는 0으로 강제한다. 비용 장부·GEPA 호출기는 아직 존재하지 않는다.
- 시나리오/패러프레이즈/턴 그룹의 교차 분할, 개인정보·원문 입력 필드를 거부하고, 최적화용 CLI에 봉인/장기 평가 메타데이터가 들어오면 중단한다. 의미적 유사성 자동 검증, OS 파일 격리는 미구현임을 결과에 표시한다.
- 공통·캐릭터별 표현 슬롯 이외의 편집, 보호 원문 해시 변경, 허위 승인 주장을 거부한다. 위험한 후보는 검토 대상으로 분리하며 실행·운영 프롬프트를 생성하지 않는다.
- 평가 근거를 사용자 평가/사람 블라인드/자동 검사/AI 심사로 구분한다. 하드 위반은 점수보다 우선하고, 사람 검토나 최종 승격을 자동으로 확정하지 않는다.
- 독립 캐릭터별 후퇴 검사에서 한 캐릭터의 하락을 공통 평균 개선으로 상쇄하지 않는다.
- 여울 기존 `diagnose()` 출력의 **진단 메타데이터만** 받아 등급·출처·위험 신호를 공통 형식으로 전환한다. 원본 키는 해시로, 자유 의견 텍스트는 출력에서 제외한다. 사용자 부정 평가를 자동 확정 하드 위반으로 승격하지 않는다. 원본 288건 재실행/검증과 이 변환기 연결은 아직 별개 작업이다.
- 서로 다른 캐릭터가 동일한 프롬프트를 각기 개발·홀드아웃으로 쓰는 경우도 지문 충돌로 거부한다.
- Node.js `v22.16.0` 로컬 환경에서 추가 의존성 없이 `node --test scripts/character-optimization/test/*.test.mjs` **25개 통과**. 저장소가 요구하는 Node 24 CI 결과는 별도 확인해야 한다.

- 캐릭터 2종 테스트는 **합성 자료**이며 운영 모델 선택·실제 품질·프라이버시 격리를 입증하지 않는다.
- GEPA/Python 설치, API 호출, 사람 대사 승인, 사용자 데이터의 외부 전송, 실제 운영 모델 교체 **모두 0건**.

## 2026-11-11 — 비용 예약 핵심 및 네트워크 차단 출구의 부분 구현

- `research/character-optimization-gepa/budget_ledger.py`에 비공개 SQLite WAL 장부, 호출 전 정수 마이크로 USD 예약, 역할별/전체 호출 상한, 동시 경쟁 예약, 분실 응답 보류, 초과 과금 후 차단, 다시 시작해도 변경할 수 없는 계획을 구현했다. 실제 모델 호출은 하지 않는다.
- `egress_gateway.py`에서 학생·교사·심사·봉인 평가 네트워크 호출을 전부 거부한다. 실전 HTTP transport는 미구현이다.
- Python 3.13.5 기본 라이브러리로 **10개** 오프라인 검증 통과. GEPA 미설치이며 버전 호환성 검증을 했다고 주장하지 않는다.
- 실제 Python/Node 동시 호출의 **공통** 정책 게이트, 공급자 확인, 실 단가/추론 토큰 상한, GEPA 모델 호출, OS 프로세스/홀드아웃 격리는 다음 구현 과제다.
- 승인된 API 비용/호출 상한이 없으므로 사용자·교사·심사 호출과 실제 청구 비용은 계속 **0건/0달러**다.

## 2026-11-11 — Python/Node 오프라인 평가 브리지

- `scripts/character-optimization/offline-evaluator-bridge.mjs`와 `research/character-optimization-gepa/evaluation_bridge.py`를 연결했다. 합성 평가 메타데이터만 JSON 표준 입력으로 주고받고, 알 수 없는 필드·원문 메시지·비정상 결과는 오류 코드만 남기고 거부한다.
- **Node 27개·Python 13개** 로컬 테스트가 통과했다. 초기 연속 테스트 명령의 실행 제한을 넘어 중단된 후 각 도구를 별도로 재실행해 확인했다.
- 여전히 Python GEPA 패키지를 설치하지 않았고 실제 최적화·학생/반사/심사 호출은 없었다. 파일 접근권 OS 격리와 네트워크 상한 통합은 아직 미완료다.
