# 여울 신규 개발·검증 자료의 분할 간 유사 문장 차단 v1

> 2026-11-13 · character-runtime-lab · 합성 연구 자료에 한정 · 사용자 원본/유료 API 미접근

## 기존 공백과 적용 범위

기존 `screenPrivateYeoulOverlap()`는 **기존 비공개 Y01~Y12와 신규 여울 8개 가족의 겉보기 문장 유사성**을 검토할 수 있지만, 새로운 **개발 4가족 ↔ 최적화 검증 4가족 사이의 유사 문장**을 검사하지 않았다. 분할 검사는 가족 ID·SHA-256의 완전 동일성만 차단하므로, 같은 문장을 띄어쓰기와 구두점만 바꿔 다른 분할에 배치할 수 있었다.

새 `screenSyntheticCrossSplitLexicalOverlap()`는 **호출자가 제공한 합성 문장만 메모리 안에서** NFKC·소문자·공백·구두점 정규화 및 글자 2-gram 겹침으로 대조한다. 같은 캐릭터의 서로 다른 분할 가족끼리 비교하며, 임곗값은 0.65(정확히 동일하거나 한 문장이 다른 문장에 포함될 경우 강제 플래그)이다. 표본 수·검사 가족 수·의심 가족 ID만 반환하고 원문·정규화 문장·원문 해시를 출력하지 않는다.

`makeNewYeoulScenarioPlan()`는 신규 여울 8개 합성 가족에 이 검사를 적용하고 의심 중복이 있으면 등록 계획 생성 단계에서 실패한다. 정상 입력이어도 모든 후보는 기존 `candidate_semantic_overlap_review_required` 상태이며, 개인 원본 Y01~Y12의 의미 중복 또는 신규 평가자료의 독립성을 증명하지 않는다.

## 보호 조건과 한계

- 테스트는 가상·합성 문장에만 수행한다. 캐릭터 간 실제 대화 원본을 읽거나 GitHub로 복사하지 않는다.
- 기본·검증 가족을 구분한 16쌍의 신규 여울 비교와 유사한 2턴 질문, 공백·구두점 변형, 불법 분할·문구·문자열 식별자·원문 출력 차단을 점검한다.
- **임곗값 이하라도 동의어 치환, 질문 의도, 응답 구조 등 의미적 중복이 가능하다.** 의미 독립성을 자동 확정하거나 최적화·유료 호출을 허용하지 않는다.
- 기존 288개는 개발 근거이고, 24개 대사·6개 규칙은 검토 미승인 후보다. 신규 8가족도 사람의 의미 중복 판정 전에는 GEPA 정식 입력으로 등록할 수 없다. 이전 공개 H01~H10은 새 비공개 봉인 시험이 아니다.
