# 여울 일상 발화 상시 성격·행동 선택 실험 (2026-11-18)

## 목표

사용자 발화가 특별하지 않아도 여울의 사고와 관심이 대사에 묻어나도록 한다. “오늘 기분이 좀 허전해요.”처럼 평범한 말에서 일반 AI 위로 문구가 먼저 나오는 실패를 고친다. 이 구현은 **DRAFT 연구용**이며 기존 운영 대화나 Canon/기억/관계 데이터를 변경하지 않는다.

## 구현 내용

- `yeoul-everyday-voice-v3.mjs`: 10가지 합성 일상 질문에 동일한 상시 성격 체계(Bible A1/E1/E2, Runtime R1/R3/R5/R6/R7/R8/R10/R14)를 제공한다. 입력 단어로 care/caught/baseline을 분류하여 모델에게 다른 성격을 주입하지 않는다.
- 모델에게 여울의 **비공개 1인칭 순간 반응**을 정하게 하고, 그 반응에 맞는 `action`을 선택한 뒤 `reply`를 작성하도록 만든다. `reply`만 최종 사용자 대사이며 판단 필드는 연구 파일에만 기록된다.
- 첫 만남에서 깊은 관계 이후에나 가능한 `acknowledge_feeling`은 선택지에서 제외한다. 상대를 “여울 씨”라고 잘못 부르거나 “그랬군요”형 상투적인 위로로 시작한 결과는 **출력 정지**한다. 금지 문구를 단순 치환하거나 자동 재시도하지 않는다.
- `yeoul-everyday-voice-v3.test.mjs`: 동일 인격 10건, 상황 키워드에 따른 인격 교체 금지, 문서 SHA 및 관계 입력 경계, 출력 실패 유형 검증.
- `yeoul-everyday-voice-local-v3.mjs`: 기존 키를 이용한 공개 가능한 합성 질문 4건의 단회 평가 경로. 기본 동작은 비과금 계획 출력이며, 개인 PC 저장소 밖에만 원본 출력 저장.

## 실제 실측과 한계

- **첫 구현 시점의 v3 코드**로 Luna 4/4 응답을 실제 생성. 자동 재시도 0회. 공급자 보고 비용 **USD 0.00061112**.
- 허전함 질문에서 일반적인 공감형 첫 문장이 재발했다. 밥 질문에서는 사용자를 “여울 씨”로 잘못 부르는 오류도 발생했다. 따라서 **목표 성격 품질은 미달**이다.
- 실패를 분석하여 `private_reaction`을 여울 본인의 즉각적인 1인칭 반응으로 바꾸고, 첫 만남의 감정 인정 행동을 제외하고, 상투적 위로·자기 이름 오용을 차단하는 품질 게이트를 추가했다.
- 위 보정 이후 **오프라인 테스트 4/4 통과**. 하지만 **보정된 코드의 새 Luna 출력은 검증하지 못했다**. 기존 500원 전역 한도의 보수적 사용/예약 추정액은 최초 282원 + 이전 실측 상한 79원 + 이번 실측 상한 120원 = **481원**으로, 남은 19원만으로 다음 실험의 최악 비용을 보장하기 어려워 추가 유료 호출은 보류한다. 실제 청구 총액과 지난 실패 CI 실행의 정산은 별도로 불명확하다.
- 10개 일상 질문의 **실제 모델 응답은 아직 4개만 실측**했고, 실제 품질 만족 여부에 대한 사람 확인도 없다. 결코 최종 검증 통과나 운영 배포로 간주하지 않는다.
