## 구현
- 각 장 목적에 참고 분량을 명시: 1~4·6장 750~1,000자 / 5장 1,700~2,300자. 강제적인 빈말 채우기는 금지한다.
- 여울이 독자의 특징을 발견하고 살짝 짓궂게 반응하다가 필요한 곳에서는 진지해지는 전개를 명시한다.
- 1~4·6장이 5장에 밀려 요약문으로 축소되지 않도록 하고, 같은 기준·책임·개선 문장을 장마다 반복하지 않도록 조정한다.
- 예시 문장은 **문체용**이며 특정 인물의 실제 경험을 추정하거나 복사하도록 하지 않는다.
- 호출당 최대 출력 토큰 14,000 → 18,000으로 헤드룸만 확대. 모델 1종, 호출 1회/생성, 원본 JSON 계약, 입력 검증, 비공개 저장, 승인 파일·상한 계산, 단회 잠금·재시도 차단은 불변.
- 비공개 생성 JSON을 독서형 HTML과 Markdown으로 렌더링하는 오프라인 스크립트 `render-yeoul-one-shot-reading.mjs` 추가. HTML 텍스트 이스케이프, 6장 일치, 원문 보존 검사, 파일 덮어쓰기 방지. 모델 호출 없음.

## 품질 판단과 남은 위험

- **개선 관찰:** v5보다 여울의 눈치·장난·직설 및 진지한 마무리의 빈도가 높고, 1~4장 서술이 풍부해졌다. 5장에는 2026~2030 연도 흐름과 2026년 11월~2027년 4월 절입 전후 월별 근거가 포함됐다.
- **품질 미달 요소:** 모델이 원천 근거의 완곡한 성향 설명을 구체적인 행동·감정 사실처럼 확대한다. 예를 들어 원천의 '현실 조건을 챙긴다'를 '남이 맡긴 일까지 다시 검수한다', '선택지에서 효율을 살핀다'를 '침착하고 결정 미루는 버릇이 있다'로 단정했다. '속으로 쌓아두다 폭발한다' 역시 증거 없음.
- 이 문장들은 **근거로 입증된 해석이 아니다.** 문체가 좋아졌다는 이유로 상품·명리 검수를 통과했다고 주장하지 않는다.
- 현재 상태는 구조/분량/원문 보존 성공, **캐릭터·명리 의미 정확성 사람 평가 대기**다. 이미 생성된 본문을 자동 교정하거나 출처 없는 단정을 정당화하지 않는다.
- 추가 유료 호출·다른 모델 도입 없이 이번 비교는 종료한다.
