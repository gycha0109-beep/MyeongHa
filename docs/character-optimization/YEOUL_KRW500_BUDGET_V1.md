# 여울 GEPA 파일럿 전체 500원 상한 — 원화 비용 계약 v1

> 기준일: 2026-11-12 · 사용자 발언: **여울 GEPA 유료 파일럿 총 500원(KRW) 상한** · 연구용 사전검증만, 실제 결제/호출 금지

## 1. 사용자 결정의 범위

- **모든 역할의 합계가 500원 이하여야 한다**: 학생(DeepSeek 후보), 반사, 심사, 별도 최종 평가, 모든 재시도와 실패 후 재시도까지 단일 파일럿에 합산.
- 단일 역할이나 개별 API 키당 500원이 아니다. 예산을 다 썼거나 전체 예상 비용이 500원 초과이면 추가 전송 중단이 원칙이다.
- 새 크레딧 구매, 자동 충전, 작업 범위 확장, 운영 모델 교체, 실제 대화 반출·배포를 허가한 것은 아니다.
- 사용자는 채팅으로 상한을 정했지만, **실행기의 신뢰할 수 있는 승인 원장/의사결정 출처로 인증되지 않았다.** 따라서 코드는 사람의 한도 결정이 존재한다는 사실만 기록하고 실제 유료 전송 권한은 계속 false다.

## 2. 요금·환율·수수료 계산 계약

- 모듈: scripts/character-optimization/yeoul-krw-budget-v1.mjs
- 앞선 4역할별 최악 비용·시도 횟수를 계산한 마이크로달러 견적이 실제로 내부 합계를 맞추는지 재확인한다. 역할이 없거나 가격·재시도 개수가 변조되면 거부한다.
- 환율 입력은 **원/달러 상한 시나리오**(1달러당 0.001원 단위의 정수)와 출처 URL·관측시각·최대 1시간 유효기간을 요구한다. 시장의 현재 중간환율을 카드 청구 환율 상한으로 오인하지 않는다.
- 한 번의 호출에서 환산된 금액을 **원 단위 올림**하고, 재시도를 포함한 횟수만큼 더한다. 학생·반사·심사·최종 평가 모든 역할에 동일하게 적용한다.
- 공급자 수수료, 환전 수수료, 세금, 결제 수수료, 기타 고정 비용의 5개 상한 값을 모두 요구하고 500원 합산에 포함한다. 0원이라고 적혀 있어도 증명된 수수료 0원이 아님.
- 총액이 500원 이내라는 출력은 오직 미검증 가정하의 계산 결과다. 요금 출처 인증·카드 환율/추가 수수료 상한·최종 청구 확인·반복 호출 예산 예약의 권한적 연결이 없으므로 **유료 실행 준비 완료는 false**다.
- 인용 환율 예시: 2026-11-12 대략 1달러당 1,334~1,343원. 약 0.37달러는 참고치이며 실제 실행용 최대 USD액이 아니다.

## 3. 충전·청구 차단

- OpenRouter 공식 약관 https://openrouter.ai/terms 기준, 크레딧 구매 최소금액은 **USD 5**로 안내되어 있어 **500원 예산으로 새로운 크레딧을 구매할 수 없다.**
- 공식 요금 https://openrouter.ai/pricing 기준 OpenRouter Standard는 크레딧 구매 시 수수료가 발생하고 모델 사용량은 기존 잔액에서 차감된다. 이 구매 수수료를 개별 모델 요청 가격으로 혼동하지 않는다.
- 기존 선불 크레딧 잔액이 있다면 신규 결제 없이 호출할 가능성은 있지만, 실제 잔액·사용 권한·요금제·연결된 제공업체가 확인되지 않았다. **현재 크레딧 잔액 확인 전에는 유료 호출 없음**.
- 자동 충전/신규 충전은 절대 수행하지 않는다. 해당 플랫폼의 신규 크레딧 구매가 필요한 경우 500원 상한 유지가 불가능하므로 중단한다.
