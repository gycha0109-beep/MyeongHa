# 세연 AI 답변 언어 고정 계약 — 2026-11-01

## 범위
- 대상: 세연의 실제 신규 AI 채팅 답변 (한국어, 일본어, 번체 중국어, 영어, 간체 중국어)
- 기존 공식 Reading·사용자 입력·저장된 채팅 본문은 번역하지 않습니다.
- 기존 권한·신원·결제·비공개 자료 접근·독립 검증·현재 응답 공개 제한은 변경하지 않습니다.

## 채팅 언어 규칙
1. 사이트의 기존 언어 선택기를 사용합니다. 별도의 회원가입 시 언어 선택 화면은 만들지 않습니다. 명시적 선택이 없으면 한국어입니다.
2. 최초 채팅방 진입 시 사용자의 UI 언어를 **고정 첫 인사**에 사용합니다. 같은 화면에서 언어 선택을 바꾸더라도 인삿말은 다시 번역되지 않습니다. 방을 다시 방문하면 그때 선택된 언어로 새 입장 인사를 표시합니다.
3. 각 사용자 메시지의 **최초 전송 당시 언어**를 요청 ID와 같이 브라우저 전송 보류 기록에 고정합니다. 재전송 및 중간 UI 변경으로 같은 요청의 언어가 달라지지 않습니다.
4. 서버는 명시적인 `X-MyeongHa-UI-Locale`만 허용하며, 한국어·일본어·번체·영어·간체 외 입력은 한국어로 안전하게 되돌립니다. 브라우저 `Accept-Language`만으로 언어를 바꾸지 않습니다.
5. 세연 생성 모델에는 해당 한 번의 요청 언어를 명시하고, 캐릭터·관계·출처·보안 규칙과 별개인 **답변 표현 언어**에만 적용합니다. 명백히 다른 문자 체계로 출력되면 저장 전에 차단합니다. 번체/간체 차이는 모델 지침을 사용하고 문자만으로 완벽하게 판정하지는 못합니다.
6. 정상 승인된 AI 답변은 만들어진 언어의 **원문 그대로 저장/재표시**합니다. 이후 사용자가 메뉴 언어를 바꾸더라도 기존 AI 답변과 사용자 메시지 원문에는 번역을 적용하지 않습니다.

## 현재 제한
- 서버의 실제 AI 공개/응답 경로에는 별도 신원·권한·첫 응답 공개 제한이 남아 있습니다. 언어 계약의 구현과 일반 사용자 실대화 활성화는 동일한 작업이 아닙니다.
- 향후 사용자 프로필에 선호 언어를 영구 저장하려면 별도의 계정 설정 설계·승인이 필요합니다. 지금은 기존 사이트 언어 저장 기능을 재사용합니다.
