- 일본어/번체의 기존 문구를 변경하지 않고 누락된 영어/간체 **243개 전부**의 정적 번역을 추가했습니다.
- 영어/간체에는 있으나 현재 웹 코드에서 참조하는 55개 문구의 일본어/번체 번역을 추가했습니다.
- 캐릭터 9명의 고정 인사말을 네 언어로 작성하고 캐릭터 대화방과 탐색 카드가 같은 원문을 사용하도록 통합했습니다.
- 같은 대화방 안에서 언어를 변경해도 **고정 인사**가 선택한 언어로 즉시 갱신되도록 했습니다.
- 대화 내용과 AI 응답, 공식 풀이 기록에는 자동 번역을 적용하지 않습니다.
- 전체 12개 화면의 한국어 잔존 검사를 영어/간체에도 적용했습니다. 네 언어 모두 주요 화면과 첫 인사 확인 경로를 공유합니다.

## 명확한 잔여 범위
- 영어/간체에만 있는 354개 문구는 **현재 웹 코드 참조가 확인되지 않은 사전 등록 문구**입니다. 이 PR은 이들까지 불필요하게 일본어/번체에 기계적으로 채우지 않습니다.
- 서버에서 제공하는 콘텐츠의 번역은 별도 제품 정책 및 데이터 계약 영역이며 이 작업에 포함하지 않습니다.
- 본 문서는 정적 소스/브라우저 검사의 범위를 증빙하며 운영 반영 여부는 CI 및 배포로 별도 확인합니다.

### 생성되는 AI 답변 언어는 별도

현재 AI 렌더러는 한국어 출력 지침을 명시하며, 서버의 명시적 UI 언어 처리 범위도 한국어·일본어·번체에 한정됩니다. 영어·간체 요청은 서버 요청 경계에서 한국어로 처리됩니다. **이번 전송 중 표시 수정만으로 AI가 선택 언어로 답한다고 간주하지 않습니다.** 생성 답변 언어의 다국어 지원은 서버 모델 입력·검증·응답 계약을 포함하는 별도 구현 범위입니다.
