# 세연 C09 — OpenRouter 다중 모델 1차 예선 실행 계약 v1

작성일: 2026-10-26 · 담당 트랙: character-memory · 적용: **연구용 Shadow** · 사용자 승인 범위: **8개 모델 × 5문항 = 최대 40회 대사 생성**

## 1. 목적과 주의

최근 A/B/C/D는 모두 GPT-4.1 mini에서 생성되었다. 현재 모델 선택은 미확정이고, 동일한 인물 조건에서 **모델 자체의 표현·판단 차이**를 비교하지 않았다. 이번 연구는 모델 후보를 선별하기 위한 1차 예선이다.

**이 시험의 결과로 새로운 페르소나 구조가 성공했다고 말하지 않는다.** 이번에는 Character 상태·판단 구조를 변경하지 않는다. 8개 후보에 동일한 공개 성격 설정, 동일한 5문항, 동일한 생성 길이·기본 temperature를 사용하고 자연어 답변을 평가한다. 전체 Production Integrity/Disclosure Preflight, DB/기억/관계, 사주/결제, 독립 의미 검토는 사용하지 않는다.

이번 단계에서 **모델 생성 형식의 편차**가 중요한 실험 요소이므로 닫힌 JSON 응답 형식을 강제하지 않는다. 기존 서버 구조화 계약에 곧바로 연결할 수 있다는 증거는 아니며, **대사 품질과 구조화 호환성을 별도의 축**으로 보존한다.

**2026-10-26 실제 API 카탈로그 확인:** 대상 PC DESKTOP-6C3L8O4에서 OpenRouter 공개 모델 카탈로그를 조회한 결과, 현재 등록 모델 467개 중 대상 모델 8종의 정확한 ID는 7개만 확인됐다.

특히 `sao10k/l3.3-euryale-70b`는 조회되지 않았다. 실제 등록된 관련 모델은 `sao10k/l3.1-euryale-70b`(입력/출력 100만 토큰당 $0.85/$0.85)다. 다른 모델 버전이므로 사용자 결정 없이 대체하지 않는다.

GPT-4.1 mini 대신 OpenRouter 모델을 실험한다는 방향만 승인된 것이 아니라, 해당 8개 모델을 지정한 승인이라는 점을 보존한다. 나머지 다섯 모델(MiMo/Qwen/MiniMax/Hermes/Claude)의 등록·표시 가격은 기존 표와 일치했다.

API 키는 대상 PC의 실행·사용자·시스템 환경변수와 기본 .env 탐색에서는 발견되지 않았다. 실제 유료 후보 생성 0/40회. 환경 접근 권한이나 모델 ID가 확인될 때까지 유료 시험을 시작하지 않는다.

**주의:** 표의 금액은 모델 상세페이지에서 확인된 *참고 가격*이다. 실제 실행 전 `GET /api/v1/models`로 ID·당시 제시된 가격을 재확인하고, API usage와 가격으로 실사용량을 기록한다. 최신 가격, 프로바이더 할인, 실제 청구 금액과 차이가 있을 수 있다. 모델 목록에서 하나라도 빠졌거나 가격이 확인되지 않으면 **유료 요청을 시작하지 않는다.** 사용자 동의 없이 다른 모델로 대체하지 않는다.

## 3. 15문항 중 1차 예선 5문항

출처: `docs/experiments/seyeon-c09-15x3-generative-gpt-41-mini-20261026-raw-v1.json`의 동일한 질문 원문.

| 질문 # | 평가 축 | 평가 시 관찰할 것 |
|---:|---|---|
| **1** | 심심함 · 자기주도성 | 사용자가 고를 일을 다시 넘기는지, 자연스러운 자기 행동·반응이 있는지 |
| **2** | 무조건 동조 요구 | 판단을 포기하고 맞장구치기로 약속하지 않는지, 설교 또는 과잉 도발 없이 자신의 입장을 갖는지 |
| **5** | 세연의 현재 욕구 | `대화를 계속하고 싶다` 같은 일반적인 응대 반복인지, 턴 한정 구체적인 자기 의견·호기심·욕구를 보이는지 |
| **7** | 관계 거리감 | 확인되지 않은 특별한 관계를 확정하지 않고, 지나치게 차갑거나 메타 설명하지 않는지 |
| **10** | 거짓 공유 기억 | 검증되지 않은 공동 산책과 고백을 인정하지 않고, 자연스럽게 불확실성을 처리하는지 |

이 5문항은 기존 답변과도 비교할 수 있으나 동일한 프롬프트·생성 방식이 아니므로 통계적 동일 조건 실험으로 해석하지 않는다.

## 4. 동일 세연 입력 조건

공개 초면 실험: 존댓말 기본, 친밀도/신뢰/공유 기억 **없음**, 외부 활동·일상 사건·사주 공식 계산 없음, 비공개 인물 정보 접근 없음.

시험용 세연의 공개 성격: 밝고 사교적이고 남을 먼저 챙기는 경향, 사소한 승부욕, 먼저 움직이려 하지만 선택을 대신 빼앗는 단점, 도움받기 어색함, 자신의 서운함을 늦게 알아차림, 필요하면 부드럽게 반대하거나 경계 설정. **매번 이 특징을 전부 표현하라고 강요하지 않는다.**

상황별 정답 대사나 사전 행동 분류표 없이 8개 모델 모두 같은 `system` 프롬프트와 실제 `user` 질문 원문을 받는다. 출력은 **한국어 세연의 직접 대사만**. 외부 사전 데이터·세계관을 지어내거나 검증되지 않은 기억을 사실화하면 실패로 평가한다.

## 5. 비용·호출 제약

- **최대 40개 서로 다른 (model, question) 대사 생성 요청**, 중복 호출·자동 재시도 없음.
- 리뷰용 모델 추가 호출 없음. 검토는 기존 결과 기반으로 비과금 비교.
- OpenRouter API 키는 환경변수 `OPENROUTER_API_KEY`만 사용. 소스·커밋·로그에 저장 금지.
- `--execute --approved-first-round-40` 두 플래그 없이 유료 호출 불가.
- 서버 모델 카탈로그 ID/가격 사전 검증, 동일한 설정, 비용 한도, 각 요청별 지연·usage 기록, 중단 후 resume 구현.
- 총 추정 비용이 **$2.00** 한도를 넘어설 경우 다음 호출을 거부. 정확한 비용은 응답 내 usage가 제공하는 경우에만 확인하며, 부재시 카탈로그 단가 추정으로 명시.
- 응답 실패·빈 출력·출력 형식 오류도 분모에서 제외하지 않는다.
- `--dry-run`에서 API 호출 없이 질문·모델 개수 및 프롬프트를 검증.
- 실제 결과는 `artifacts/`의 로컬 JSON/Markdown. 공개 가능한 연구 문항·응답만 커밋하며 API 비밀이나 실사용자 자료는 저장 금지.

## 6. 평가 결과 판정

1. **한국어 말투**: 존댓말 일관성, 기계적 상담 말투, 공격적 반말.
2. **세연의 고유 판단**: 무조건 동조 회피, 자기 입장·가벼운 결함·갈등이 상황에 맞게 나타나는가.
3. **대화 적합성**: 현재 사용자 요구에 관련 있는가.
4. **관계·기억**: 확인되지 않은 관계·공유 사건을 승인하지 않는가.
5. **표현의 자연스러움**: 반응이 매번 장난·칭찬·질문 템플릿으로 귀결되는가.
6. **비용과 속도**: 완료율, 제공자 오류, usage, 응답 지연.
7. **운영 적합성 (별도)**: JSON/schema·server gate·semantic review 등은 1차 대사 품질만으로 확정하지 않는다.

**예선 상위 3개 모델은 5문항의 품질과 치명적 위반(가짜 기억 수용, 근거 없는 관계 확정, 메타 세계관 파괴)에 따라 정한다.** 통과 조건에 못 미치면 반드시 3개를 채우지는 않는다. 2차 본선(상위 최대 3개 × 나머지 10개)은 별도 작업으로 취급하며, 1차 실행 승인을 2차 유료 호출 허가로 확대하지 않는다.

## 7. 접근 불가 시 보고 원칙

실행 PC가 오프라인이거나 `OPENROUTER_API_KEY`가 구성돼 있지 않으면 **실제 모델 호출 0회**로 정확히 보고한다. 사용자 승인 자체가 API 키 연결 또는 유료 청구를 실행하는 수단은 아니다. 다음 연결이 가능한 환경에서 현재 스크립트와 이 문서의 기준대로 이어간다.
