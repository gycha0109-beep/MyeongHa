# 고객 문의 회신 — 도메인 확보 전 준비

- 상태: **발송 모듈과 회귀 테스트 준비**, 실제 고객 발송 **비활성**.
- `apps/api/src/contact-reply-transport-v1.ts`는 기존 Resend 공급자 경로를 재사용하는 **내부 전송 함수**입니다. 공개 API, 관리자 화면, 발송 버튼은 아직 연결하지 않았습니다.
- 고객에게 노출되는 From은 `CONTACT_REPLY_FROM_EMAIL`만 사용하며, 개인 Gmail을 발신자로 사용하지 않습니다.
- `CONTACT_REPLY_ENABLED=true`, `RESEND_API_KEY`, `CONTACT_REPLY_FROM_EMAIL`이 모두 필요합니다. `@resend.dev` 샌드박스 발신자는 고객 회신에 사용할 수 없습니다.
- 추후 연결 시 **실제 운영자 회원 인증 및 owner-admin 권한 확인**이 선행되어야 합니다. 일반 회원/게스트 공개 API에서 이 함수를 호출하지 마십시오.
- 문의 접수 메일은 현재 별도 티켓 DB에 저장되지 않습니다. 관리 화면에서 고객 이메일·문의 ID·원문을 안전하게 확인할 수 있는 출처와 권한 경계가 확정되기 전에는 회신 라우트를 열지 마십시오.
- 도메인 확보 후 DNS 발신 인증(SPF/DKIM), 회신 수신 경로, 공식 발신 주소, 관리자 전용 회신 UX, 발송 기록/중복 방지, 실제 고객 메일 수신 테스트가 후속 작업입니다.
- 기존 `POST /api/contact` 수신 기능 및 운영 설정은 변경하지 않습니다.
