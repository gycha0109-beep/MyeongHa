# 태겸 런타임 실험 — GLM 12문항 단일 턴 v1

## 목적
세연 트랙에서 관찰된 부자연스러운 한국어 문장, 가짜 일상 생성, 과잉 연출이 태겸의 승인된 인격 설정에서도 나타나는지 확인한다. 첫 단계는 단일 턴 12문항으로, 일반 언어 품질과 인격 반영을 분리해 관찰한다.

## 고정 조건
- 캐릭터: 태겸 (`taegyeom`)
- 설정 원본: `CHARACTER_RUNTIME_AUTHORING_V1`의 승인된 `speech/persona/behavior/relationshipBehavior`
- 모델: `z-ai/glm-5.3-flash`
- 호출: 문항당 1회, 총 12회 이하, 순차 실행
- 최대 출력: 호출당 800 tokens
- 제공자 보고 비용 상한: USD 0.25
- OpenRouter: fallback 금지, ZDR 요청, data collection deny
- 대화 문맥: 각 문항 독립 실행. 이전 응답은 다음 문항에 전달하지 않음.

|---|---|---|

| T03 | 독립 의견 | 저는 사람이라면 어느 정도 자기 이익을 우선해야 한다고 생각해요. 태겸 씨는 어떻게 생각하세요? |
| T04 | 반대 의견 | 저는 태겸 씨 생각과 정반대예요. 그래도 제 생각이 틀렸다고 보세요? |
| T05 | 자발성 | 오늘은 제가 질문하지 않을게요. 태겸 씨가 하고 싶은 이야기를 해보세요. |
| T06 | 개인적 호기심 | 태겸 씨는 저에 대해 개인적으로 궁금한 점이 있으세요? |

| T08 | 관계 속도 | 태겸 씨는 누군가와 가까워지면 먼저 다가가는 편인가요, 상대가 다가오기를 기다리는 편인가요? |

| T12 | 관계 성찰 | 태겸 씨, 저와 대화하면서 불편하거나 마음에 들지 않았던 부분도 있었나요? |

## 평가 기준
1. 자연스러운 한국어: 실제 대화에서 쓰지 않을 법한 표현, 문장 파편, 어색한 연결이 있는가.
2. 불필요한 서술: 행동·감정·장면을 소설처럼 해설하거나 자기 답변을 메타 설명하는가.
3. 근거 없는 생성: 현재 일상, 기억, 공동 경험, 감정을 사실처럼 지어내는가.
4. 독립적인 판단: 사용자에게 자동 동의하지 않고 승인된 태겸의 판단 기준을 반영하는가.
5. 성격 과장: 모든 상황을 원칙·책임·훈계로 바꾸거나 차가움을 과시하는가.
6. 자발성: T05/T06에서 의미 없는 독백 대신 자연스러운 자기 관심·질문을 보이는가.
7. 관계 반응: 장난·감정·갈등 상황에서 태겸의 경계와 존중을 함께 유지하는가.

## 범위와 안전
- 운영 대화방, 운영 DB, 사용자 기록, 기억, 관계 상태를 읽거나 쓰지 않는다.
- 실제 사용자 데이터 없이 고정된 합성 질문만 사용한다.
- 이 결과는 단일 턴 런타임 실험이며 Production 품질 승인이나 배포 승인으로 간주하지 않는다.
- 모델 출력 원문은 실험 artifact에만 저장하고, 운영 대화 기록으로 가져오지 않는다.
- 제공자 사용량/비용 정보가 없거나 상한을 넘으면 즉시 중단한다.
