# 여울 GLM / GPT-6 Luna 언어·인격 비교 실험

## 목표
태겸과 같은 통제 방식의 독립 실험을 **여울의 승인된 인격**에 맞춰 진행한다. 태겸의 건조한 어법이나 원칙주의를 여울에게 강제하지 않는다.

## 실험 설계
- 고정 모델: `z-ai/glm-5.3-flash` 와 `openai/gpt-6-luna`.
- 질문 12개 × 반복 2회 × 조건 3개 × 모델 2개 = **최대 144호출**.
- 동일 여울 인격 기반 JSON schema 조건 A(기본), B(자연스러운 한국어 언어 규칙), C(별도의 짧은 가상 대화 예시).
- 여울의 감정 관찰·정서적 미세 차이·열린 결론·느린 친밀감·부드러운 경계에 맞춘 질문을 사용한다.
- 각 질문은 대화 이력 없는 단일 턴. 자전적 사건, 실제 날씨, 기억과 관계를 창작하지 않도록 제한한다.
- 결과를 문항/조건/모델/반복별 원문 그대로 보관하고, 자연스러움·성격 충실도·환각·화자 혼동·속도·비용을 비교한다.
- 과거 태겸 실험과 **질문이 동일하지 않으므로** 두 캐릭터 간 점수/시간 비교는 참고용이다.

## 비용/격리
- 사전 승인 범위 내 최대 $0.20 OpenRouter 공급자 보고 비용; 실제 청구액 별도.
- 미상 토큰 비용·공급자 오류·JSON 문제는 즉시 HOLD 및 미완료 결과 보관.
- GLM temperature 0.7, Luna 공급자 기본 temperature(지원 파라미터 차이).
- OpenRouter ZDR/데이터 수집 거부, 파라미터 지원 강제, 모델 대체 라우팅 금지, 키 비공개.
- GitHub Actions 보호된 main 일회성 트리거. 운영 대화/기억/관계 상태 접근 및 제품 반영 없음.
- 실험 아티팩트 14일 보존 후 문서로 내구성 확보.

## 완료 판정
실제 응답 144개와 비용·시간 근거를 확인하고, 질문별 비교표를 제공한다. 가짜 대사나 검증 전 완료 선언 금지.
