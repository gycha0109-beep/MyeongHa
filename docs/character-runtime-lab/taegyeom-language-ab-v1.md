# 태겸 GLM/Luna 핵심 인격 JSON 언어 A/B 실험 v1

## 목표
기존 핵심 인격 + JSON의 실제 표현을 기준으로 GLM 5.3 Flash와 GPT-6 Luna가 한국어 어휘·반응·인격을 얼마나 자연스럽게 만드는지 비교한다.

## 고정 조건
- 기존 승인 CHARACTER_RUNTIME_AUTHORING_V1의 태겸 프로필을 읽어 동일한 core 프롬프트를 구성한다.
- 각 모델에 동일한 질문 12개 × 동일한 반복 2회 × 조건 3개 = 모델당 72회, **총 144회**를 개별 호출한다.
- 두 모델: `z-ai/glm-5.3-flash`, `openai/gpt-6-luna`. provider fallback 금지.
- 기존 12문항과 JSON Schema `{reply:string}`, temperature 0.7, reasoning low, max_tokens 1200 적용.
- 세 조건: baseline(핵심 인격만), language_rules(일상 한국어 언어 규칙 추가), conversation_examples(다른 상황의 가상 대화 네 쌍). 승인 인격은 수정하지 않는다.
- 문항별 조건·모델 호출 순서를 교차하여 진행한다. 개별 12문항은 단일 턴이므로 장기 인격 품질을 입증하지 않는다.
- 과거 대화·실존 경험을 만들지 말라는 제약을 모든 조건에 포함한다.
- 제시 예시에는 평가 12문항의 답변을 넣지 않아 정답 유출을 피한다.

## 비용·보안
- OpenRouter 환경 비밀값만 사용, ZDR 요구, 데이터 수집 거부, 모델 대체 라우팅 거부.
- 모델 제공자가 보고한 누적 비용 USD 0.20에서 중단한다. 비용·토큰 확인 불가, 제공자 거부, 형식 오류 발생 시 멈추고 완료한 답변까지 결과 아티팩트에 저장한다.
- 가격·최종 청구액은 별도 검증 대상이며 모델 제공자가 비용을 보고하는 방식에 의존한다.
- 운영 대화·사용자 기억·관계 상태를 읽거나 쓰지 않는다. 프로덕션 자동 적용·승격 금지.
- GitHub Actions main 트리거 1회 실행, 결과 원문 14일 보관.

## 평가·보고
- 반드시 실제 생성 문장 **질문별 6조건 × 2반복**을 보여준다.
- 그 다음 한국어 어휘 자연스러움, 태겸 고유 판단, AI상담원 문장 반복, 환각, 응답 시간, 출력/추론 토큰, 비용을 비교한다.
- 판단과 발화를 같은 모델 한 번에 생성한 단일 턴 비교이며 실험 간 학습·미세조정은 수행하지 않는다.
- 설정 차이 외에도 GLM과 Luna의 토크나이저와 추론 토큰 정의가 달라 모델 간 토큰의 직접 비교는 참고로만 사용한다.
