# D4B-4 — 비용 정산 중단과 재요청 검증

Watchtower-Track: character-memory

## 검증 범위

- D4B-3 반영본에서 출발하며 기존 테스트를 변경하지 않음.
- 합성 회원·가격표와 일회용 PostgreSQL `myeongha_seyeon_d4b4_test`만 사용.
- 예약 상한 3,700, 확인된 실제 비용 300 (단위: 백만분의 1 미국 달러).
- 실사용자 자료·외부 추론 호출·실제 서비스 예산 변경 없음.

## 검사 절차 및 기대 결과

1. 3,700 예약: 개인별 원장과 전역 점유가 동시에 3,700으로 기록됨.
2. 별도 PostgreSQL 연결이 정산 기록을 갱신하되 저장 확정 직전 일시 정지. 테스트 권한으로 해당 **하나의 연결만** 강제 종료.
3. 연결 종료 후 원장은 다시 예약 중 상태, 비용 미확정, 점유 3,700. 부분 정산·유령 환불 없음.
4. 새로운 연결에서 정산을 성공시켜 실제 비용 300으로 확정. 성공 결과를 애플리케이션이 받지 못한 상황을 합성.
5. 동일 증빙을 다시 제출해도 이미 정산된 것으로만 응답하고 300을 다시 공제·환불하지 않음.
6. 증빙의 경과시간만 다르게 한 충돌 재요청은 거부하며 기존 정산 증빙을 변경하지 않음.
7. 두 번째 예약 3,700 뒤 사용량 확인 불가능한 시간 초과를 기록. 비용 0으로 취급하지 않고 3,700을 보수적으로 계속 점유. 동일 증빙 재요청과 변조 거부.
8. 이미 예약된 호출 ID의 중복 발송 허가 거부 및 최종 총점유 4,000 = 확정 300 + 미확인 3,700 확인.

## 남은 위험 및 제한

- 일회용 DB에서 정산 작업 도중 *연결 종료*와 *정산 성공 후 결과 유실*만 재현. 외부 사업자 요금 청구와 서비스 운영 장애는 검증하지 않음.
- 잠금 순서, 장기 대기, 교착과 시간 초과는 D4B-5 별도 범위.
- 손님 계정 경합은 별도 후속 검증 필요.
- 운영환경 변경·권한 교체·유료 호출 없이 모든 검증 완료가 병합의 선행 조건.
