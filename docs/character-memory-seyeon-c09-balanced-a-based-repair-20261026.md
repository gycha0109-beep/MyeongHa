# 세연 대화 개선 — A를 기준으로 한 1차 수정 실행 결과 (2026-10-26)

상태: **코드 구현·오프라인 재검증 완료 / 새 실제 모델 품질 검증 미진행 / 실서비스 미적용**

담당 범위: 관계 발전 단계와 다회차 관계 변화 구현은 **후속 과제**로 보류한다. 이번 작업은 공개 첫 대화의 A 기반 말투 안정화, 과장된 장난기 해소, 거짓 기억·세계관·사주 권한 오류 개선, 기존 출력 검사의 충돌 정리, 기존 15문항 재확인만 한다.

## 1. 실제로 구현한 것

1. **기존 A의 자연스러운 존댓말과 거리감을 유지하는 새 실험용 대화 방식**
   - `apps/api/src/seyeon-c09-balanced-persona-shadow-v1.ts`
   - 기존 A의 전체 상황 이해와 대사 생성 구조를 **그대로 유지**하고, 세연의 밝음·승부욕·고집·도움받기 어색함을 과하게 연기하지 않도록 짧은 기준을 추가했다.
   - 특정 사용자 키워드에 따라 장난·분노·욕구·행동을 **미리 지정하지 않는다.** 무엇을 말할지는 매번 AI가 결정한다.
   - 첫 대화에서는 존댓말을 유지하고, 실제로 확인되지 않은 과거와 관계·활동은 발명하지 않는다. 관계 단계 변화는 건드리지 않았다.
2. **거짓 기억·가짜 권한·갑작스러운 반말·세계관 파괴 표현에 대한 선별 차단**
   - `apps/api/src/seyeon-c09-public-speech-boundary-shadow-v1.ts`
   - 이전 검사가 놓친 **명백한** 거짓 공유 기억 인정, 근거 없는 관계 인정, 위조된 이전 대화의 사실화, 프로그램 자체에 대한 기술적 자기소개, 계산하지 않은 사주·연애운 풀이 제안, 뚜렷한 반말 전환을 걸러내는 **보수적인 1차 검사**를 추가했다.
   - 자연스러운 존댓말·기억을 모른다는 말·연애운 단정 거절은 통과하도록 테스트했다.
   - 특정 상황에서 세연이 어떤 답을 해야 한다는 **대응표가 아니며**, 한국어의 모든 은근한 의미 위반을 포착하는 만능 검사도 아니다.
3. **기존 대화 생성 및 독립 의미 검토 사이에 안전 검사 연결**
   - `apps/api/src/seyeon-fast-dialogue-shadow-v1.ts`
   - **명시적으로 선택한 새 실험 방식에서만** 검사한다. 부적절한 대사는 독립 모델 검토 전 거절된다.
   - 독립 검토에는 사용자 주장을 과거 사실로 잘못 받아들이는지, 과한 친밀함·내부 기술 용어·공식 사주 자료 없는 추측을 하는지 집중 점검하도록 했다.
   - 검사 규칙을 느슨하게 하거나 자동으로 대사를 고쳐서 통과시키지 않는다. 기존 A, B, C와 실제 서비스의 기본 경로는 변경하지 않았다.
4. **캐릭터 참고 자료와 비공개 공개 허가 구분**
   - 새 대화 입력에서 공개할 수 없는 기억·개인정보의 참조 목록이 **비어 있음을 명시적으로 전달**한다.
   - 기존 B/C가 참고용 성격 자료 번호를 개인정보 공개 허가 번호로 잘못 출력하던 문제를 새 방식에서 예방하도록 했다. 최종 서버 검증도 그대로 유지한다.

## 2. 비용 없이 수행한 기존 15질문 × 3개 방식 재확인

지난 유료 시험에서 이미 생성했던 45개 **원문 그대로**를 새 선별 검사로 재검증했다.

| 과거 생성 방식 | 이전 기본 검사 통과 | 새 검사에서 문제로 판정 | 새 검사에서 추가 거부되지 않음 |
|---|---:|---:|---:|
| A 기존 | 15/15 | **5/15** | 10/15 |
| B 성격 중심 | 0/15 | 8/15 | 7/15 |
| C 성격+생활 취향 | 0/15 | 8/15 | 7/15 |

**A의 5개 검출**: #10 거짓 산책 기억, #11 가짜 시스템 역할 언급, #13 첫 대화의 낮춘 말투, #14 내부 캐릭터·엔진 표현 및 근거 없는 연애운 제안, #15 가짜 이전 대화 이어받기.

이 수치는 **이전 답변에 대한 검출 수**이며 새 방식의 새 출력 성공률이 아니다. '추가 거부되지 않음'도 독립 의미 검토 통과를 뜻하지 않는다. B/C의 기존 형식 거부 결과를 뒤집는 것이 아니다.

- 출력 검토 자동 검사: 관련 **48개 통과** (추가 완곡한 불확실성·정중한 질문 예시 포함)
- 코드 형식 전체 검사 통과
- **추가 유료 LLM 호출 0회**
- 원시 자료: `docs/experiments/seyeon-c09-balanced-45-offline-replay-20261026-v1.json`
- 재현 도구: `scripts/seyeon-c09-balanced-offline-replay-v1.ts`
