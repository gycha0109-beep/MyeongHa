# C08-B — 세연 5회·3회 응답 경로 무료 비교

Watchtower-Track: character-memory

**검증 대상: 첫 만남의 공개 대화만. 실모델·사용자 데이터·실제 DB 없음.**

## 무엇을 확인하나요?

실제 서버의 대화 처리 함수/판정기를 사용하되 AI 답변은 **고정된 가상 응답**으로 대신합니다. 각 경로에 대한 호출을 센 뒤 동일한 결과와 오류 처리인지 비교합니다.

| 기존 경로 (5회) | 새 후보 (3회) |
|---|---|
| 1. 사실·공유 추억 주장 분류 | 1. 두 분류를 한 요청으로 처리 |
| 2. 민감한 개인사 질문 분류 | 2. 해석 + 한국어 답변 초안을 한 요청으로 처리 |
| 3. 답변 방향 해석 | 3. 기존 독립 의미 검증 |
| 4. 한국어 답변 초안 생성 |  |
| 5. 독립 의미 검증 |  |

구현: `test/seyeon-c08b-five-three-real-guards-offline-v1.test.ts`.

기존 경로는 `runSeyeonCharacterTurnV2`, 새 경로는 `createSeyeonUnifiedGovernanceCandidateV1` + `runCharacterGovernedPreflightV1` + `createSeyeonFastDialogueShadowV1`을 직접 호출합니다. 둘 다 내부 **서버 Guard/권한 Resolver를 실제 구현**으로 사용하고, 외부 모델만 가짜 함수로 교체합니다.

## 강제로 실패시켜 보는 경우

- 정상적인 공개 인사: 기존 5번, 신규 3번 호출 후 최종 답변과 해석·공개 범위를 비교
- 최종 의미 검증이 잘못된 답변 해시를 반환: 두 방식 모두 최종 결과 거부
- AI가 관계·권한 변경 필드를 몰래 반환: 두 방식 모두 위험한 단계에서 중단
- 가짜 관리자·가짜 공동 여행: 사실로 승인되지 않고, 3회 빠른 응답 경로 자체를 사용하지 않음
- 기존 사용자 기억을 붙이거나, 관계가 이미 진행된 상황: 빠른 응답 경로를 Provider 호출 이전에 중단

## 제한 사항

- 위 검사는 **실제 AI가 그런 답변을 낸다는 의미가 아닙니다.** AI 모델과 외부 API를 전혀 호출하지 않습니다.
- 첫 만남 공개 대화 외의 연애·가족·장기 기억·관계 깊이별 실제 응답 동등성은 미검증입니다.
- 실제 5→3 운영 전환, 품질·속도·토큰 및 실비 절감은 아직 증명되지 않았습니다.
- post-turn 기록/분석 모델과 외부 시스템 호출, 권한 부여·철회 및 DB commit도 이 작은 비교에서 검증하지 않습니다.
- 정상 시나리오가 통과해도 결과는 **`SHADOW_ONLY_NOT_PRODUCTION`** 입니다.
