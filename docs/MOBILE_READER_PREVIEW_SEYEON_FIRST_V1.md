# 모바일 사주·관상 Reader 프리뷰: 세연 우선

Web PR #1753에 이어 Mobile Reader 선택 UI를 첫 후보 '세연' 1명으로 제한한다. 캐릭터별 서사 설정 미확정 상태에서 나머지 8명은 UI를 삭제하지 않고 `컨셉 준비 중`으로 표시한다.

- 같은 9명 canonical roster와 웹/모바일 프리뷰 후보 목록 일치. 이름/칭호/정체성을 서버 권한으로 인정하지 않는다.
- 기존 모바일 사주 Preview는 Reader 선택으로 계산/해석의 의미가 바뀌지 않는다.
- 관상은 안전한 이미지 intake / 저장·삭제 / 실행 / 결과 자격 승인이 이루어지지 않았다. Reader 선택은 관상 분석 개방과 무관하다.
- 세연 또한 **유료 Reader 실제 해석은 미공개**다. `native-mobile-reader-interpretation-service.ts`는 Public activation OFF 유지.
- 다른 8명 공개 시 Character 설정·Runtime 검증·서버 grant·Reader public route·결제 권한·실사용 smoke를 각 캐릭터별로 승인한다.
- 본 PR에는 서버·Vercel·결제·DB·실제 APK 변경이 없다.
