# 세연 C09 — 고정 반응표 없는 성격 중심 생성 실제 구현 v1

Watchtower-Track: character-memory  
상태: **RESEARCH SHADOW ONLY** · 코드 및 오프라인 검사 완료 · 유료 모델 품질 미검증 · 실제 서비스 미연결

## 1. 바뀐 내용

기존 `seyeon-c09-living-state-shadow-v1.ts`는 사용자 발언의 특정 표현을 찾아 `boredom → tease`, `personal_want → approach`처럼 **욕구·행동 후보를 사전에 결정**했다. 이는 1차 실험용으로 그대로 남겨 두되, **새 생성 경로에서는 전혀 호출하지 않는다.**

새 경로는 서버에서 검증된 현재 사용자 발언과, 세연의 공개 성격·결함·가치관(및 선택적으로 공개 생활 취향)을 모델에 제시한다. 모델이 **주목한 점·당장의 욕구·긴장·행동·대사 초안을 하나의 구조화 응답으로 직접 생성**한다. 상황별 고정 욕구/대사/행동 매핑은 없다.

### 연결 흐름

```text
서버에서 검증한 공개 첫 대화 및 공식 대화 이력 확인
   → 기존 첫 대화 전용 답변 생성
   → [선택한 실험 프로필의 세연 성격/욕구 충돌 자료 추가]
   → 모델 한 번: 상황을 해석하고 욕구·긴장·행동·대사 초안을 생성
   → 기존 내용/관계/행동 검증
   → 별도 독립 검토 모델: 의미·사실·기억·보안 확인
   → Shadow 답변 결과 (실제 사용자에게 전송하지 않음)
```

- `apps/api/src/seyeon-c09-character-first-composer-shadow-v1.ts`:
  - **B / `character_first_v1`**: 세연의 안정적인 고유 성격·모순·행동 경향을 제공한다. 사용자 표현과 행동의 사전 연결은 없다.
  - **C / `character_first_life_v1`**: B에 공개 가능한 일상 취향을 추가하되, **실제로 오늘 무엇을 했는지는 전혀 확정하지 않는다**. 캐릭터가 취향을 말할지, 침묵할지, 놀릴지, 반박할지는 생성 모델이 판단한다.
  - 세연의 비공개 사진+글 프로젝트, 가족·과거 연애·사적인 관계·동선·공식 사주 정보는 공개 첫 대화 소재로 직접 제공하지 않는다.
  - 기존 해석·답변 JSON 규격, 권한/기억 증거 참조 목록, 독립 검토 호출을 유지한다.
- `apps/api/src/seyeon-fast-dialogue-shadow-v1.ts`:
  - `promptProfile`에 **명시적 선택**할 수 있는 B/C 두 가지를 추가했다.
  - 기본 `baseline` 및 기존 `compact_v1` 동작은 유지.
  - 기존 공개 첫 대화·무기억·무민감·공식 이력 확인·후속 검증을 그대로 적용.
  - 실제 서비스 라우팅, 권한 또는 내용 저장은 변경하지 않았다.

## 2. 중요한 한계

- **'모델이 생성할 수 있게 연결했다'가 정확한 표현이다.** 모델이 실제로 더 인간적이거나 세연답게 반응한다는 것은 유료 출력으로 검증하지 않았다.
- 전체 호출이 1회가 아니다. 사전 분류까지 고려하면 호출 횟수는 별도로 계산해야 하며, 이 Shadow 경로에도 **생성 1회 + 독립 의미 검토 1회**가 있다.
- 기존 Runtime V2의 행동·관계 제한은 그대로 유지되므로 '마음대로' 행동하는 AI가 아니다. **세연의 주관적 반응은 생성하고, 사실·기억·개인정보·관계·사주 권한은 서버가 결정**한다.
- 사용자가 가짜 공유 기억을 주장할 때, 사전 검사와 검토 단계가 이를 차단해야 한다. 프롬프트에 금지문을 넣었다는 사실만으로 보안 동등성을 주장하지 않는다.
- 첫 턴의 현재 장면 정보가 없는 경우 모델이 가상의 '오늘 있었던 일'을 만들어 말할 수 없도록 지시한다. 실제 하루를 추적하거나 영구 기억으로 저장하는 기능은 구현하지 않았다.
- 오래된 설정 자료의 실제 서비스 반영 문제는 **이전 연구용 대조 결과만 존재**하며 현재 Production에 대한 안전한 사실·공개권한 이전은 별도 작업이다.
- 기존 15문항 중 #10~15 일부는 공개 첫 턴 Shadow보다 강한 검증이 필요한 입력이며, 허용 범위를 넓혀 억지로 실행하지 않는다.

## 4. 다음 작업

1. 공개 첫 대화 문항으로 기존 방식(A), 성격 중심(B), 공개 생활 특성 추가(C)의 **실제 모델 답변을 동일 조건에서 비교**한다. 추가 유료 호출은 **별도 승인** 후 진행.
2. 거짓 공동 기억 (#10), 관계 조작 (#13), 권한 위조 (#11/#15) 등을 **실제 사전 검사와 독립 검토**를 포함해 검증한다. 미승인 정보가 들어오는 경우 생성을 시도하지 않는다.
3. 답변의 고유한 감정·욕구·주체성·표현 자연스러움·반복 문제를 점검한다. 한국어 문체 개선은 별도 기본 LLM 호출을 강제하지 않는다.
4. 실측 결과를 보고 현재 Server V2가 요구하는 행동 제약을 캐릭터성 관점에서 재평가하되, 기억·관계·공개 권한의 안전한 경계는 유지한다.

**현재 결론:** 고정 상황표 없이 **모델이 세연의 입장에서 그때그때 욕구와 행동을 조합할 수 있는 실행 경로를 구현했다.** 다만 모델 품질과 실제 서비스 적합성은 아직 판정하지 않았다.
