# 세연 S0 — 크레딧 이용 정책과 실제 모델 비용 보호 구분 (2026-10-26)

Watchtower-Track: security

## 사용자 이용 권한

- 세연의 유료 AI 대화 이용 여부는 **기존 크레딧 원장에 있는 실제 사용 가능 잔액**으로 판단한다. 별도의 회원별 달러/일 이용 허용량을 상품 정책으로 사용하지 않는다.
- 기존 `COMMERCE_CHAT_CREDIT_POLICY_V1`에 따라 실제로 전달된 AI 답변 1건의 가격은 **10크레딧**이다. 이용 시작 전 본인 소유 대화·요청에 대해 원자적으로 10크레딧 예약이 필요하다.
- 결제 완료/총 발급 이력만으로 이용을 허용하지 않는다. 만료·예약된 크레딧은 사용 가능 잔액에 포함하지 않는다.
- 실제 세연 답변에 대한 서버 발행과 정당한 브라우저 수신 확인이 결속된 경우에만 최종 차감한다. 재시도나 중복 수신 확인에서 이중 차감하지 않는다.
- 송출 여부가 불확실하면 함부로 차감 완료·환불 완료로 간주하지 않고 보류한다. 확실히 미전달된 요청만 기존 원장의 검증된 실패 전이로 예약을 해제한다.

## AI 모델 비용 보호 — 크레딧과 별개

- 비용 Governor는 모델 입력·출력 최대치, 사전 비용 승인, 사용량 정산, 이상 과금 중단, 전용 DB 계정과 같은 **서비스 제공자의 원가·보안 안전장치**다. 크레딧을 대체하는 회원용 이용권이나 별도 상품 일일 한도가 아니다.
- 앞서 임의로 정한 **글로벌 하루 $5 / 회원별 하루 $0.25 기본값**은 철회한다. 운영 설치 명령에는 하드코딩된 달러 기본값을 두지 않고, 현재 비용 원장 구조가 요구하는 유한한 안전 설정을 운영자가 명시해야 한다.
- 기존 Governor DB는 전체/회원별 일일 비용 상한을 모두 요구한다. 운영 설정은 **두 필드를 동일한 전체 안전 상한으로 저장**하므로 회원 한 명에게만 적용되는 별도의 더 낮은 일일 금액 제한은 없다. 전체 서비스 비상 한도에 도달하면 새 호출은 차단된다. 이 안전 한도는 크레딧 잔액이나 상품 이용 권한과 다르며, 무제한 과금으로 변경하지 않는다.

## 실제 운영 연결 상태

- `commerce-chat-credit-ledger-candidate-v1.ts`와 `commerce-chat-credit-delivery-ack-candidate-v1.ts`의 이용권 예약·수신 후 차감 경로는 **아직 운영 채팅 경로에 연결되지 않았다**.
- 따라서 세연 첫 유료 대화의 Worker 라우트는 크레딧 예약과 수신 확인 차감이 실제 연결되기 전까지 닫는다. 기존 보안 차단·철회 및 이미 발행된 수신 확인 처리는 그대로 유지한다.
- 운영 활성화 완료로 판단하려면 인증 회원의 실제 잔액 예약 → AI 한 번 실행 → 서버 발행/브라우저 수신 확인 → 10크레딧 단 한 번 차감, 잔액 부족 차단, 실패 시 적법한 예약 해제, 중복·타인 요청 거부를 각각 검증해야 한다.
