## 감사 보존

감사 이벤트의 기본 최소 보존은 365×24시간이며, INSERT 트리거가 만료 시각을 부여합니다. 장기 보존·무기한/기한부 hold를 보호하는 비공개 원장과 최대 1000건의 정리 RPC를 설치했습니다. 정리와 그 결과 감사는 같은 트랜잭션입니다. 별도 Retention Executor는 RPC만 실행하고 직접 DELETE를 할 수 없으며 기존 Audit Writer는 정리 RPC를 실행할 수 없습니다.

폐기형 PG17.6과 실제 Production의 전체 롤백 검사에서 365일 경계, 장기/무기한 hold, 한도, 역할 분리, 정리 결과 감사 및 감사 실패 시 삭제 롤백을 검증했습니다. Production 검사 전 감사 원장이 비었음을 확인하는 가드를 두었습니다. 모든 합성 데이터·임시 권한은 롤백됐고 감사 저장 행은 0개입니다. 로그인 자격증명·정리 스케줄은 없습니다.
