## 공통 적용 원칙

1. **구현 완료:** 해당 트랙이 소유하고 실제 커밋·테스트·검증된 기능만 완료로 확정한다. 마지막 커밋/PR/CI 링크가 필요한 경우 현행 값을 확인한다.
2. **승인된 보류:** 이미 사용자/권위 문서에서 OFF/HOLD로 확정한 기능은 "추가 결정을 기다리는 질문"으로 되돌리지 않는다. 미실행을 실패나 임의 개발 과제로 만들지 않는다.
3. **타 트랙 의존성:** 실제 모델/GEPA, 캐릭터 공개, Saju, Reader, Commerce, Security, DR는 각각 원천 소유자가 검증한다. 이 트랙은 연결점만 계약한다. 거짓 통과나 무단 기능 활성화는 금지한다.
4. **종료 선언 구분:** 부분 구현 `SCOPE_COMPLETE`은 전체 `ROADMAP_COMPLETE`과 다르다. 기존 필수 목표와 운영/안전 게이트는 제거하지 않는다.
5. **중단 규칙:** 미완료가 독립 증거·승인·실제 운영 조건에만 의존한다면 같은 종류의 오프라인 테스트를 추가하지 말고 정확한 원인/소유 트랙/재개 신호를 기록하고 현재 작업 단위를 종료한다.
6. **사용자 질문 방지:** 이전에 확정된 결정은 원본 승인 문서를 우선 확인하고 새로 묻지 않는다. 사용자 판단이 진짜 필요한 새 변경이 발생했을 때만 요청한다.

이 점검은 **교차 트랙 상태의 구조 진단**이지, 모든 트랙이 같은 이유로 막혔다거나 대부분 완료됐다는 실증 결과가 아니다. 각 트랙의 승인된 출시 목표와 출처·보안·운영 조건은 그대로 유지한다.
