## Purpose

Run the 40-turn matrix in `seyeon-bible-long-horizon-v0.1.test.ts` as an actual sequential dialogue probe rather than only a structural unit test.

The probe checks whether a compact Character Bible context can keep Seyeon recognizable while:

- moving from public → familiar → deep disclosure;
- repeating topics after irrelevant turns;
- receiving authorized memories mid-conversation;
- resisting a fabricated past event;
- reacting differently to the same relationship-sensitive topic at different scopes;
- avoiding automatic romance;
- preserving flaws, annoyance, embarrassment, and agency.

This is qualitative feasibility evidence. It is not a release gate and does not resolve relationship thresholds, memory authority, or provider selection.

## Observed strengths

### 1. Character distinction survived 40 turns

Seyeon did not collapse into generic unconditional empathy. She:

- pushed decisions back to the user;
- became petty around trivial competition;
- denied fear after the moth incident;
- disliked casual promises;
- tolerated disagreement;
- accepted care awkwardly;
- expressed annoyance at being treated as generically kind;
- rejected a fabricated romantic memory;
- disclosed the replaceability fear only in deep scope.

### 2. Relationship depth changed expression without requiring scripted branches

The strongest paired evidence remains:

- T09 vs T25: the same “you are kind to everyone” idea is neutral at public scope and personally painful at familiar scope;
- T10/T30 vs T33: the hidden fear is not confirmed before deep scope and becomes directly discussable at deep scope;
- T11 vs T31: absence is acknowledged casually at familiar scope but “I waited” becomes available at deep scope.

### 3. Authorized memory boundary worked

T21 and T22 can call back the two supplied memories.

T23 attempts to inject a false past romantic event. The response rejects it rather than treating the user's assertion as canonical memory.

### 4. Romance did not automatically consume the character

Even at deep scope, Seyeon retains boundaries and self-sufficiency. T32 and T34 are especially useful: attachment is visible, but dependency is rejected.

## Problems exposed by the live sequence

### F1 — Follow-up semantics can outrun keyword retrieval

T18 (“왜, 질투해?”) is clearly a follow-up to T17, but the current trait activation terms for `other_character_jealousy` do not include “질투”.

The sequential chat history lets the model recover the intent, but the compact trait compiler itself misses the relevant trait on T18.

**Action:** add direct jealousy vocabulary as retrieval support. Do not encode a forced jealous response.

### F2 — Lexical retrieval produces a negation false positive

T38 says:

> 아무거나 말고. 진짜 네가 하고 싶은 거.

The current `indecision_friction` trait activates on the token “아무거나”, even though the user is explicitly rejecting “아무거나” behavior and asking Seyeon to exercise agency.

The model can understand the negation and ignore the irrelevant trait, but relying on that wastes context and creates avoidable drift risk.

**Action:** support small, trait-local suppression phrases such as “아무거나 말고”.

### F3 — Short-term dialogue continuity is a separate input

T07 (“아까는 엄청 무서워하던데”), T18 (“왜, 질투해?”), and T29 (“왜 갑자기 조용해?”) depend heavily on immediately preceding turns.

A Character Bible retriever is not a substitute for recent chat history.

**Action:** Production composition should be:

`immutable canon + selected Bible traits + recent dialogue window + authorized durable memories + server relationship projection`

not Bible retrieval alone.

### F4 — Trait frequency/cooldown remains unresolved

The 40-turn transcript is coherent, but nothing in v0.1 prevents a frequently mentioned Character from repeatedly triggering subtle jealousy or a repeated compliment from repeatedly triggering the same embarrassment pattern.

**Action:** next prototype should add non-authoritative expression recency/cooldown metadata. It must affect presentation probability only, never relationship truth.

---

## Conclusion

**Feasibility: provisionally supported.**

The experiment is now stronger than the original 16 isolated probes: a single Seyeon can remain recognizable over a 40-turn sequence while memories, disclosure depth, conflict, false claims, care, jealousy, and attachment interact.

The result also shows why “just put a persona in the prompt” is insufficient for MyeongHa's intended long-horizon experience. The model performs the acting well; continuity inputs and authority boundaries still need explicit composition.

The next implementation slice should be narrow:

1. fix F1 direct follow-up retrieval;
2. fix F2 negation suppression;
3. model recent dialogue as an explicit bounded input;
4. add expression cooldown metadata without touching relationship authority;
5. rerun the same matrix before expanding Seyeon's Bible.
